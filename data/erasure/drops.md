Observed: the first strict drop is at n = (p−1)(e+1)+2, exactly the smallest n whose saturation threshold e*(n,p)=⌈(n−1)/(p−1)⌉−1 exceeds e (for n ≤ (p−1)(e+1)+1 both budgets already sit at the floor 2n−1).  The value 2^(p−1)+1 is instead the first n that is *unreachable* with e=0.
