# 事前登録: 完全二分木 T_5（n=31）の最小手数 T_P(T_5, 6)（2026-09-29・結果を見る前に凍結）

観測（全数 BFS・3 通り照合・`overleaf/2026-WiNF/code/results_P2.txt`）:
p=h+1 の最小手数 T_P(T_h, h+1) = 5, 21, 57（h=2,3,4）．p=h では到達不能（h<=4）．
KSS Thm 5.5 の構成の手数は (2h-3)2^h+1 = 5, 25, 81, 225（h=2..5．再生器で検査済み）．

3 点に合う式は無数にある．代表 2 つを候補として書き，h=5 で分ける:

- **候補 A**（線形型）: T(h) = 2T(h-1) + 4h - 1 ⟹ **T(5) = 133**．成り立てば T = Θ(n)
- **候補 B**（n log n 型）: T(h) = (h-1)2^h + 4h - 7 ⟹ **T(5) = 141**

**予測**: T_P(T_5, 6) < 225（KSS の構成は h=5 でも最適でない）．A と B のどちらかは言わない．

反証条件: SAT が T=224 で UNSAT（DRAT 検証つき）なら予測は棄却．
⚠ どちらの候補が当たっても「規則」とは呼ばない（台帳 Q9 の警告．4 点からの外挿）．
漸近の判定（Θ(n) か Θ(n log n) か）は下界の証明か，一般 h の構成でしか付かない．

## 結果（2026-09-29 同日・凍結後に追記）

**T_P(T_5, 6) = 141。** 予測「< 225」は当たり。候補 B（n log n 型）と一致、候補 A（133）は棄却。
- 求め方: 自己同型 2^15 で割った BFS（`overleaf/2026-WiNF/code/p2_symbfs.cpp`、1675 万状態・1 分）
- 検算: 検算者エージェントが前工程のコードを見ずに別方式で再実装し 141 を再現。証人（141 手）は KSS Def 2.6/2.7 直書きの再生器を通過
- ⚠ SAT（p2_sat.py）は T=141 の SAT も 20 分で解けなかった。T=139 UNSAT の DRAT は <host> `~/p2tree` で取得中
- 次の予測（未検定）: 候補 B が一般に成り立つなら T(T_6, 7) = 337
