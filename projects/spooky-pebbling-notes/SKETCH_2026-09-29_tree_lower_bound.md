# 完全二分木の spooky pebbling の時間下界: 素案（2026-09-29・層 2〜3 の混在。各主張に層を付ける）

対象: 完全二分木 T_h（h 段、n=2^h-1、辺は子→親）、ペブル上限 p（主に最小の p=h+1）。
規則（Quist–Laarman。KSS Def 2.6/2.7 と最小手数が一致）: pebble/unghost は子が全てペブル・上限内、
unpebble は子が全てペブル、ghost は前提なし。T_P = 空 → 根だけペブル・幽霊なし の最小手数。
厳密値（層 2、2 実装一致）: T_P(T_h,h+1) = 5, 21, 57, 141（h=2..5）。上界（証人つき）: h=6 で 335。
⛔ 候補式 (h-1)2^h+4h-7 は h=5 を当てたが h=6 の証人 335 で棄却（予測 337）。

## 補題 1（射影）— 紙の証明、短い

T_h の正しい手順 S と、根 r の子 u を根とする部分木 T(u) を取る。S のうち T(u) の頂点に打つ手だけを
順に並べた列 S|u は、T(u) 単独のゲームで正しい手順である。各時刻で T(u) 上のペブル数 ≤ p − (T(u) の外のペブル数)。

証明: 手の前提条件（子が全てペブル）は、その頂点の子、すなわち T(u) 内の頂点しか見ない。
T(u) 外の手は T(u) 内の状態を変えない。□

## 補題 2（往復の分解）— 紙の証明

V(k, c, m) := 高さ k の木で、空 → 「根がペブルで木全体のペブル数 ≤ m」の状態を経由 → 空、上限 c の最小手数。
T_P の手順 S で r を初めて置く時刻 t_r には、両方の子 u,w がペブルを持つ。r の置き場を含めてペブル数 ≤ p なので、
|P_{t_r} ∩ T(u)| + |P_{t_r} ∩ T(w)| ≤ p − 1。終状態で T(u),T(w) は空（幽霊もなし）。
補題 1 より S|u, S|w はそれぞれ往復で、経由点のペブル数を m_u, m_w とすると

  T_P(T_h, p) ≥ 1 + min_{m_u + m_w ≤ p−1} [ V(h−1, p, m_u) + V(h−1, p, m_w) ].

数値（V は全状態ライブラリの探索で求めた厳密値。p2_lift.cpp の VPRINT）:

| h | 下界 | 最小を与える (m_u,m_w) | 厳密値 |
|---|---:|---|---:|
| 3 | 19 | (1,2) | 21 |
| 4 | 49 | (2,2) | 57 |
| 5 | 123 | (2,3) | 141 |

V(k,c,m) の表（c = k+1..k+3、m = 1..c）:
- k=2: [10,8,6] / [10,8,6,6] / [10,8,6,6,6]
- k=3: [34,28,22,20] / [30,24,22,20,18] / [28,24,22,20,18,16]
- k=4: [84,70,64,56,54] / [78,64,58,54,50,48] / [74,60,54,52,50,48,46]

⚠ この下界は「2 つの子の射影に同じ時刻の上限 p を静的に課す」だけで、時間とともに変わる上限の結合
（片方が保持している間、もう片方は p−1 以下）を捨てている。差 2, 8, 18 はそこから来ると見ている（未検証）。

## 補題 3（最後の外し）— 紙の証明、要検査

往復（空 → 空）の中で根 r のペブルが最後に消える手は unpebble である（ghost なら r に幽霊が残り、
幽霊は unghost でしか消えず、unghost は r にペブルを戻すので「最後」に反する）。
よって往復には、子が両方ペブルを持つ時刻が少なくとも 2 つある: r を初めて置く t_1 と、r を最後に外す t_2（t_1 < t_2）。
各子の射影は、t_1 と t_2 の両方で子の根がペブルを持つ往復である。

## 予想される道筋（層 3。ここが穴の候補）

補題 3 で、子 u の根が [t_1, t_2] の間ずっとペブルを持ち続けるなら、その間 u の分のペブルが 1 個固定され、
もう一方の子 w と r が使える上限は下がる。持ち続けないなら、u の根は [t_1,t_2] の中で置き直される
（u の部分木の再計算が要る）。最小ペブル数 p = k+1 では両方の子が持ち続けることは上限と両立しない、
したがって各段で少なくとも一方の子の部分木が 2 回計算される、と示せれば

  V(k) ≥ V(k−1) + 2·(再計算の費用 ≈ 2^k) の形 ⟹ V(k) = Ω(k·2^k)、T_P = Ω(n log n)

が出るはずである。未解決の点:
(i) 「持ち続けることが上限と両立しない」の正確な主張。r が [t_1,t_2] で幽霊になっている場合（r のペブルを
    外して後で unghost）もあり、そのときは上限の計算が変わる
(ii) 再計算の費用が「部分木全体の往復」に等しいとは限らない（部分木の一部だけが置き直される）
(iii) 深い段では上限が p より緩い（浅い段の部分木はペブルを持たない時間がある）ので、
     最小ペブル数の強制が全ての段に効くとは限らない。KSS の構成の漸化式が 2^{h+1} で、最適が 2^h（予想）
     であることとの整合

## 検査の予定

- 補題 2 の下界の数値は再計算可能（p2_lift.cpp VPRINT=1、K0 を段ごとに変えて全状態ライブラリの上で V を解く）
- 補題 3 に基づく「2 経由点の往復」V2 を計算すれば、補題 2 より強い下界が数値で出るかを確かめられる（未実施）

## 第 2 回（2026-09-29 夕）: log 因子を生む仕組みの探索 — 結果は否定的

### A. 後片づけの厳密値 C(k,c,m)（数値・全状態の逆向き BFS、QL 規則。scratchpad/lb/cl.c）
C(k,c,m) := 根がペブルで木全体のペブル数 ≤ m の状態から、上限 c で空にする最小手数（m について単調化）。
- k=2,c=3: 5,4,3 ／ k=3,c=4: 21,16,11,10 ／ k=3,c=5: 17,12,11,10,9
- k=4,c=5: **55,42,37,30,29** ／ k=4,c=6: 49,36,31,28,25,24
最小上限では、ペブルを多く持たせても後片づけは安くならない（C(4,5,5)=29 は T(4)=57 の約半分）。

### B. 最上段の不等式（補題 1〜3 と根の**最後の**配置 t'_r。紙の証明＋厳密な C）
t'_r 以前に全頂点は 1 度置かれ、t'_r に乗っていないものは外されている: 前半 ≥ 2(n−1) − (m_L+m_R)。
t'_r 以後、各子の射影は「根がペブル・ペブル数 m の状態から上限 ≤ h で空へ」: ≥ C(h−1,h,m)。
  T(h) ≥ 2(n−1) + 1 + min_{m_L+m_R ≤ h} [C(h−1,h,m_L) + C(h−1,h,m_R) − m_L − m_R]
数値: 19, **57**, 135（h=3,4,5。critic の W 版と同値）。**ただし C を再帰的に下から抑えないと一般の h に伸びない。**

### C. 再帰で閉じる試み — 2 つとも失敗
1. 静的な上限の射影だけで C を再帰的に抑える: 深い段ほど上限が緩み、**線形の 4n−2p−1 に張り付く**（h≤20 で計算）。
2. 「後に根を外し終える子 Y の根は、親の最後の除去 f から Y の最後の除去まで**乗り続ける**」と置いて上限を結合する DP:
   **不健全**。h=3 で「不可能」を返す（実際は 21 手）。Y の根は途中で幽霊にされ置き直されうるので、「f と f_Y で乗っている」は
   「区間の間ずっと乗っている」を意味しない。大きい h では値は再び 4n−2p−1 に張り付く（scratchpad/lb/rec.py）。
   ⇒ 左右の結合は「2 時刻で乗っている」からは取り出せない。取り出すには、Y を置き直す費用まで込みで数える必要がある。

### D. 置き回数の統計（最短手順 h=3,4,5 と h=6 の証人 335 手）
平均置き回数 1.57, 1.93, 2.29, 2.67（1 段あたり約 +0.37、h に比例 = n log n と整合）。最大は 4 のまま。
深さ別平均（h=6）: 1.00, 1.50, 2.00, 2.25, 2.44, 3.09（葉が最も多い）。

### E. 「頂点ごとに互いに素な置き直し」候補の検定 — データで否定
J_u := [u の最後の配置, u の最後の除去]。
- 候補 H1「J_u の中で少なくとも一方の子が置き直される」: 各深さに置き直し 0 の u がある（h=6 の深さ 4 で 16 頂点中 4 つが 0）
- 候補 H2「同じ深さの J_u は互いに素」: 隣接対で成り立つのは 1/4, 3/11, 14/26（h=4,5,6）
⇒ 最短手順は「置き直し」を区間に局在させず、時間的に重ね合わせている。

### 残る道（層 3、未検証）
- 置き直しの「費用」を区間でなく**ペブル×時間の面積**で数える（最小上限では面積の総量が限られる）
- 最上段の不等式 B を、C の厳密値でなく「C(k,k+1,m) ≥ α·T(k)」型の比の不等式として帰納する（数値では C(4,5,m)/T(4) = 0.96〜0.51）

### 批判者レビュー第 2 回（2026-09-29 夜）を受けた訂正 — E の結論は撤回
- ⛔ **E の H2 の否定は撤回。** 兄弟の J は構造上必ず重なる（親の最後の除去 f_w に両方の子が乗るため）。兄弟以外の同じ深さの対は
  ほぼ互いに素（非葉 3/4, 25/28, 136/140、h=4,5,6）。⇒ 「異なる親を持つ同じ深さの u,v で J_u∩J_v=∅」が候補として生き残る（例外 4/140 を要調査）
- ⛔ **E の H1 は区間の取り方の誤り。** 再計算は最後の配置の「前」に起きる。I_u := (最後の配置の直前の除去, 最後の配置) で、その除去が ghost なら
  部分木 u（u を除く）の全頂点が I_u 内で置き直される（h=4: 2/2, h=5: 8/8, h=6: 24/25）。KSS の U と同じ形。ただし祖先と子孫の I_u は
  大半が部分重複（h=6: 45 対中 互いに素 9・入れ子 0・部分重複 36）なので、単純に足すと二重計上になる。**これが最有望の手がかり（層 3）**
- D の平均置き回数は (T+1)/(2n) の恒等式で新情報なし。「h に比例」は誤り（平均/h は減少、平均 ≈ 0.37h+定数のアフィン）。深さ別の分布は新情報
