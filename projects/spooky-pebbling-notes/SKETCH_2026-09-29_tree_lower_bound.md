# 完全二分木の spooky pebbling の時間下界: 素案（2026-09-29・層 2〜3 の混在。各主張に層を付ける）

対象: 完全二分木 T_h（h 段、n=2^h-1、辺は子→親）、ペブル上限 p（主に最小の p=h+1）。
規則（Quist–Laarman。KSS Def 2.6/2.7 と最小手数が一致）: pebble/unghost は子が全てペブル・上限内、
unpebble は子が全てペブル、ghost は前提なし。T_P = 空 → 根だけペブル・幽霊なし の最小手数。
厳密値（層 2、2 実装一致）: T_P(T_h,h+1) = 5, 21, 57, 141（h=2..5）。上界（証人つき）: h=6 で 335。
⛔ 候補式 (h-1)2^h+4h-7 は h=5 を当てたが h=6 の証人 335 で棄却（予測 337）。

## 補題 1（射影）— 紙の証明、短い

T_h の正しい手順 S と、根 r の子 u を根とする部分木 T(u) を取る。S のうち T(u) の頂点に打つ手だけを
順に並べた列 S|u は、T(u) 単独のゲームで正しい手順である。各時刻で T(u) 上のペブル数 ≤ p − (T(u) の外のペブル数)。

証明: 手の前提条件（子が全てペブル）は、その頂点の子、すなわち T(u) 内の頂点しか見ない。
T(u) 外の手は T(u) 内の状態を変えない。□

## 補題 2（往復の分解）— 紙の証明

V(k, c, m) := 高さ k の木で、空 → 「根がペブルで木全体のペブル数 ≤ m」の状態を経由 → 空、上限 c の最小手数。
T_P の手順 S で r を初めて置く時刻 t_r には、両方の子 u,w がペブルを持つ。r の置き場を含めてペブル数 ≤ p なので、
|P_{t_r} ∩ T(u)| + |P_{t_r} ∩ T(w)| ≤ p − 1。終状態で T(u),T(w) は空（幽霊もなし）。
補題 1 より S|u, S|w はそれぞれ往復で、経由点のペブル数を m_u, m_w とすると

  T_P(T_h, p) ≥ 1 + min_{m_u + m_w ≤ p−1} [ V(h−1, p, m_u) + V(h−1, p, m_w) ].

数値（V は全状態ライブラリの探索で求めた厳密値。p2_lift.cpp の VPRINT）:

| h | 下界 | 最小を与える (m_u,m_w) | 厳密値 |
|---|---:|---|---:|
| 3 | 19 | (1,2) | 21 |
| 4 | 49 | (2,2) | 57 |
| 5 | 123 | (2,3) | 141 |

V(k,c,m) の表（c = k+1..k+3、m = 1..c）:
- k=2: [10,8,6] / [10,8,6,6] / [10,8,6,6,6]
- k=3: [34,28,22,20] / [30,24,22,20,18] / [28,24,22,20,18,16]
- k=4: [84,70,64,56,54] / [78,64,58,54,50,48] / [74,60,54,52,50,48,46]

⚠ この下界は「2 つの子の射影に同じ時刻の上限 p を静的に課す」だけで、時間とともに変わる上限の結合
（片方が保持している間、もう片方は p−1 以下）を捨てている。差 2, 8, 18 はそこから来ると見ている（未検証）。

## 補題 3（最後の外し）— 紙の証明、要検査

往復（空 → 空）の中で根 r のペブルが最後に消える手は unpebble である（ghost なら r に幽霊が残り、
幽霊は unghost でしか消えず、unghost は r にペブルを戻すので「最後」に反する）。
よって往復には、子が両方ペブルを持つ時刻が少なくとも 2 つある: r を初めて置く t_1 と、r を最後に外す t_2（t_1 < t_2）。
各子の射影は、t_1 と t_2 の両方で子の根がペブルを持つ往復である。

## 予想される道筋（層 3。ここが穴の候補）

補題 3 で、子 u の根が [t_1, t_2] の間ずっとペブルを持ち続けるなら、その間 u の分のペブルが 1 個固定され、
もう一方の子 w と r が使える上限は下がる。持ち続けないなら、u の根は [t_1,t_2] の中で置き直される
（u の部分木の再計算が要る）。最小ペブル数 p = k+1 では両方の子が持ち続けることは上限と両立しない、
したがって各段で少なくとも一方の子の部分木が 2 回計算される、と示せれば

  V(k) ≥ V(k−1) + 2·(再計算の費用 ≈ 2^k) の形 ⟹ V(k) = Ω(k·2^k)、T_P = Ω(n log n)

が出るはずである。未解決の点:
(i) 「持ち続けることが上限と両立しない」の正確な主張。r が [t_1,t_2] で幽霊になっている場合（r のペブルを
    外して後で unghost）もあり、そのときは上限の計算が変わる
(ii) 再計算の費用が「部分木全体の往復」に等しいとは限らない（部分木の一部だけが置き直される）
(iii) 深い段では上限が p より緩い（浅い段の部分木はペブルを持たない時間がある）ので、
     最小ペブル数の強制が全ての段に効くとは限らない。KSS の構成の漸化式が 2^{h+1} で、最適が 2^h（予想）
     であることとの整合
