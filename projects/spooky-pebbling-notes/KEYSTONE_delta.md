## 1. なぜ「符号 1 本」で足りるのか

`closed.py` の実装は 2 つの部品でできている。

| 部品 | 中身 | 層 |
|---|---|---|
| **KSS Cor 4.12** | $T_{UG}(n,s)=\min_{k\in[1,n-1]}\bigl[2k-1+T_{UP}(k,s)+T_{UG}(n-k,s-1)\bigr]$ | **1**（`SpookyPebbling/Unghost.lean`） |
| **δ 則** | $T_{UP}(n,s)=T_{UG}(n,s)+\delta(n,s)$、$\delta=+1$ if $n\ge\theta(s)$ else $-1$ | **3** |

Cor 4.12 の右辺に $T_{UP}$ が入るので、**単独では回らない**（README の
「Cor 4.7 も Cor 4.12 も右辺に $T_{UP}$ を含むのに $T_{UP}$ を決める式が無い」）。
**δ を代入すると右辺が $T_{UG}$ だけになり、$n$ か $s$ が真に減るので自己完結する。**

**機械で確かめた**: δ だけを使って組み直した実装が、$s=2..10$・$n=1..60$ の
**540 点で既存実装と完全一致**（`breakpoint_map.py --recurrence` の検定と同じ道具立て）。

## 2. どこまでが既に証明済みか（Lean の定理名と**仮定の範囲**をそのまま書く）

| Lean の定理 | 主張 | 仮定 |
|---|---|---|
| `UGvsUP.TUG_le_TUP_succ`（KSS Lemma 4.10） | $T_{UG}\le T_{UP}+1$ | $1\le n$、実行可能 |
| `UGvsUP.TUP_le_TUG_succ`（KSS Lemma 4.9） | $T_{UP}\le T_{UG}+1$ | $1\le n$、$1\le s$、実行可能 |
| **`UGvsUP.TUG_TUP_diff_one`** | **差はちょうど 1**（$0$ はパリティで排除。**この形は KSS に無い**） | $1\le n$、$1\le s$、実行可能。**$n$ に上限なし** |
| `Sign.delta_sign_flip` | 符号が $n=\theta(s)$ で反転する | ⚠ **$s\le n\le B_4(s)-1$**。傾き 4／6 の領域だけ |

**⇒ $\delta\in\{-1,+1\}$（$0$ は無い）は $n$ に上限なく証明済み。**
**開いているのは符号だけ**、しかも $n\ge B_4(s)$（傾き 8 以降）でだけ。
さらに $T_{UP}\le T_{UG}+1$ は証明済みなので、**要るのは $T_{UG}\le T_{UP}$ の一方向だけ**
（差が 1 なので、そこから $T_{UP}=T_{UG}+1$ が出る）。

## 3. README の書き方との関係（同じ穴の別の呼び方）

README は残る層3 を「**(a) 傾き 8 以降の上界（構成）**——各 $m$ についてその区間で達成する」
と書いている。**同じ穴だが、こちらの形には区間の帳簿が要らない。**
上包絡の $m$ ごとの区間（$s=4$ なら $m$=1→[1..4], 2→[4..9], 3→[9..17], …）を
1 本ずつ潰す代わりに、**$n\ge\theta(s)$ という 1 つの条件で書ける。**

⚠ **等価だとまでは示していない。** 言えるのは「δ の符号 ⟹ 表全体」の向きだけ
（§1 の機械検査）。逆向き（表 ⟹ δ の符号）は自明だが、
**構成を作る難しさが減るかどうかは未確認**である。これは層3 の見立てにすぎない。
