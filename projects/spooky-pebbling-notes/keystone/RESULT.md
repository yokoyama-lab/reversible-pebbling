### 証明の筋（依頼の候補 (a) に当たる）

`U = T_UP`、`G = T_UG`。使うのは `decomp_exact`、`decomp_ug_le'`、傾き 2・4 の閉形式、`s = 2` の閉形式だけ。
傾き 6 以降の厳密値（定理F）も上包絡の構成も使わない。

1. **補題1・2**（`U` の増分）。`U(m+1,s+1)` の最適な分割 `m+1 = k+q` を取り、`U(m,s+1)` には 1 つ小さい分割を入れる。
   `k ≥ 2` なら頭を縮めて差は `2 + (U(k) − U(k−1))`。`k = 1` なら尻尾を縮めて `s` の帰納法。底は `U(n,2) = n²+n−3`。
2. **本体**（`s` の帰納法）。`θ(s+1) ≤ n` とし、`U(n,s+1)` の最適な分割 `n = k+q` を取る。
   - 場合A `θ(s) ≤ q`: 帰納法の仮定 `G(q,s) ≤ U(q,s)` を、同じ `k` で Cor 4.12 に入れる。
   - 場合B `q < θ(s)`: `k ≥ s+2` になる。分割を 1 つずらし `n = (k−1)+(q+1)` を Cor 4.12 に入れる。
     頭は補題2 で 4 手得、尻尾は閉形式から `G(q+1,s) ≤ U(q,s)+5`、掃きで 2 手得。合計で `G(n,s+1) ≤ U(n,s+1) − 1`。

場合B は実際に起きる（数値では `s ≤ 14`、`n ≤ 1000` の最適な `k` 1,079,150 個のうち 442 個）。
分解の最適な `k` は存在量化で 1 つ渡されるだけなので、両方の場合が要る。

### 証明の筋

`m` の帰納法と、その中で `s` の帰納法。使う構成は `T_UP` の分解の `≤` 側（`decomp_le`）だけ。

傾き `2(m+2)` の区間 `[brk (m+1) (s+1), brk (m+2) (s+1)]` は、折れ目の漸化式から、
頭の区間 `[brk m (s+1), brk (m+1) (s+1)]`（上限 `s+1`、傾き `2(m+1)`）と
尻尾の区間 `[brk (m+1) s, brk (m+2) s]`（上限 `s`、傾き `2(m+2)`）の**和にちょうど一致する**。
したがって区間内のどの `n` も `n = k + q` と分けられ、
`(2k−1) + (2(m+1)k − β_{m+1}(s+1)) + (2(m+2)q − β_{m+2}(s)) = 2(m+2)n − β_{m+2}(s+1)` で `k` が消える。
分け方は 2 通りで足りる（小さい側は頭を左端に、大きい側は尻尾を右端に固定）。
底は補題4（`T_UP = 2n−1`、`n ≤ s`）と `T_UP(n,2) = n²+n−3`。下界は既存の定理E'。

定理F（傾き 6）と同じ形の議論を、すべての傾きに対して 1 本の二重帰納法で回しただけである。
新しい構成（手順）は作っていない。
