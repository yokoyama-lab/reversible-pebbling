## 方法: 自己同型の商の上のフロンティア BFS

SAT（2788 手 × 255 頂点）は UNSAT の証明が現実的でないので採らず、状態空間を全部掃いた。
T_8 で 11 個以下の盤の軌道は高々 52,497,674,884（`orbcount.py`）で、全状態を覚える BFS には載らない。
そこで 3 層だけ持つ BFS にした。

### 正しさの根拠
1. **無向**: v を置く手が合法なら v を外して戻る手も合法（合法性は v の子だけで決まる）。
2. **二部**: 1 手でペブル数が ±1。深さ d の盤のペブル数の偶奇は d と一致（A・B とも全状態で実行時に検査）。
3. よって **L_{d+1} = N(L_d) \ L_{d−1}**。前・今・次の 3 層で層が正確に決まる。
4. **商**: Aut(T_H) は合法性とペブル数を保つ。軌道の道は帰納的に持ち上がる（[x_i]〜[x_{i+1}] の代表 x', x'' と
   σ(x')=y_i なる σ をとれば σ(x'') は y_i の隣）。ゴールの軌道は {根} だけなので、商の距離 = 元の距離。
5. ゴールが層 d に初めて現れれば M = d。層が空になれば到達不能。打ち切りは「未確定」。

### 2 つの独立な実装
| | A（`fbfs.c`） | B（`fbfs_b.c`） |
|---|---|---|
| 表現 | 高さ H−2 の部分木の軌道に番号（(b,L,R)、L≤R の hash-cons）、上 2 段を明示して 128 ビット | 再帰配置のビット列。正準形 = 各節点で左 block ≤ 右 block（辞書式）。鍵はペブル位置の昇順列 |
| 後継 | 高さ H−2 の後継表を ∅ からの閉包で前計算 | 盤の上で合法性を直接調べ toggle、祖先を辿って左右を入れ替え直す |
| 間引き | A=B なら B の手、半分が等しければ半分 2 の手を省く | 等しい兄弟の右側には降りない（空の部分木は最左の葉だけ）。打つ直前に合法性を再検査 |

**対称性の間引きの健全性**（依頼 3）: 節点 a の左右の block が等しいとき、a での入れ替え σ は盤を保つ自己同型で、
右の block の v を左の σ(v) に移す。v と σ(v) の toggle の結果は σ で移り合う（同じ軌道）。複数の祖先が該当しても、
最も上の該当祖先での入れ替えを繰り返せば代表に移る。実測でも B の枝刈りあり・なし（`--noprune`）・素朴版
`fbfs_b_naive.c` の三者が h≤6 の全 12 組で A と層ごとに一致。
