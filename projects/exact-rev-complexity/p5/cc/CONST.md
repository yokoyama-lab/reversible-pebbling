# 予算一定の SORT と蜘蛛型の木の予想 CC（2026-10-31）

`SORT.md` §4 の「GRAFT の等式を予算一定の場合に Knill の再帰から示せるかを先に見る」の記録．ユーザーの選択「お勧めで」（紙の帰着の検算 → GRAFT の最小の場合）による．
層: §1〜§4 は紙の証明（層 2，未検算）．使う Lean の定理は Knill の向き M(P_n,S) ≥ F_c(n,S)（`P5TreeKnill.lean` の `path_Fc_le`）だけ．
§5 の数値は計算機援用の有界検査（`const/`）．

記号: F(n,S) は Knill の再帰（`P5TreeChain.lean` の `Fc`．F(n,0)=∞，F(1,S)=1，n ≥ 2 で F(n,S) = min_{1≤m<n} F(m,S)+F(m,S−1)+F(n−m,S−1)）．
R^G_S(X) は予算 S 一定で ∅ から盤 X へ行く最短手数（手は可逆なので X から ∅ も同じ）．鎖の森の定義は `SORT.md` §1．

## 1. 補題 M（Knill の再帰の差分は n について非減少）

**補題 M.** すべての S ≥ 2 と x ≥ y ≥ 1 で F(y,S) + F(x,S−1) ≥ F(x,S) + F(y,S−1)．
（同値な言い方: 増分 I_S(n) = F(n+1,S) − F(n,S) は I_S(n) ≤ I_{S−1}(n)．ペブルが 1 個増えると，どの n でも増分が小さくなるか等しい．）

**補題 M0（凸性と増分の併合）.** F(·,S) の有限域は 1 ≤ n ≤ 2^{S−1} で，そこで凸（増分が非減少）．増分の列は
  I_S = (2) に続けて，列 I_{S−1} と列 J_S（J_S(m) = I_S(m) + I_{S−1}(m)）を小さい順に併合したもの．

*証明.* 離散の下限たたみ込みの標準的な事実を使う: 凸な列 f（域 1..A）と g（域 1..B）について h(n) = min_{m+k=n} f(m)+g(k)（域 2..A+B）は凸で，
h(2) = f(1)+g(1)，h の増分の列は f と g の増分の列を小さい順に併合したもの．
G_S(m) = F(m,S) + F(m,S−1) とおくと，n ≥ 2 で F(n,S) = (G_S □ F(·,S−1))(n)．S について帰納法，各 S の中で n について帰納法．
F(n,S) は m ≤ n−1 の G_S(m) だけで決まるので，n−1 までの F(·,S) が凸なら，G_S の 1..n−1 への制限は凸な列の和で凸．
その制限と F(·,S−1) のたたみ込みは凸で，n での値は F(n,S) に一致する．よって F(2..n,S) はその凸な列の制限．
F(1,S) = 1，F(2,S) = 3（S ≥ 2）で最初の増分は 2．以後の増分は併合の要素で，どれも 2 以上（I_{S−1} の要素は帰納法の仮定で 2 以上，J_S の要素は 4 以上）．
したがって F(1..n,S) も凸．有限域は G_S の域 2^{S−2} と F(·,S−1) の域 2^{S−2} の和 2^{S−1}．
基底: F(1,1) = 1，n ≥ 2 で F(n,1) = ∞（域 1 = 2^0）． ∎

*補題 M の証明.* しきい値 k ごとに c_S(k) = #{n : I_S(n) ≤ k} とおく．補題 M0 より，k ≥ 2 で c_S(k) = 1 + c_{S−1}(k) + #{m : J_S(m) ≤ k} ≥ c_{S−1}(k)．
列はどちらも非減少なので，I_{S−1}(n) = k なら c_{S−1}(k) ≥ n，よって c_S(k) ≥ n，すなわち I_S(n) ≤ k = I_{S−1}(n)．
F(·,S−1) の域 2^{S−2} を超える n では I_{S−1}(n) = ∞ とみなせば同じ．差分の形へは y から x まで和を取る（F(x,S−1) = ∞ なら左辺が ∞ で自明）． ∎

## 2. 補題 E（頂上だけに石がある鎖の森の厳密な手数）

**補題 E.** 長さ ℓ_1,…,ℓ_m の鎖の森 F* で盤 X が各鎖の頂上だけのとき，
  R^{F*}_S(X) = min_σ Σ_{j=1}^m F(ℓ_{σ(j)}, S − j + 1)（σ は鎖の並べ方）．
さらに補題 M により，最小は長い順（ℓ_{σ(1)} ≥ ℓ_{σ(2)} ≥ …）で達する．

*証明.* (≤) 鎖 σ(1) を頂上だけにし（F(ℓ_{σ(1)},S) 手．Knill の上界の構成），その石を残したまま鎖 σ(2) を予算 S−1 で，… と順に作る．
(≥) 最短の手順 π をとり，鎖 i の盤が空である最後の時刻を t_i とする（時刻 0 では全部空なので定まる）．t_i の小さい順に並べ（同じ値は任意の順），j 番目の鎖を σ(j) とする．
時刻 t_{σ(j)} より後では，σ(1),…,σ(j−1) の鎖の盤は空でない（それぞれの最後に空だった時刻は t_{σ(j)} 以前）．
したがって鎖 σ(j) の t_{σ(j)} より後の手は，その鎖だけで見て ∅ から {頂上} への手順で，盤の大きさはいつも S − (j−1) 以下．
Knill の向き（Lean `path_Fc_le`: 道の手順は F_c 以上）より，その手数は F(ℓ_{σ(j)}, S−j+1) 以上．鎖ごとの手は別々なので足せる．
（S − j + 1 ≤ 0 なら F = ∞ で，そのような π は無い．）
最小が長い順で達すること: 隣り合う j, j+1 で ℓ_{σ(j)} < ℓ_{σ(j+1)} なら，入れ替えると和は増えない（補題 M を T = S−j+1，x = ℓ_{σ(j+1)}，y = ℓ_{σ(j)} で使う）． ∎

## 3. 定理（予算一定の SORT）

**定理 SORT_const.** すべての鎖の森 F，各鎖の頂上に石がある盤 X，S で R^F_S(X) ≥ R^{1本}_S(sorted(X))．
したがって予算一定の GRAFT（R^Q_S = R^P_S）も成り立つ．

*証明.* 補題 D（`SORT.md` §2．各石の位置で切っても手数は増えない）で R^F_S(X) ≥ R^{F*}_S(X)．F* は区間の長さ s_1 ≥ … ≥ s_k の鎖で頂上だけに石．
補題 E より R^{F*}_S(X) = Σ_j F(s_j, S−j+1)（長い順）．
1 本の鎖の sorted(X) は区間を短い順に上から積んだ盤なので，一番下の区間が最長 s_1．一番下の区間（その頂上から鎖の終わりまで）を F(s_1,S) 手で頂上だけにし，
その石を残して，すぐ上の区間（最下の頂点の手は下の区間の頂上の石を要るが，それはある）を予算 S−1 で F(s_2,S−1) 手，… と作る．
手数は Σ_j F(s_j, S−j+1) で，R^{1本}_S(sorted(X)) はそれ以下． ∎

注: `SORT.md` §2 の命題（GRAFT ⇒ SORT）は使っていない．歩み（予算が相ごとに ±1 で変わる）の SORT は未解決のまま．
予算一定では森の側が補題 E で厳密に求まり，1 本の側は順に作る構成で上から押さえれば足りる．歩みでは森の側で鎖を同時に作る手順が速くなりうるので，この論法は通らない．
（1 本の側の厳密値は Σ_j F(s_j,S−j+1) より小さいことがある．支えの石を外して置き直す手順のため．`SHALLOW.md` §6 の「成り立たないもの」の 3 つ目．）

## 4. 系（蜘蛛型の木で予想 CC）

**系 S1'.** 根 u から長さ ℓ_1,…,ℓ_k の道（脚）が出る木 G（蜘蛛型．頂点数 n = 1 + Σℓ_i）とすべての S で M(G,S) ≥ M(P_n,S) = F_c(n,S)．

*証明.* 最短の手順 π（∅ → {u}）で u は 1 回だけ置かれ，外されない（`SHALLOW.md` 補題 S0 (i)）．補題 L（`PROOF.md` §3）を脚 k 本すべてに一度に当てる（証明は 2 本の場合と同じ．W = {u}）．
u を置く前は W の盤が空で脚の予算は S，置いた後は W の盤が {u} で脚の予算は S−1．u を置く瞬間の脚の盤 X は全脚の頂上を含み，|X| ≤ S−1．
π の脚への手は，前半が予算 S 一定で ∅ → X，後半が予算 S−1 一定で X → ∅ の手順なので，|π| ≥ 1 + R^F_S(X) + R^F_{S−1}(X)．
定理 SORT_const を両側に当てて，脚を 1 本につないだ鎖 Q（u の下に長さ n−1 の 1 本の道．すなわち P_n）の盤 Y = sorted(X)（|Y| = |X|，頂上 v_0 に石）で
R^Q_S(Y) ≤ R^F_S(X)，R^Q_{S−1}(Y) ≤ R^F_{S−1}(X)．P_n で「前半で Y を作り，u を置き，後半で Y を消す」手順は合法（u の手は v_0 を要るだけ）で，
手数は 1 + R^Q_S(Y) + R^Q_{S−1}(Y) ≤ |π|．よって M(P_n,S) ≤ M(G,S)．M(P_n,S) = F_c(n,S) は Knill の定理（≥ は Lean `path_Fc_le`）． ∎

これは `SHALLOW.md` 命題 S1 を 2CM_1 なしで示したもの．脚を 2 本ずつ併合すると文脈に他の脚が入って予算が歩みになるが，全部を一度に併合すると文脈は u だけで予算は一定になる．
命題 S2（深さ 2 以上で枝分かれしない木）と一般の木は，文脈に他の部分木が残るので歩みの SORT（または 2CM_2）が要り，未解決のまま．
系 LI の毛虫型とは別のクラス（長さ 2 以上の脚が 3 本以上ある蜘蛛は毛虫型でない）．
