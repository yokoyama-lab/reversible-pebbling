## 0. 定義

- 森 Φ（辺は子から親へ）．頂点 v を置く手・外す手は，v の子がすべてペブル済みのときだけ合法．
  盤 X ⊆ V(Φ)．常に |盤| ≤ B で盤 X から盤 Y へ移る最短手数を d^Φ_B(X,Y) と書く（無ければ ∞）．
  手は可逆なので d(X,Y) = d(Y,X)．木 G（根 r）について M(G,S) = d^G_S(∅,{r})．
- F_c は鎖の Knill の再帰（p5/lb/PROOF.md §0）．Knill の定理（Thm 2.1）により F_c(n,S) = M(P_n,S)（P_n は n 頂点の道）．
  （Lean: `reversible-pebbling-lean` の無条件版 `Unconditional.gameF_eq_Fpre_uncond`（`GameDecomposition.gameF_eq_Fpre` は仮定
  `GameAttain` つき）．critic が名前と所在を grep で確認．本セッションではビルドしていない．）
- 予想 CC: すべての根付き木 G とすべての S で M(G,S) ≥ F_c(|G|,S)．
- 削除補題（p5/fm/PROOF.md 補題 2）: D が下に閉じた集合，U = V − D で，合法な手順のある時刻 t' に盤 ∩ U = ∅ なら，
  t' より前の U への手をすべて消しても合法で，各時刻の盤は大きくならない．
- 盤 X の**領域**: x ∈ X について R_x = {v : v の祖先（v 自身を含む）のうち X に入る最も近いものが x}．
  X の下に無い頂点はどの領域にも入らない．
- Φ/C: 森 Φ から C の頂点を除いた森（C の頂点はずっとペブル済みとみなすので，親の要求からも消える．
  親が C に入る頂点は根になる）．

## 1. 補題 D（多目標の距離の分解）

**補題 D.** 森 Φ，空でない盤 C（k = |C|），予算 B について
  d_B(∅,C) = 1 + min_{c,P} [ d^Φ_B(∅,P) + d^{Φ/C}_{B−k}(∅, P∖C) ]．
最小は c ∈ C と，c ∉ P，P ⊇ (C∖{c}) ∪ ch(c)，|P| ≤ B−1 を満たす盤 P の組にわたる．

*証明.* (≥) 最短の手順 π（長さ d < ∞）をとる．各 c ∈ C について，c への最後の手の時刻 t_c をとる（最後の盤に c があるので
その手は置く手）．t_c が最大の c を c* とし，その手の直前の盤を P とする．c* ∉ P，置く手なので ch(c*) ⊆ P，|P| + 1 ≤ B．
c ∈ C∖{c*} は t_c < t_{c*} の後に動かないので c ∈ P．t_{c*} より後は C のどの頂点も動かない．
したがって後半の手はすべて C の外の頂点への手で，C の頂点は後半ずっと盤にある．C の外の頂点 v の手の合法性は
v の C の外の子だけで決まる（C の子はずっとある）ので，後半は Φ/C の手順で，C の外の盤は P∖C から ∅ へ移り，
盤には C の k 個が常にあるので C の外は B−k 個以下．逆再生すれば d^{Φ/C}_{B−k}(∅,P∖C) 以上．前半は ∅ から P への
予算 B の手順．よって d ≥ (t_{c*} − 1) + 1 + (d − t_{c*}) ≥ d_B(∅,P) + 1 + d^{Φ/C}_{B−k}(∅,P∖C)．
(≤) ∅ から P へ最短に（予算 B），c* を置く（ch(c*) ⊆ P，|P|+1 ≤ B），C を持ったまま Φ/C の ∅ → P∖C の最短手順を逆に
たどる（盤は C の k 個と C の外の B−k 個以下．合法性は上と同じ理由）．終わりの盤は C． ∎

数値: 森の全数（頂点数 ≤ 8，すべての C，B）で左辺（Φ の BFS）と右辺（Φ と Φ/C の BFS）が一致（`decomp_check.c`，
403,883 組．不一致 0）．

## 2. 予想 GCC と CC への帰着

**Ψ.** 盤 X の領域の頂点数を大きい順に m_1 ≥ … ≥ m_k とし，Ψ_B(X) = Σ_{i=1}^{k} F_c(m_i, B−i+1)（予算 ≤ 0 の項は ∞）．

**予想 GCC.** すべての森 Φ，盤 X，予算 B で d^Φ_B(∅,X) ≥ Ψ_B(X)．
（X = {根} の 1 成分の森ではこれが CC そのもの．X の下に無い頂点は削除補題で消せるので，X が各成分の根を含む場合に帰着する．）

**命題 2.1（GCC ⇒ CC）.** GCC が森 G−r で成り立てば，木 G について M(G,S) ≥ F_c(|G|,S)．

*証明.* n = |G| ≥ 2，M(G,S) < ∞ とする．p5/fm の補題 3 により，ch(r) ⊆ C ⊆ V−{r}，|C| ≤ S−1 のある C で
M(G,S) = 1 + d_S(∅,C) + d_{S−1}(∅,C)（距離は森 G−r の上）．G−r の頂点はすべて ch(r) ⊆ C の元の下にあるので，
C の領域は V−{r} を分割し，大きさ m_1 ≥ … ≥ m_k（k = |C| ≤ S−1）の和は n−1．GCC を 2 回使い
  M(G,S) ≥ 1 + Σ_{i=1}^{k} [F_c(m_i,S−i+1) + F_c(m_i,S−i)]．
右辺 ≥ F_c(n,S) を k の帰納法で示す: F_c の再帰で分割点を m_1 にとると F_c(n,S) ≤ F_c(m_1,S) + F_c(m_1,S−1) + F_c(n−m_1,S−1)
（1 ≤ m_1 ≤ n−1）．n − m_1 = 1 + Σ_{i≥2} m_i なので，k = 1 なら F_c(1,S−1) = 1（S−1 ≥ k ≥ 1），k ≥ 2 なら
S−1 と k−1 個の部品で帰納法の仮定を使う． ∎（順序は大きい順でなくても成り立つ．F_c の点ごとの支配は使わない．）

**数値（GCC）**: すべての森（頂点数 ≤ 14），すべての盤 X（各成分の根を含むもの），すべての B で破れ 0
（頂点数 ≤ 9: 1,238,833 点，10〜12: 223,645,111 点，13: 1,056,076,203 点，14: 6,034,495,810 点．`gcc_check.c`．
右辺の m を m+1 にした変異は頂点数 ≤ 9 の範囲で 579,955 点で破れる）．頂点数 15（34,551,905,625 点）も破れ 0（op．`out/op/gcc_13_15.txt`）．

### 2.1 GCC を補題 D の帰納法で示す試み（届かない）

補題 D と，手順の長さについての帰納法を使えば，GCC は次の不等式から従う:
  **INEQ**: 補題 D の条件を満たすすべての (C,c,P,B) で 1 + Ψ_B(P) + Ψ^{Φ/C}_{B−k}(P∖C) ≥ Ψ_B(C)．
（前半・後半の距離は元より短い手順なので帰納法の仮定が使える．k = 1，C = {根} のときは命題 2.1 の計算そのもの．）

- **INEQ は偽**．最小の破れは頂点数 5: 孤立点 z と長さ 4 の鎖（頂 t），C = {z,t}，B = 3，c = z，P = {t, 鎖の底}．
  Ψ_3(P) = F_c(3,3)+F_c(1,2) = 6 だが d_3(∅,P) = 8．1 + 6 + 1 = 8 < 10 = Ψ_3(C)．この P は**最適な分解**でもある
  （1 + 8 + 1 = 10 = d_3(∅,C)）．原因: Ψ は入れ子の領域（底の 1 点の上に 3 点の領域）を独立とみなし，下の領域に依存する
  上の領域にも大きい予算を割り当てる．
- 最適な分解のうち INEQ を満たすものを選べるか: 頂点数 ≤ 7 では毎回選べるが，**頂点数 8 で選べない組がある**
  （例: 森 `[-1,0,0,2,0,4,4,6]`（親の配列），C = {0,5}，B = 4．最適な分解は c = 5，P = {0,4,6} の 1 つだけで，
  Ψ_4(P) = 13 に対し d_4(∅,P) = 19．`decomp_check.c` の cls0 NOGOOD 8 組）．
- 予算を緩めた仮説 Ψ^{(a,b)}_B(X) = Σ F_c(m_i, aB+b−i+1)（a, b は定数．CC の代わりに M(G,S) ≥ F_c(|G|, aS+b) を与え，
  a = 1 でも b を定数にすれば指数 1.3317，a = 2 でも 1.2145 が出る）でも INEQ は偽: 鎖の長さ L と孤立点，P = {頂, 底}，
  L > aB+b なら破れる（`ineq_counter.py` で L=16, B=6, (a,b)=(2,0),(2,1) と L=20,(3,0) を BFS で確認．しかもこれらは最適な分解）．
  **大きさだけで決まる下界を仮説にする限り，分解の P が入れ子になると前半の下界が真の値から大きく外れる．**
- 鎖への並べ方の下界 L_B(X)（領域を線形拡大の順に下から並べた鎖の多目標の距離の最小．入れ子を見る）では，
  予想 GCC-arr（d ≥ L）は頂点数 ≤ 8 の森で破れ 0（403,883 点中 396,574 点が等号）．INEQ-arr は実現可能な P でも
  頂点数 8 で破れる（例: 森 `[-1,-1,1,1,3,1,5,5]`，B = 4，C = {0,1,3}，c = 0，P = {1,2,3}．L(P) = 15，d(P) = 23．領域が枝分かれしている
  ことを L が見ないため）．ただし頂点数 ≤ 8 では「|P| が最小の最適な分解」はすべて INEQ-arr を満たした．
  これを仮説にできる形（大きさと順序だけで判定できる P の性質）は見つかっていない．

## 3. 脚の併合への帰着（本稿の主な帰着）

**脚.** 頂点 u の子 c の部分木が道（各頂点の子が高々 1 個）のとき，それを u の脚と呼ぶ．長さはその頂点数．

**操作 legmerge(u; A, B).** u の 2 本の脚 A（頂 A_0，…，底 A_{a−1}）と B（頂 B_0，…，B_{b−1}）について，
B_0 の親を u から A_{a−1} に替える（A の下に B をつなぎ，長さ a+b の 1 本の脚にする）．頂点数は変わらない．

**補題 L（文脈から見た脚の問題）.** 木 G，u の 2 本の脚 A, B，W = V ∖ (A ∪ B)（u を含む）．
G の任意の合法な手順 π（予算 S，∅ → {r}）について，W への手を順に w_1,…,w_K とし，w_j と w_{j+1} の間の脚への手を
「相 j」とする（相 0 は w_1 の前，相 K は w_K の後）．相 j の間の W の盤の大きさを c_j として β_j = S − c_j とおく．
w_j = u（u への手）である j の直前（相 j−1 の終わり）を「境目」とする．このとき，π の脚への手の列は次の
「2 本の鎖の問題」の実行可能解で，手数は π の脚への手の数に等しい:
  2 本の独立な鎖 A, B（底は自由．鎖の頂点 v の手は鎖の中の子があるとき合法），初めと終わりは空，
  相 j の間は 2 本の盤の大きさの和 ≤ β_j，各境目で A_0 と B_0 が盤にある．
逆に，併合した木 G' = legmerge(G; u; A, B) で同じ W の手を同じ順に打ち，相 j の脚への手を
「1 本の鎖（A の下に B）の問題」（相 j の間は盤の大きさ ≤ β_j，各境目で A_0 が盤にある，初めと終わりは空）の
実行可能解の相 j の手に替えたものは，G' の合法な手順（予算 S，∅ → {r}）である．

*証明.* 脚の頂点の子は脚の中にあるので，脚への手の合法性は W の盤によらない（G でも G' でも．G' では A_{a−1} の子が B_0）．
W の頂点のうち子が脚に入るのは u だけ（G では A_0 と B_0，G' では A_0）．したがって W への手 w_j の合法性は，
w_j ≠ u なら脚の盤によらず，w_j = u なら G では A_0, B_0，G' では A_0 が盤にあることと同値．予算: 相 j の間の盤の大きさは
c_j + （脚の盤）≤ S ⟺ 脚の盤 ≤ β_j．手 w_j の瞬間の盤は相 j−1 の終わりと相 j の初めの盤の大きい方以下なので，両側の相の
予算の条件で押さえられる．r ∈ W（r は u またはその祖先）なので，初めと終わりの脚の盤は空． ∎

**予想 2CM（2 本の鎖の併合）.** 長さ a, b ≥ 1，任意の J，任意の予算の列 β_0,…,β_{J−1} と境目の集合について，
OPT_1本(A の下に B) ≤ OPT_2本．

**定理 R（2CM ⇒ legmerge の単調性 ⇒ CC）.**
(i) 2CM(a,b) が成り立てば，長さ a, b の脚を持つすべての木 G（文脈は任意）とすべての S で M(legmerge(G),S) ≤ M(G,S)．
(ii) すべての a, b ≥ 1 で 2CM(a,b) が成り立てば CC が成り立つ．
(iii) 完全二分木については，a = b = 2^k − 1（k = 2,…,h−1）の 2CM だけで CC_T(h) が従う．

*証明.* (i) 最短の手順 π を補題 L で 2 本の鎖の問題の解とみなし，2CM で手数が多くない 1 本の解に替え，補題 L の後半で
G' の手順に戻す．W の手の数は同じなので M(G',S) ≤ |π|．
(ii) 道でない木 G には，子を 2 個以上持つ頂点のうち，それより下に子を 2 個以上持つ頂点が無いもの u がある．u の子の部分木は
すべて道（脚）なので，2 本を (i) で併合すると M は増えず，葉の数が 1 減る．葉が 1 枚（道）になるまで繰り返すと
M(G,S) ≥ M(P_n,S) = F_c(n,S)（Knill の定理）．
(iii) T_h を下から変形する: 高さ 2 の部分木（u と葉 2 枚）は (1,1) の併合で道 P_3 になる（§4 の補題 LI で無条件）．
高さ k+1 の部分木は，子 2 つがすでに長さ 2^k − 1 の道になっているので，(2^k−1, 2^k−1) の併合で道 P_{2^{k+1}−1} になる． ∎

注: 補題 L の 2 本の鎖の問題は文脈を予算の列と境目に縮めたもので，2CM は**鎖だけの主張**である（ただし時間とともに変わる
予算と境目つきで，Knill の理論（予算一定・目標 1 つ）の範囲の外にある）．
2CM は任意の予算の列を量化しており，要るものより強い．補題 L が作る列は「隣り合う相で β が ±1 だけ動き，境目では u の手の
置く／外すに応じて符号が決まる」ものに限られるので，定理 R はこの列に限った弱い版 2CM_real で足りる．
また 2CM は「先読みなしの 1 手ずつの模倣」では示せない（§5(c)）．

**障壁との関係（critic の指摘を反映）.** 補題 L と定理 R (i) は Ghost の有無を使わない（spooky の模型でも脚の手は脚だけで，u の手は
A_0, B_0 の存在だけで決まるので，同じ帰着が「spooky 版 2CM ⇒ spooky でも鎖がいちばん速い」として成り立つ）．可逆性が効くのは，
最後に使う Knill の定理 M(P_n,S) = F_c(n,S) と鎖の下界 F_c ≥ n^{1.33} の側である．spooky の鎖は O(log n) 個で
O(n log n/log log n) 手で済むとみられる（KSS arXiv:2110.08973 の要旨による．本文は未確認）ので，spooky 版 2CM が成り立っても
Lee–Lee–Jeong の結果とは矛盾せず，帰着全体は障壁と衝突しない．

## 4. 示せた特別な場合

**補題 LI（葉の差し込み）.** 頂点 u が葉の子 t と別の子 c（部分木は任意）を持つとき，t を u と c の間に差し込んだ木
G'（t の親は u，c の親は t）について，すべての文脈と S で M(G',S) ≤ M(G,S)．

*証明.* 最短の手順 π をとる．t は葉なので，t の存在に依存するのは u の手だけ．t がある極大の区間 [p,q)（p で置き q で外す）が
u の手を 1 つも含まなければ，その 2 手を消しても合法で短くなるので，最短の π ではどの区間も u の手を含む．
区間の中の最初と最後の u の手を u_f, u_l とし，π' では t を u_f の直前に置き，u_l の直後に外す（区間は縮むだけ）．
他の手は同じ．合法性: G で u の手は c を要るので，u_f の直前と u_l の直後には c が盤にあり，G' で t の手が合法．
G' の u の手は t を要る（c は要らない）: [u_f,u_l] では t があるので合法．c とその下の頂点の手の合法性は子だけで決まり
変わらない．盤は各時刻で π のもの以下．手数は同じ． ∎

これは 2CM の a = 1（A が 1 点）の場合を，B が任意の部分木でも示したものになっている．

**系 LI.** 各頂点の「葉でない子」が高々 1 個の根付き木（根から下る 1 本の道に葉が付く木．子の数は任意）では，
すべての S で CC が成り立つ．
*証明.* 葉でない子 c を持つ頂点 u の葉の子をすべて LI で c の上に差し込み，葉の子しか持たない頂点（星）では葉を 1 枚ずつ
別の葉の上に差し込む．下から順に行うと道になり，M は増えない． ∎

**定理 T3（根の子がちょうど S−1 個）.** G の根の子が S−1 個で，各子の部分木 T_c がすべての予算 s で
M(T_c,s) ≥ F_c(|T_c|,s) を満たすなら M(G,S) ≥ F_c(|G|,S)．
*証明.* p5/fm の定理 5 により M(G,S) = 1 + min_σ Σ_i M(T_{σ(i)},S−i+1) + min_τ Σ_i M(T_{τ(i)},S−i)．仮定で各項を F_c に
下げる．鎖の点ごとの支配 δ(m,s) ≤ δ(m,s−1)（RevExact の Lean `CountRecursion.gen_pointwise_dom`．p5/fm の系 6' の証明と
同じ交換の議論）により，Σ_i F_c(m_{σ(i)}, s−i+1) は大きい順の σ で最小になるので，σ と τ の最小は同じ順でとれる．
すると命題 2.1 の後半の計算で ≥ F_c(|G|,S)． ∎
（p5/fm の F ≠ M の族（命題 7 の族，鎖・星・葉の族）はすべてこの形で，子の部分木が各頂点の葉でない子が高々 1 個の木（系 LI）なので，
子について CC が成り立ち，T3 で CC が成り立つ．）

## 5. 試して駄目だったこと（詳細）

(a) **GCC の補題 D による帰納法**: §2.1．Ψ でも，予算を何倍に緩めた Ψ でも INEQ は偽（入れ子の P）．並べ方の下界 L では
実現可能だが最適でない P で偽．

## 6. 2CM の計算機援用の決定（先読みあり．小さい a, b）

`closure.py`: 2 本の問題と 1 本の問題の動的計画法のベクトル (D2, DM)（各盤にいる最小手数）を，同じ相の作用
（予算 β の min-plus の作用，境目では頂を含まない盤を ∞ に）で同時に進める．どの相の後で終わってもよいので，
到達しうるすべての組で DM(∅) ≤ D2(∅) なら，任意の長さの任意の予算の列と境目で 2CM(a,b) が成り立つ．
両方から同じ定数（D2 の有限な値の最小）を引いて正規化する（min-plus の作用は定数のずらしと可換）．
DM の値は −K 未満を −K に，K 超を ∞ に丸める．これは DM を上げる方向（味方に不利）だけなので，min-plus の作用の単調性により
丸めた系の DM は真の DM 以上で，丸めた系で DM(∅) ≤ D2(∅) なら真の系でも成り立つ．D2 は丸めない．
到達しうる正規化された組の集合が有限で閉じれば，2CM(a,b) が決まる（幅優先で閉包を作る．閉じた集合を保存して別の検査器を付ければ証明書になるが，未実施）．

結果: (1,1) 250 組，(1,2) 2,332 組，(2,2) 4,950 組，(2,3) 101,651 組（以上 K = 40），(1,3) 13,116，(1,4) 179,458（K = 60），
(2,4) 1,629,188（K = 80），(3,3) 3,186,418（K = 80，K2 = 240）で閉じ，すべて DM(∅) − D2(∅) ≤ 0（`out/op/closure_runs.txt`）．
(1,b) は補題 LI の論法で任意の b について紙で出るので，ここで新しいのは (2,2)，(2,3)，(2,4)，(3,3) の 4 組．
**(2,3)，(3,3) は先読みなしの模倣では負けるが（§5(c)），先読みありでは任意の長さの任意の予算の列で 2CM が成り立つ**（計算機援用．
コードの正しさに依存．critic が (2,3) までを別のコードで再実装して状態数まで一致）．
完全二分木については，(iii) に要る (3,3) は CC_T(3) にしか効かず（既知），(7,7) 以降は未確認なので，**CC_T(h) について §6 から

(3,3) は丸め無しでは状態が線形に増え続けた（正規化した D2 の一部の値が際限なく増える列があるとみられる）ので，K2 = 240 で再実行している．
なお 1 本の側は長さ a+b の鎖という同じ物なので，2CM(a,b) と 2CM(b,a) は同じ主張．
