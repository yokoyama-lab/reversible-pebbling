## 4. 「保持できるなら保持が最適」（2026-11-01）

**記号.** 境目 t1 < t2，間の相の予算の最小を m とする．脚の頂上をすべて含み |Y| ≤ m の盤 Y を「保持できる盤」，
hold = min_Y [pre(Y) + post(Y)]（pre は ∅ から Y，post は Y から ∅．どちらも定理 W の値）とおく．

**命題 H（予想 → 偽．§5）.** 保持できる盤があって hold が有限なら，森の最短手数 = hold（間で脚の手 0 の解が最適）．

sorted(Y) は一番上の v_0 を含み，大きさは |Y| なので境目の瞬間と間の予算に収まる．よって OPT_1本 ≤ hold = OPT_森．

**次.** 間の扱いは「保持」ではなく「谷まで崩して戻す」形で比べる必要がある．

Z は頂上を含まないことがあるので，定理 W を「頂上を含まない盤で終わる」形に広げる必要がある．

### 6.2 谷で切る形

境目 p，q の 2CM_2 の列で，間の相 p, …, q−1 のうち予算が最小の相を r とする．森の手順を相 r のある時刻で切ると，その時刻の盤 Z について

- 前半: ∅ から境目 p（森は全頂上，1 本は v0）を経て相 r で Z に至る．最短を A_w(Z)（w = β_0, …, β_r）とおく．
- 後半: 逆にたどると同じ形になる（手は可逆）．歩みは β_{J−1}, …, β_r で，境目 q は予算が 1 下がる切り替えになる．

どちらの歩みも「最後の相の予算が，境目より後の相の予算の最小」という条件（谷の条件）を満たす．

**主張 VC（歩みによらない形）.** 森の盤 Z ごとに 1 本の盤 g(Z) があって，谷の条件を満たすすべての歩みで A^{1本}_w(g(Z)) ≤ A^{森}_w(Z)．

**VC ⇒ 2CM_2（紙の論法．独立の検算は未）.** 森の最短の手順を相 r で切った盤を Z とすると，OPT^森 ≥ A^森_{w前}(Z) + A^森_{w後}(Z)．1 本の側で，前半の最短手順（g(Z) で終わる）と後半の最短手順の逆（g(Z) から始まる）をつなぐと合法で（相 r の中ではどちらも盤 ≤ β_r），OPT^{1本} ≤ A^{1本}_{w前}(g(Z)) + A^{1本}_{w後}(g(Z)) ≤ OPT^森．
2CM_2 に要るのは，その列の 2 つの歩みについて両方を支配する 1 本の盤があること（主張 VC2，下）までで，VC はそれより強い．

### 7.2 規則 S

森の盤 Z の各脚 i について，頂上の空き t_i（一番上の石より上の空いた頂点の数．石が無ければ ℓ_i）と区間（石から次の石の手前まで，最後の石は脚の底まで）をとる．
**S(Z)** = 長さ Σℓ の 1 本の鎖で，一番上に τ = Σ_i t_i 個の空き，その下に全区間を短い順に並べ，各区間の先頭に石を置いた盤．

Z が全脚の頂上を含むとき（τ = 0）S(Z) は定理 W の sorted(Z) と一致する．S は sorted を頂上の空いた盤へ広げたもの．

**予想 VC2-S.** 2CM_2 規則版の各列で，間の予算が最小のどの相 r と，そこでのどの最適な切り口 Z についても，

### 8.1 §7.5 の訂正: τ = 0 は定理 W そのものではない

### 8.5 帰着（紙の論法）

**命題.** 2CM_2 の列に，全頂上を含み脚の中で整列した最適な切り口 Z があれば，G0s（一般の主張として）からその列で 2CM_2 が成り立つ．
*論法.* 前半の片側の歩み（β_0, …, β_r，境目 p で −1）と後半の片側の歩み（β_{J−1}, …, β_r，境目 q は逆向きでは −1）は，どちらも落差と谷の条件を満たす（r は間の予算が最小の相）．
G0s（≤ の向き）を両側に当てると A^{1本}_{w前}(sorted Z) ≤ A^森_{w前}(Z)，後半も同じ（sorted Z は Z だけで決まるので両側で同じ盤）．§6.2 の「VC ⇒ 2CM_2」と同じく，1 本の側で前半の最短手順と後半の最短手順の逆を sorted(Z) でつなぐと合法で，OPT^{1本} ≤ OPT^森． ∎

8.3 の表では，全頂上を含む整列した最適な切り口がある列が大半（たとえば (4,4) で 12,493 列中 12,187 列）なので，G0s が示せればそれらの列の 2CM_2 は閉じる．
残りの列（頂上の空いた最適な切り口しか整列していないもの）は，頂上の空きを含む形（§7 の S）の議論が要る．τ > 0 では脚の中で整列していても歩みによらない形は偽（§6.2 の (4,6)，Z = {A0, B1}）．
