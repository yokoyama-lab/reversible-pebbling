# 予算が動く場合の SORT（2026-10-31）

`CONST.md` の続き．ユーザーの選択「3 実施して」（予算が時間とともに変わる場合の SORT）による．
層: §1〜§3 は紙の証明（層 2，未検算）．§4 の数値は有界の全数検査（`walk/`）．
使う外部の結果は `CONST.md` と同じ 2 つ（Knill の下界の向き〔Lean `path_Fc_le`〕と構成の向き〔紙，古典的〕）と，補題 M（Lean `P5TreeFcConvex.lean`）．

記号: 歩み w = (β_0, …, β_J)．相 k では盤 ≤ β_k，相 k から k+1 への切り替えの瞬間の盤 ≤ min(β_k, β_{k+1})（`SORT.md` §1）．
以下の証明は「隣り合う予算の差が ±1」を使わない．F(n,T) は Knill の再帰（T ≤ 0 なら ∞）．

## 0. 歩みから決まる数

j ≥ 1 について
- p_j = β_k ≤ j−1 となる最後の相 k（無ければ −1），
- 後半 A_j = {k : k > p_j}（相の後ろの区間．A_1 ⊇ A_2 ⊇ …．A_j の相ではどれも β ≥ j），
- m_j = max_{k ∈ A_j} β_k（A_j が空なら −∞），T_j = m_j − (j−1)．

m_1 ≥ m_2 ≥ … なので T_{j+1} ≤ T_j − 1．

**主張（定理 W）.** 長さ s_1 ≥ s_2 ≥ … ≥ s_k の鎖の森 F*（盤は各鎖の頂上だけ）と，長さ Σs_j の 1 本の鎖の盤 sorted（区間を上から短い順，すなわち下から s_1, s_2, …）について，
すべての歩み w で
  R^{F*}_w(頂上) = R^{1本}_w(sorted) = Σ_j F(s_j, T_j)．
特に（補題 D と合わせて）予想 SORT（`SORT.md` §1）がすべての歩みで成り立つ．

1 本の鎖（k = 1）では R_w({頂上}) = F(s_1, T_1)，すなわち歩みのもとで 1 本の鎖を作る最短手数は「最後に予算が 0 になった後の最大の予算」で一定にしたときの値に等しい．

## 1. 下界（森の側）

**補題 W1.** R^{F*}_w(頂上) ≥ min_σ Σ_j F(s_{σ(j)}, T_j)．

*証明.* 最短の手順 π をとる．鎖 i の盤が空である最後の時刻を t_i とする．t_i の直後の手は鎖 i に石を置く手なので t_i は互いに異なる．小さい順に並べて j 番目を σ(j) とする．
t_{σ(j)} より後のすべての時刻で，鎖 σ(1), …, σ(j) の盤はそれぞれ 1 個以上（各鎖は最後に空だった時刻より後はずっと空でない），よって盤全体は j 個以上．
t_{σ(j)} の次の手を含む相を k_0 とする．相 k_0 以降の各相は t_{σ(j)} より後の盤を少なくとも 1 つ含む（相の初めの盤は切り替えの瞬間の盤で，それも相の制約を受ける）ので，その相の β は j 以上．
したがって相 k_0 以降はどれも A_j に入り，t_{σ(j)} より後の鎖 σ(j) の盤は β_k − (j−1) ≤ m_j − (j−1) = T_j 以下．
鎖 σ(j) の t_{σ(j)} より後の手は，その鎖だけで見て ∅ から {頂上} への合法な手順（盤の最大 ≤ T_j）なので，Knill の下界の向きにより F(s_{σ(j)}, T_j) 手以上．鎖ごとの手は別々なので足せる． ∎

**補題 W2（長い順が最小）.** T > T′ と x ≥ y ≥ 1 で F(x,T) + F(y,T′) ≤ F(y,T) + F(x,T′)．したがって T_1 > T_2 > … のもとで min_σ Σ_j F(s_{σ(j)}, T_j) は長い順で達する．

*証明.* T′ ≤ 0 なら右辺が ∞（F(x,T′) = ∞）．T′ ≥ 1 のとき補題 M（Lean `Fc_diff_mono`: F(x,U+1) + F(y,U) ≤ F(y,U+1) + F(x,U)）を U = T′, …, T−1 で足す．
途中の項 F(x,U)，F(y,U)（T′ < U < T）は両辺に 1 回ずつ現れて消える（∞ になりうるのは F(·,U) で U が小さいときだけで，そのとき F(x,T′) = ∞ で右辺が ∞．
正確には F(x,U) が有限なら U 以上のすべての F(x,·)，F(y,·) が有限なので，F(x,T′) が有限な場合は途中の項がすべて有限で，打ち消してよい）．
隣り合う j, j+1 で s_{σ(j)} < s_{σ(j+1)} なら入れ替えて和は増えない（T = T_j > T′ = T_{j+1}）． ∎

## 2. 上界（1 本の鎖の側）

**補題 W3.** R^{1本}_w(sorted) ≤ Σ_j F(s_j, T_j)（s_1 ≥ s_2 ≥ …，区間 j は下から j 番目）．

*証明.* 右辺が有限とする（すべての j で T_j ≥ 1，A_j は空でない）．k_j = A_j の中で β = m_j となる最後の相，とおく．

(a) k_1 ≤ k_2 ≤ …．m_{j+1} = m_j のとき: A_{j+1} ⊆ A_j で，m_j の値は A_{j+1} の中でも取られるので，A_j の中で m_j を取る最後の相は A_{j+1} の中にあり，k_{j+1} = k_j．
m_{j+1} < m_j のとき: A_j の中で m_j を取る相はどれも A_{j+1} の外，すなわち p_{j+1} 以下（A_{j+1} は後ろの区間）にあるので，k_j ≤ p_{j+1} < k_{j+1}．

(b) 手順: 区間 j = 1, 2, … の順に，相 k_j の中で区間 j を空から「頂上だけ」にする（Knill の構成，盤の最大 T_j，F(s_j, T_j) 手）．k_j が等しい区間は同じ相の中で番号順に続けて作る．
- 区間 j の一番下の頂点の手は，すぐ下の区間 j−1 の頂上の石を要るが，区間 j−1 は k_{j−1} ≤ k_j の相（同じ相なら先）で作り終えて頂上を残しているのである（j = 1 では鎖の一番下で，いつでも打てる）．
- 区間 j を作る間の盤は（下の j−1 個の頂上）+（区間 j の盤）≤ (j−1) + T_j = m_j = β_{k_j}．
- 区間 j を作り終えた後は j 個の石を持ち続ける．相 k_j 以降はどれも A_j に入る（A_j は後ろの区間で k_j ∈ A_j）ので β ≥ j で，切り替えの瞬間も両側が j 以上．
- 相 k_1 より前は盤が空（β ≥ 0）．最後の相の終わりの盤は sorted．
手数は Σ_j F(s_j, T_j)． ∎

## 3. 定理 W と系

*定理 W の証明.* 補題 W1，W2 で R^{F*}_w ≥ Σ_j F(s_j,T_j)（長い順），補題 W3 で R^{1本}_w(sorted) ≤ 同じ和．
さらに 1 本の鎖を補題 D で区間ごとに切ると F*（長い順に並べ直しても森は同じ）なので R^{1本}_w(sorted) ≥ R^{F*}_w ≥ Σ．
森 F* の側も W3 と同じ手順（区間の代わりに鎖，支えは不要）で Σ に届くので等号． ∎

**系.**
1. 予想 SORT（`SORT.md` §1）: すべての森 F，各鎖の頂上に石がある盤 X，すべての歩み w で R^F_w(X) ≥ R^{F*}_w(X) = Σ ≥ R^{1本}_w(sorted(X))（補題 D と定理 W）．
2. 補題 GRAFT（D の区間が短い順）: SORT の特別な場合（`SORT.md` §2 の同値）．D の区間の並びが任意の GRAFT は，Q の盤が sorted でないので従わない（未解決のまま．数値では破れ 0）．
3. 2CM_1(a,b) がすべての a, b で成り立つ（`SHALLOW.md` §3 の論法．φ_sort は歩みによらない）．蜘蛛型の木の CC は `CONST.md` の系 S1' で既に予算一定から出ていたので，CC の範囲は広がらない．
4. 1 本の鎖の中の並べ替えは，すべての歩みで手数を増やさない（F を 1 本として系 1）．

**範囲の注意（量化子）.** 定理 W は「∅ から盤へ」の比較で，途中の盤を指定しない．予想 CC の帰着で深さ 2 以上の頂点 u（手が 2 回以上）を扱うには，
u の各手の瞬間に脚の頂上がすべてある「盤から盤へ」の移動を比べる形（2CM_k，k ≥ 2）が要り，定理 W からは直接は出ない．
1 本に併合した側では u の手が要るのは一番上の v_0 だけなので，森の側より制約が弱い点が手がかりになる．
