# 予想 SORT と補題 GRAFT（2026-10-31）

`SHALLOW.md` §6 の続き．ユーザーの選択「1 と 2」（1: 1 本の鎖の中の並べ替えを先に証明する．2: φ_sort の独立の検算）のうち 1 の記録．
層: §2 の帰着は紙の証明（層 2．saikensha の独立検算〔2026-10-31〕で補題 D・C，命題，同値とも確認）．§3 の数値は計算機援用の決定（閉包．閉じた集合は保存していないので証明書ではない）．GRAFT の一般の証明は無い．

## 1. 定義

- 鎖の森 F: 長さ ℓ_1,…,ℓ_m の鎖を並べたもの．鎖の頂点は頂上から v_0,…,v_{ℓ−1}，v_i（i<ℓ−1）の手は v_{i+1} に石があるときだけ，源 v_{ℓ−1} はいつでも．
- 予算の歩み w と R^F_w(X) は `SHALLOW.md` §3 と同じ（相ごとの予算は ±1 で変わり，切り替えの瞬間の盤は両方の予算以下．∅ から始めて最後の相の終わりに盤 X にいる最小の手数）．
- 盤 X は各鎖の頂上に石があるとする．各石から下へ次の石の手前（または鎖の終わり）までが区間．区間の長さの多重集合を seg(X) と書く．
- sorted(X): 長さ ℓ_1+…+ℓ_m の 1 本の鎖で，seg(X) を短い順に上から積んだ盤．

**予想 SORT.** すべての森 F，盤 X，歩み w で R^F_w(X) ≥ R^{1本}_w(sorted(X))．

2 本で X ∋ A0, B0 の場合が 2CM_1 の写像 φ_sort（`SHALLOW.md` §6）．1 本の場合は「1 本の鎖の中では区間を短い順に並べた盤が最も速い」．

**補題 GRAFT（予想）.** 長さ c の鎖 A（盤 {A_0}）と鎖 D（盤 Z_D，区間はすべて c 以上）の 2 本の森 P と，A を D の上につないだ 1 本 Q（A_{c−1} の手に D_0 が要る）について，
すべての歩み w で R^Q_w({A_0} ∪ Z_D) ≤ R^P_w({A_0} ∪ Z_D)．
（Q の手は P の手の一部なので逆向きの不等式は自明．したがって GRAFT は「つなぐ制約はただ」という等式 R^Q_w = R^P_w を言う．）

## 2. 帰着（紙の証明）

**補題 D（切り離し）.** 森 F の盤 X について，X の各石の位置で鎖を切って区間ごとの鎖にした森を F* とすると，すべての w で R^{F*}_w(X) ≤ R^F_w(X)．
*証明.* 頂点集合と盤の大きさは同じで，F で合法な手は F* でも合法（切った位置の直上の頂点は F* では源になり，制約が無くなるだけ）．∎

**補題 C（文脈の吸収）.** 森 F = F_1 ⊔ F_2 と F' = F'_1 ⊔ F_2（F_1 と F'_1 の頂点数は証明で使わない）で，F_1 の盤 x と F'_1 の盤 y が
すべての歩みで R^{F'_1}(y) ≤ R^{F_1}(x) を満たすなら，F_2 の任意の盤 z とすべての歩みで R^{F'}(y ∪ z) ≤ R^F(x ∪ z)．
*証明.* F の手順 π をとる．F_2 の側の盤の大きさを c(t) とし，F_1 の側の実効の予算を β(t) − c(t) とおく．
これは予算の変化（±1）と F_2 の手（±1）のたびに 1 ずつ変わる歩み w' になる．
F_1 の側の盤は w' の各相で実効の予算以下で，切り替えの瞬間も両方以下（予算の切り替えでは上がるときも下がるときも全体が min(β,β') 以下，F_2 が石を置く手では置いた後の全体が β 以下）．
したがって π の F_1 への射影は w' のもとで x に至る F_1 の手順．仮定より w' のもとで y に至る F'_1 の手順で手数が以下のものがある．
これを F_2 の手と同じ相の区切りで差し込めば，各時刻の全体の盤は β 以下で，手数は π 以下．
（実効の予算が F_1 の頂点数を超える相は頂点数に切り詰めてよい．等しい予算の相が続く部分は 1 つの相にまとめる．）∎

**命題.** GRAFT が（D の区間が短い順に並ぶ場合だけでも）成り立てば SORT が成り立つ．
*証明.* 補題 D で R^F(X) ≥ R^{F*}(X) とする．F* は長さ s_1 ≤ … ≤ s_k の鎖で各頂上だけに石．
D = (s_k) から始めて，s_{k−1}，s_{k−2}，…，s_1 の鎖を順に D の上へ GRAFT でつなぐ（s_i ≤ s_{i+1} ≤ … なので条件を満たし，D は常に短い順）．
残りの鎖は文脈で，補題 C により各段で手数は増えない．最後は 1 本の鎖で盤は sorted(X)．∎

逆に GRAFT（D が短い順）は SORT の特別な場合なので，**SORT と GRAFT（D が短い順）は同値**．
連鎖: GRAFT ⇒ SORT ⇒ 2CM_1（すべての a,b）⇒ 蜘蛛型の木で予想 CC（`SHALLOW.md` 命題 S1）．
1 本の鎖の中の並べ替え（依頼の 1）も SORT の特別な場合なので GRAFT から従う．

## 3. 計算（sf3．`pair_cmp.c`，`transfer_check.py`，`stack_check.py`，`stack2_check.py`）

`pair_cmp P Q < 写像` は 2 つの森と盤の写像について，閉包（`forest_cmp.c` と同じ）で「すべての歩みで R_Q(y) ≤ R_P(x)」を調べる．
自己検査として 2 本 → 1 本の φ_sort を L ≤ 11 で流して違反 0（`SHALLOW.md` §6 と一致）．どの実行も閉包は閉じた（CAP なし）．出力は `out/sort/`．

| 主張 | 範囲 | 違反 | 対照（成り立たないはずの形） |
|---|---|---|---|
| GRAFT（D は任意の順，区間 ≥ c） | 合計 ≤ 12（36 通りの (c,d)） | 0 | c > D の一番上の区間: 1,359 |
| STACK（短い順の鎖 C で区間 ≤ t を，頂上だけの長さ t の鎖の上に） | ≤ 12，文脈の鎖 1 本つき ≤ 9 | 0 | C に t より長い区間: 2,187．整列を課さない: 67 |
| 2 本の各鎖の中を短い順に並べる（isort2） | ≤ 11 | 0 | |
| 2 本のまま片方の鎖で選択整列の 1 段（sel2） | ≤ 11 | 0 | |
| A と B が短い順のとき A の一番下の区間を B の整列位置へ（tinsert） | ≤ 11 | 0 | B の一番下へ入れる: L ≤ 11 で 262 |
| 1 本の鎖で選択整列の 1 段（上の j 個が最小の j 個を整列したもの → 残りの最小を j+1 番目へ） | 1 本 L ≤ 10 | 0 | 上の j 個に条件を課さない: 84（L=10） |
| 1 本の鎖で最小の区間を一番上へ | L ≤ 10 | 0 | |

成り立たないもの（証明の形を除く）: A の一番下の区間を B の一番下へそのまま移す（L ≤ 7 で 68），区間 1 つの A を任意の B の上に載せる（39），
上の k−1 区間だけを並べ替える（L=9，10 で 1，2），下の k−1 区間だけを並べ替える（多数），最大の区間を一番下へ（多数），隣接 1 回の交換（`SHALLOW.md` §6）．

独立の検算（saikensha，2026-10-31）は SORT の森の場合を合計 L ≤ 12 のすべての長さの並び（4,095 通り）で別実装により確認した（`SHALLOW.md` §6 末尾）．
GRAFT は SORT の特別な場合なので，この範囲では GRAFT も別実装で確認されたことになる．§2 の帰着（紙の証明）は検算していない．
