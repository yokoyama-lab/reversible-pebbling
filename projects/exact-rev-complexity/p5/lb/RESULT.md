## 得られた指数

- 漸近: 1 + κ* = 1.331742379…（再帰 F について無条件．M については条件付き）．この比較法の限界でもある
  （F_c(2^h−1, p_h) ≤ f_{h+1} = n^{1.3317+o(1)}）．
- 有限の h での下界の値 F_c(2^h−1, p_h)（厳密な整数）と log/log n:
  h = 8: 2111（1.381），h = 12: 95603（1.379），h = 20: 1.87e8（1.374），h = 40: 2.77e16（1.366）（単調ではない）．
  F*(h) との比は h = 12 で 1.61．
- 再帰 F の指数は [1.3317, log₂3] に入る（数値は 1.436）．
- 「n^{1.33}」は漸近の主張で，実効的な h の閾値は出していない（明示式の (B3) は h ≤ 24 で 0）．

## 証明の要点

1. **補題 A**（3 行）: F(G,S) ≥ F_c(|G|,S)．木の再帰の各分割 u は，部分の頂点数 m = |G_u|，n−m = |G∖G_u| で
   鎖の再帰の分割 m と同じ形の和を与えるので，|G| の帰納法で成り立つ．任意の次数の木で成り立つ．
2. **補題 B**: 鎖の行の計数関数 C_S は優解 θ^{−1}v^qρ^{qS} で押さえられる（別稿 §4.1 の議論を自己完結に書き直した）．
   行の整列から F_c(n,S) ≥ (n−1)⌊((n−1)θ/2)^{1/q}ρ^{−S}⌋．空間が log₂n + o(log n) なら n^{1+κ*−o(1)}，β log₂ n なら n^{1+V_β−o(1)}．
   行の整列と併合式 (3) は，別稿ではゲームの F について述べられているので，再帰の F_c に使うには Knill の定理が要る
   （Lean にあるが私はビルドしていない．S ≤ 10〜13 は数値で確認）．
3. **定理 C**: p_h = h + Θ(log* h)（Královič，厳密には CLNV Thm 3.3）なので補題 A と B から．
4. **系 E**: 重心の辺で切ると p_min(G) ≤ 1 + ⌈log_{Δ/(Δ−1)}(n−1)⌉．補題 A と B の一般形から．
5. **定理 D**: 仮説 CC_T(h) と補題 B から（直接の含意）．

## 試して駄目だった論法とその理由（詳細は PROOF.md §5）

- Královič 型の制限（両側が空でない区間）: 半到達 H について 1 段 2 項の不等式しか出ず指数 1．導出は PROOF.md §5(a)．
- Ω(n log n) を狙う漸化式: 余裕 1 の項を余裕 0 の項で押さえられない（なお Ω(n log n / log log n) は既知）．
- ある時刻の配置による領域分解: 余裕（S − p_min）つきの項が残る．
- ピーク（ピンポン）論法: 交互の進行を排除する補題が要る（p5/fm の反例はこの種の入れ替えで F を下回る）．
- 鎖の半到達の切断: 子 2 個の頂点で「ちょうど {根}」の時刻が無いことがあり，後置順では森の損失．
- 以上 4 つは spooky の手順にも成り立つ議論で，障壁により原理的に指数 1 を超えられない．
- 局所的な手術（部分木を同じ頂点数の鎖に置き換える 1-Lipschitz・ペブル数非増加の写像）: 星・T_2・T_3 では存在．
  T_4 では存在しない（影のゲームで全戦略について負け）．道の併合は損失 ⌊(a−1)/2⌋（a ≤ 7）で比例的に見える．
  非存在はソルバの出力（証明ログなし）．
- 影のゲームで余分のペブル δ を許すと: 失敗した小さい木はすべて δ = 1 で勝ち，T_4 は δ = 2 で勝つ．入れ子にすると余分が
  積み上がり，それを抑える議論が無い．
- ペブル数の上限を固定した写像は T_4（S = 6, 7）で存在（`out/psi_T4_S6.txt`．CC_T(4) の証明書）．一般の h への構成は無い．

## まだやっていないこと

- **CC の一般の証明**（無条件化の核心）．障壁により，証明は Ghost の無いことを使わなければならない．
  F = M が偽なので F 経由は使えない．局所的な写像は上のとおり一般には無い．
- 粗い模倣（鎖の長さ Θ(n)，手数・空間を定数倍まで許す）の構成．あれば β = 2 でも指数 1.2145 が無条件に出る（PROOF.md §5(g)）．
- 木に固有の改善（指数 1.3317 → 数値の 1.436 へ）．鎖との比較は頂点数だけを使うので木の分岐の分を取りこぼし，
  この比較法の限界は 1.3317 そのもの．木の行による計数関数（原稿 §6）が要る．
- arXiv:2610.09434 の証明の厳密な検算（読み込みの水準で確認しただけ）．
- UNSAT・影のゲームの負けの証明ログ（DRAT 等）．道の併合の a = 7 の対称性なしの再確認．
- T_5 の写像・影のゲーム（S = 7 で 19,198 軌道．鎖側の状態が多すぎて未着手）．
- Lean 化（補題 A は短いので容易と見込むが未着手．鎖側の既存 Lean も自分でビルドしていない）．
- 原稿への反映（原稿は編集しない約束．反映候補: 定理 C・系 E，F = M が偽であること，arXiv:2610.09434 の引用と
  「下界は自明な n しかない」の訂正）．
