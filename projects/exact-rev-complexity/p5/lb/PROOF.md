# P5 指数の下界 — 証明の草稿（p5/lb）

2026-10-15 起稿，2026-10-16 critic の指摘を反映．
層: 補題 A・補題 B・定理 C・系 E は紙の証明（層 2），定理 D は条件付き（層 2・仮説つき），
数値はすべて「計算で確かめた範囲」（有界．層 1 ではない）．非存在（UNSAT・影のゲームの負け）はソルバの出力で，
DRAT などの証明ログは取っていない．

## 0. 定義

**ゲーム**（原稿 P5 §3，KSS の persistent 版）．根付き木 G の辺は葉から根へ向く．頂点 v に置く手と外す手は，
v の子がすべてペブル済みのときだけ合法．空の盤から根だけがペブルされた盤へ，同時に S 個以下で移る最短手数を
M(G,S) と書く（無ければ ∞）．p_h = p_min(T_h)，n = 2^h − 1，M*(h) = M(T_h, p_h)．

KSS の常設仮定（JCSS §2 末，逐語）: "In the rest of the paper, we use the term pebbling to refer to persistent reversible pebbling unless explicitly stated otherwise."

**木の再帰 F**（原稿 定義 1）: S ≤ 0 で F = ∞，葉で F = 1（S ≥ 1），それ以外
F(G,S) = min_{u≠根} [F(G_u,S) + F(G_u,S−1) + F(G∖G_u,S−1)]．構成なので M ≤ F（原稿）．

**鎖の再帰 F_c**（Knill．arXiv:2609.15062 の式 (1)）: F_c(0,S)=0，F_c(n,0)=∞（n ≥ 1），F_c(1,S)=1（S ≥ 1），
n ≥ 2 で F_c(n,S) = min_{1≤m<n} [F_c(m,S) + F_c(m,S−1) + F_c(n−m,S−1)]．
F_c(n,S) < ∞ ⟺ n ≤ 2^{S−1}．

RevExact §1 の常設仮定（逐語）: "A move toggles (places or removes) a pebble on node i and is legal if i = 1 or node i − 1 carries a pebble; at most S pebbles may be on the chain at once; the play starts with an empty chain and ends with a single pebble on node n."
同所: "Knill [2] proved, for n, S ≥ 2, the exact recursion (1)"．

**依存関係の注意（critic R2 で訂正）.** RevExact の F はゲームの最短手数として定義されている．補題 B で使う
行の整列（§2）と併合恒等式 (3) は，その F についての主張なので，再帰で定義した F_c に使うには
Knill の定理（ゲームの最短手数 = 再帰）が要る．この定理は Lean にもある（`reversible-pebbling-lean` の
`RowExact.gameAttain_holds`，`GameDecomposition.gameF_eq_Fpre`）が，**私はその Lean をビルドしていない**．
数値の裏づけ: 整列と (3) は S ≤ 10 で私の `chain.py`（`Row` と `Fc_dp` の一致），S ≤ 13 で critic の独立実装が確認．
補題 A 自体は F_c を再帰として使うだけなので，この依存は無い．

## 1. 補題 A（木の再帰は同じ頂点数の鎖の再帰より小さくならない）

**補題 A.** すべての根付き木 G（子の数は任意）とすべての整数 S について F(G,S) ≥ F_c(|G|,S)．

*証明.* |G| についての帰納法．S ≤ 0 なら左辺 = ∞．|G| = 1 なら両辺 1（S ≥ 1）．|G| = n ≥ 2，S ≥ 1 とする．
根以外の任意の u について m = |G_u| とおくと 1 ≤ m ≤ n−1，|G∖G_u| = n−m．帰納法の仮定から
F(G_u,S) + F(G_u,S−1) + F(G∖G_u,S−1) ≥ F_c(m,S) + F_c(m,S−1) + F_c(n−m,S−1) ≥ F_c(n,S)．
最後の不等号は F_c の定義（m での値は最小値以上）．u について最小をとれば F(G,S) ≥ F_c(n,S)． ∎

使ったのは「分割の 2 つの部分の頂点数の和が n」と，F と F_c の再帰の形が同じこと（第 1 項が S，残り 2 項が S−1，
第 1・2 項が同じ部分）だけである．

**数値検査**（`test_lb.py` T3）: 頂点数 ≤ 11 の全根付き木 3047 形・34519 点で破れ 0（有限で等号 20045 点）．
右辺を F_c(|G|+1,S) にする変異は 20779 点で破れる（検出力あり）．
最小空間 S = p_h では T_2（5 = 5）・T_3（17 = 17）で等号，T_4 で初めて差が出る（53 対 47）．
最小空間でなければ T_4 でも等号がある（S = 7 で F = 45 = F_c(15,7)）．

## 2. 補題 B（鎖の再帰の下界．空間がほぼ最小のとき）

RevExact §2（逐語）: "We call the multiset row(S) = {δ(n, S) : 2 ≤ n ≤ 2^{S−1}} the row at level S; it has 2^{S−1} − 1 entries and is nondecreasing in n."
ここで δ(n,S) = (F_c(n,S) − F_c(n−1,S))/2．同 (3): row(S) = {1} ∪ row(S−1) ∪ {δ(i,S)+δ(i,S−1)}_{2≤i≤2^{S−2}}．
計数関数 C_S(v) = #{n : 2 ≤ n ≤ 2^{S−1}, δ(n,S) ≤ v}（v < 1 で 0）．

**(B1) 計数の漸化式．** 行が整列していることと (3) から，v ≥ 1 で
C_S(v) = 1 + C_{S−1}(v) + max_{0≤τ≤v} min(C_S(τ), C_{S−1}(v−τ))．
（(3) の第 3 項は row(S) の i 番目に小さい値 a_i と row(S−1) の i 番目 b_i の和．a_i + b_i ≤ v ⟺ ある τ で
i ≤ C_S(τ) かつ i ≤ C_{S−1}(v−τ)．）これは RevExact Lemma 3.1 の双対不等式 (4)(5) を等式にしたもの．
Lemma 3.1 の常設仮定（逐語）: "For every S ≥ 2, all positive integers u, w, v, and every integer τ with 0 ≤ τ ≤ v − 1,"．
**数値検査**: この漸化式で計算した F_c（`chain.py` の `Row`）は，再帰そのもの（`Fc_dp`）と S ≤ 10 の全 n で一致し，
鎖のゲームの全数探索（`chain_bfs`）とも n ≤ 8，S ≤ 9 で一致（`test_lb.py` T1）．

**(B2) 優解．** q > 0，ρ_c(q) を ρ^{−q} + (1+ρ)^{−q} = 1 の正根，ρ > ρ_c(q)，θ = 1 − ρ^{−q} − (1+ρ)^{−q} (> 0)，
Φ_S(v) = θ^{−1} v^q ρ^{qS} とすると，すべての S ≥ 1，v ≥ 0 で C_S(v) ≤ Φ_S(v)．

*証明*（RevExact §4.1 の議論を写したもの）．(S,v) の帰納法．C_1 ≡ 0，C_S(0) = 0．S ≥ 2，v ≥ 1 で
τ = ⌊v/(1+ρ)⌋ ≤ v−1 とおく．(B1) の max の各項は τ' ≤ τ なら C_S(τ') ≤ C_S(τ)，τ' ≥ τ+1 なら
C_{S−1}(v−τ') ≤ C_{S−1}(v−1−τ) で押さえられるので
C_S(v) ≤ 1 + C_{S−1}(v) + max(C_S(τ), C_{S−1}(v−1−τ))（これが (5)）．
帰納法の仮定と τ ≤ v/(1+ρ)，v−1−τ < ρv/(1+ρ) から右辺 ≤ 1 + (ρ^{−q} + (1+ρ)^{−q})Φ_S(v) = 1 + (1−θ)Φ_S(v)．
v ≥ 1，ρ > 1 なので θΦ_S(v) = v^q ρ^{qS} ≥ 1，よって右辺 ≤ Φ_S(v)． ∎
（ρ_c(q) > 1 は ρ = 1 で左辺 1 + 2^{−q} > 1 から．）

**(B3) 和への変換．** 行は整列しているので F_c(n,S) = 1 + 2·（row(S) の小さい方から n−1 個の和）．任意の v ≥ 0 で
その和 ≥ v·(n − 1 − C_S(v))．v = ⌊((n−1)θ/2)^{1/q} ρ^{−S}⌋ とすれば C_S(v) ≤ (n−1)/2 なので

  **F_c(n,S) ≥ (n−1)·⌊((n−1)θ/2)^{1/q} ρ^{−S}⌋．**

**系 B'.** S = log₂ n + k_n，k_n = o(log n) なら F_c(n,S) ≥ n^{1+κ*−o(1)}，κ* = sup_q (1/q − log₂ ρ_c(q)) = 0.33174…
（*証明*: (B3) の右辺は n^{1+1/q−log₂ρ}·ρ^{−k_n}·(定数) − n で，ρ^{−k_n} = n^{−o(1)}．q を最大化点 q* ≈ 1.51538 に，
ρ ↓ ρ_c(q) とする．κ* の値は RevExact Theorem 1.2．）
より一般に S = β log₂ n + O(1)（β ≥ 1 定数）なら F_c(n,S) ≥ n^{1+V_β−o(1)}，V_β = sup_q (1/q − β log₂ ρ_c(q))．

## 3. 定理 C（再帰 F について．無条件）

p_h（= p_min(T_h)）は，Chan–Lauria–Nordström–Vinyals（arXiv:2305.19104）Theorem 3.3（逐語）
"Then the persistent pebbling price of a pyramid of height h, as well as of a complete binary tree of height h, is h + g^{−1}(h)"
（同文献の高さは辺の数で，"binary tree of height 0 can be pebbled with 1 pebbles"（Lemma 5.5 の証明）．
原稿の T_h は彼らの高さ h−1 なので p_h = (h−1) + g^{−1}(h−1)）．
Královič 2004 は Theorem 4.9 で "Smin(h) = h + Θ(lg∗(h))"（complete computation）を述べ，証明の中で
上線つきの S̄min（Definition 4.1 の semicomplete = persistent）について "Hence, S̄min(h) = h + Θ(lg∗(h)) holds." と書いてから，
"From Lemma 4.2 it follows, that Smin(h) = h + Θ(lg∗(h))." と上線なしの Smin へ移している
（上線の有無は `pdftotext -raw` で S̄ が「S␤min」と改行で割れることで判別した．critic R1 で訂正）．
Bt(1) は 1 頂点なので Bt(h) = T_h．いずれにせよ p_h − h = Θ(log* h) = o(h)．
`lb_table.py` は CLNV の式が原稿の p_min（h ≤ 12）と跳びの位置 h = 2, 3, 7, 135 を再現することを確かめる．

**定理 C.** すべての h で F(T_h, p_h) ≥ F_c(2^h − 1, p_h)．さらに F(T_h, p_h) ≥ n^{1+κ*−o(1)} = n^{1.33174…−o(1)}．

*証明.* 前半は補題 A．後半は系 B'（n = 2^h−1，S = p_h，k = p_h − log₂ n = o(log n)）． ∎

意味: 「部分木を置く → 保持して残りを置く → 部分木を外す」を入れ子にした戦略は，最小のペブル数のもとで
n^{1.3317−o(1)} 手より速くならない．原稿の定理 1 の構成（戦略木），Chan の Lemma 3.22 の構成
（"run P1, then run P2, and finally run P1 in reverse"），原稿の背骨族（入れ子の分割だけでできているので F ≤ Ff）はこの形である．
よって再帰 F の指数（数値では 1.436）は区間 [1.3317, log₂ 3] に入る．
この比較で得られる指数は 1.3317 が限界でもある: p_h ≥ h+1 と F_c の S についての単調性から
F_c(2^h−1, p_h) ≤ F_c(2^h, h+1) = f_{h+1} = n^{1.3317+o(1)}．

### 系 E（有界次数の木．再帰 F について無条件）

G を頂点数 n ≥ 2，無向の最大次数 Δ ≥ 2 の根付き木とし，d(G) = min{S : F(G,S) < ∞} とする
（KSS Lemma 10 と原稿により d(G) = p_min(G)）．

(E1) **d(G) ≤ 1 + ⌈log_{Δ/(Δ−1)}(n−1)⌉．** 重心 c（G − c の各成分が n/2 以下）の最大の成分 C は
|C| ≥ (n−1)/Δ．c と C を結ぶ辺で切ると，部分の頂点数は |C| ≤ n/2 と n − |C| ≤ n − (n−1)/Δ．
根付きで見ればこれは G_u と G∖G_u（u はその辺の両端のうち子のほう）なので，F の定義から
d(G) ≤ 1 + max(d(G_u), d(G∖G_u))．部分木も最大次数 ≤ Δ．m − 1 ≤ ((Δ−1)/Δ)(n−1) を繰り返せばよい．
（数値: 子 2 個以下の頂点数 ≤ 11 の全形で p_min ≤ 1 + log_{1.5} n．）

(E2) **F(G, p_min(G)) ≥ F_c(n, 1 + ⌈log_{Δ/(Δ−1)}(n−1)⌉) ≥ n^{1+V_{β_Δ}−o(1)}，β_Δ = 1/log₂(Δ/(Δ−1))．**
補題 A，F_c の S についての単調性，(E1)，系 B' の一般形を使う．

| Δ | β_Δ | 指数の下界 1+V_{β_Δ} |
|--:|--:|--:|
| 2（鎖） | 1 | 1.3317 |
| 3（子 2 個以下の木すべて） | 1.7095 | 1.2311 |
| 4 | 2.4094 | 1.1982 |
| 5 | 3.1063 | 1.1802 |

意味: 有界次数の木はどれも，最小のペブル数のもとで「入れ子の再帰形」の戦略では n^{1+ε_Δ} 手より速くならない．
M についての同じ主張は CC（§4）が G で成り立つことが条件．KSS の開問題 2（任意の木で O(n^k) か）は上界の問いで，
これはその下界の側の部分的な対応物にあたる．

### 3.5 既知の無条件下界（critic R3．起稿時に見落としていた）

Lee–Lee–Jeong, "Optimal (Parallel) Spooky Pebbling on Binary Trees", arXiv:2610.09434（2026-10-07）．
模型（§2.2，逐語）: "A configuration is a pair (P, G) of disjoint subsets of V."，行動は
Pebble(v)（条件 v ∉ P, pred(v) ⊆ P），Unpebble(v)（条件 {v} ∪ pred(v) ⊆ P），Ghost(v)（条件 v ∈ P），
"The initial configuration is (∅, ∅), and the goal is ({r}, ∅)"．
Ghost を使わない手順は persistent な可逆ペブリングそのものなので，可逆の手順はこの模型の手順でもある．
Theorem 4.3（逐語）: "Every sequential strategy on a full binary tree with n vertices and space at most s has Π = Ω(n log n / log(s + 1))."
（Π は置く手の数．可逆の手数 = 置く手 + 外す手 = 2Π − 1．）s = p_h = log₂ n + O(log* n) を入れると，**無条件に**

  **M*(h) = Ω(n log n / log log n)．**

私の確認: Lemma 4.1（重心による分割．次数 ≤ 3 を使う），Lemma 4.2（最後に外す時刻 τ の区間で，空の片は丸ごと置き直す），
Theorem 4.3 の数え上げを本文で読み，可逆の場合に当てはまることを追った（紙の読み込みの水準．形式化はしていない）．
指数は 1 なので決定点（n^{1+ε}）には届かない．

**障壁（ここからの帰結）.** 同論文は spooky の模型で h+1 ≤ s の全域に手数 O(nh/log(s+1)) の構成を与えている
（Theorem 3.4．s = p_h では O(n log n / log log n)）．spooky の手順の集合は可逆の手順の集合を含むので，
**spooky の手順にも成り立つ下界の論法では M*(h) について n^{1+o(1)} を超えられない**．
指数 1 を超えるには，Ghost が無いこと（測定で消せないこと）を使う必要がある．
上の (§5) の Královič 型の制限・領域分解・ピーク論法は，どれも Ghost の有無を使っていない．
なお定理 C と合わせると，入れ子の可逆戦略（≥ n^{1.33}）と spooky の最適（n^{1+o(1)}）の間に指数の差がある．

同論文 Theorem 1.2（葉数 N の full binary tree の中で完全木が手数を定数倍まで最小にする．spooky）は，
予想 CC（形についての最適性）に最も近い先行例だが，模型・比較する木の範囲・向きが異なる．

## 4. 定理 D（最短手数 M について．条件付き）

**仮説 CC_T(h)**（完全二分木での鎖比較）: M(T_h, p_h) ≥ F_c(2^h − 1, p_h)．

**定理 D（条件付き）.** 十分大きいすべての h で CC_T(h) が成り立つなら M*(h) ≥ n^{1+κ*−o(1)}．
*証明.* 仮説と系 B'（仮説からの直接の含意）． ∎ （漸近の主張で，実効的な h は出していない．§3 の表の注を参照．）

- 仮説はさらに粗くしてよい（§5(g)）: 定数 c, β ≥ 1, k で M(T_h,p_h) ≥ F_c(⌈n/c⌉, ⌈β p_h⌉)/k が十分大きい h で
  成り立てば M*(h) ≥ n^{1+V_β−o(1)}（β = 2 でも指数 1.2145）．
- CC_T(h) は **F*(h) = M*(h) から従う**（補題 A）．原稿の全数探索で h ≤ 7 は F* = M*，さらに p5/h8 が 2 実装の全数探索で
  M*(8) = 2789 = F*(8) を決めた（`p5/h8/RESULT.md`）．よって CC_T(h) は h ≤ 8 で真（h = 8 は 2111 ≤ 2789）．
  ただし h = 5..8 は証明ログの無い全数探索に依存し，独立の裏づけがあるのは h ≤ 4（私の BFS と写像の証明書）．
  定理 D に要るのは F = M ではなく，それより弱い CC_T である．
- **F = M は一般の木では偽**（p5/fm セッションの全数探索：頂点数 15，形 `(...(....)(..(..)))`，S = 6 で M = 51 < F = 53．
  私の独立の BFS でも M = 51，F = 53 を再現．最短の手順は B の部分木を片付けながら A の 4 枚の葉を置く，
  F の「後入れ先出し」に反する入れ替えをしている）．このため仮説は F = M ではなく CC の形で述べる．
  その木でも F_c(15,6) = 47 ≤ 51 で CC は成り立つ．
- **一般形の予想 CC**: すべての根付き木 G とすべての S で M(G,S) ≥ F_c(|G|,S)（「鎖はいちばん速い木」）．
  証拠（`cc_check.py`．M は p5/fm の bfs_m の全数探索の表を読み取り専用で使用）: 頂点数 ≤ 16 の全根付き木（子の数は任意）と
  子 2 個以下の木（n = 17, 18）．重複を除いて 9,050,468 点で破れ 0．
  うち n ≤ 15 の全形と子 2 個以下の n = 16 の 2,423,865 点では，有限かつ S < n の非自明な点が 1,417,363，
  その **94.0% が等号** M = F_c（CC には余裕がほとんど無い）．
  頂点数 ≤ 9 は私の BFS でも独立に確認（`test_lb.py` T4）．**これは有界の照合で，証明ではない．**
  （起稿時の「2,700,424 点」は子 2 個以下の n = 11..15 を二重に数えていた．critic L1 で訂正．）

**写像による証明書（有界）.** 木の配置から長さ |G| の鎖の配置への写像 ψ で，ψ(∅)=∅，ψ({根})={先端}，
ペブル数 ≤ S の配置を ≤ S に写し，木の合法な 1 手を「動かない」か「鎖の合法な 1 手」に写すものがあれば，
M(G,S) ≥ F_c(|G|,S)（木の手順を足踏みを除いて手数を増やさずに鎖の手順へ写せる）．
T_4 では S = 6（= p_4），7 で SAT ソルバがこの写像を見つけ（`lip_sat.py --space`），S = 6 の写像を
`out/psi_T4_S6.txt`（sha256 45b9c067…a803f7）に保存した．検査器 `check_map.py`（`lip_sat.parse` だけを共有）で
全 9949 配置・59754 手について確かめ，1 点を壊す変異は検出する（`test_lb.py` T6）．critic は S = 6, 7 の写像を
私のコードを使わない検査器で再確認した．CC_T(4) の証明書にあたるが，M*(4) = 53 は既知なので新しい数値ではない．
一般の h への構成は無い（§5(e)）．

## 5. 無条件に指数 1 を超える試み（いずれも届かなかった）

以下の (a)〜(d) はどれも spooky の手順にも成り立つ議論で，§3.5 の障壁により，それだけでは n^{1+o(1)} を超えられない．

(a) **Královič 型の制限**（Lemma 4.3 の「両側の部分木が空でない区間」）．
*導出.* X, Y を根 r の左右の部分木とする．r を最後に置く時刻を i とする．
i より前で，X か Y のどちらかが空だった最後の時刻を j' とし，そのとき空だった側を Y とする．(j', i] では両側が空でないので，
Y は ∅ → ∋R を S−1 個以下で行う（≥ H(T_{h−1},S−1)）．X は時刻 0 から ∋L まで S 個以下（≥ H(T_{h−1},S)）．
i より後は r を保持する．i 以降で片側が初めて空になる時刻を j とし，その側を Z とする．[i, j) では
両側が空でなく r もあるので，Z は ∋根 → ∅ を S−2 個以下で行う（≥ H(T_{h−1},S−2)，逆向きの半到達）．
もう一方は S−1 個以下（≥ H(T_{h−1},S−1)）．4 つの部分の手は互いに素で，r の手が 1 つあるので
M(T_h,S) ≥ 1 + H(T_{h−1},S) + 2H(T_{h−1},S−1) + H(T_{h−1},S−2)．
同様に半到達では，r を初めて置く時刻までについて H(T_h,S) ≥ 1 + H(T_{h−1},S) + H(T_{h−1},S−1)（1 段 2 項）．
H の漸化式が 1 段 2 項なので，これだけでは指数 1 にとどまる（critic が h ≤ 4・全 S の BFS で両不等式に破れが無いことを確認）．

(a') **Ω(n log n) を狙う Královič 型の漸化式**．数値では M*(h) ≥ 2M*(h−1) + 0.75·2^h が h ≤ 7 で成り立つ．
証明には「両方の部分木が最小空間で persistent に処理される」ことが要るが，根を最後に置いた後の片付けは
半到達（逆向き）でしか押さえられず，persistent な部分手順が出るのは片側がちょうど 1 頂点になる時刻だけで，
そのときの空間は S（余裕 1）になりうる．余裕 1 の項を余裕 0 の項で押さえる手段が無く，ここで止まった．
なお最小空間の半到達は安い（BFS: H(T_4,5) = 29，H(T_4,6) = 24 に対し M(T_4,6) = 53）ので，
半到達で押さえる議論は手数の大半を取りこぼす．（Ω(n log n / log log n) は §3.5 で既知．）

(b) **ある時刻の配置による領域分解**．時刻 t の配置 K で木を領域 R_k（k ∈ K）に分けると，前半は各 R_k の
persistent な手順，後半はその逆を含む．ただし後半の空間が S−1 になる保証が無く，余裕（S − p_min）つきの項が残る．
余裕の項を元の項で押さえる手段（例えば「ペブルを 1 個増やしても定数倍しか速くならない」）が無い．
（起稿時の「問題と同等」は示していない同値性の主張なので削った．critic L6．）

(c) **ピーク（ピンポン）論法**．q_{h−1} を T_{h−1} の半到達（complete computation）に要る最小の空間とする
（Královič の Smin(h−1)．Lemma 4.3 から p_h = q_{h−1} + 2）．片側が半到達のために q_{h−1} 個を使う瞬間，
もう片側は高々 1〜2 個．もう片側が根 1 個なら 3 項目（persistent な部分木）が出るが，深い頂点 1 個のこともあり，
そのときは刈り込まれた木の半到達が残る．交互の進行（ピンポン）を排除する補題が要る．
p5/fm の反例（F ≠ M）はまさにこの種の入れ替えで F を下回っている．
（起稿時の「F = M の困難そのもの」は示していない同値性の主張なので弱めた．critic L6．）

(d) **鎖の半到達の切断**（RevExact §4.4 の「最左ペブルの最大位置」で切る）．木では「常に空でない部分木」の
極小頂点が子 2 個を持つと，その部分木がちょうど {根} になる時刻が無いことがある．後置順で切ると下側が森になり，
左の成分の頂点数を失う．

(e) **局所的な手術（部分木を鎖に置き換える 1-Lipschitz 写像）**．ペブル数を増やさない写像が「どの文脈でも」
使える形（|ψ(A)| ≤ |A|，根 ∈ A ⇒ 先端 ∈ ψ(A)）なら，部分木を鎖に置き換えても M は増えず，
木全体を鎖まで縮められれば CC が出る．SAT（kissat / cadical）で調べた（`subtree_sat.py`，`lip_sat.py`，
`merge_sat.py`，`merge_loss.py`）．非存在は UNSAT の出力で，証明ログは無い．
  - ある: 星，T_2，T_3，Ch_1+T_3，根+P_2+P_2，道の併合 (1,b)（b ≤ 4），(2,2)．
  - 無い: 道の併合 (2,3)(2,4)(3,3)(3,4)，根+P_2+P_3，根+P_3+P_3，根+T_2+P_2，Ch_1+T_2 と T_2 を子にもつ木
    （critic が対称性の制限なしに cadical で再確認），T_4（Aut 不変の写像．根の条件を ψ({根}) だけに弱めても無い）．
  - 鎖を短くすれば存在する: 根+P_a+P_a の最長は a = 1..7 で 3, 5, 6, 8, 9, 11, 12（損失 0,0,1,1,2,2,3．⌊(a−1)/2⌋ と一致）．
    `merge_loss.py` は a = b のとき Aut 不変の写像に限って解くが，a ≤ 5 は私が，a = 6 は critic が制限なしで同じ値を確認した
    （a = 7 は制限つきのみ）．T_4（Aut 不変）は長さ 13 まで．損失が a に比例するなら，道を介した再帰は
    長さ約 1.5^h の鎖しか与えず，指数は 1 を超えない．
  - ペブル数の上限を S に固定した写像（文脈には使えない）は T_4 で存在する（§4）が，再帰的な構成は無い．

(e') **影のゲーム**（`shadow.py`，`shadow_bits.py`）．写像（配置だけで鎖の配置が決まる）を一般化し，
木の手に鎖が 0 手か 1 手で応じ，不変条件を保ち続けられるかを安全ゲームとして解いた（勝ちの領域の最大不動点）．
勝てば写像と同じく M(木) ≥ F_c が出て，pluggable 版なら局所手術にも使える．木の自己同型で勝ちの領域は不変なので
軌道に縮めても一般性を失わない．2 つの実装（集合版とビット列版）は試した 12 の場合で一致．
  - pluggable 版（|Z| ≤ |A|）の勝ち負けは，試した 6 本の木で写像の SAT/UNSAT と一致（記憶を使っても得をしない）．
  - T_4 → 長さ 15 の鎖は **pluggable 版で負け**（すべての戦略について．写像の Aut 不変版 UNSAT より強い）．
  - 「∅ と {根} では厳密，それ以外は |Z| ≤ |A| + δ」と緩めると: 上で負けた根+P_2+P_3，根+P_3+P_3，根+T_2+P_2，
    T_2 と Ch_1+T_2 を子にもつ木はすべて δ = 1 で勝つ．T_4 は δ = 1 で負け，δ = 2 で勝つ．
    根+P_a+P_a（長さ 2a+1）に要る最小の δ は a = 2..6 で 0,1,1,1,2．
  - 入れ子の手術では δ が活動中の単位の数だけ足されるので，δ が小さくても全体の余分は大きくなりうる
    （活動中の単位は最大でペブル数 × 高さ）．これを抑える議論は無い．
  - space 版（|A| ≤ 6 の範囲で |Z| ≤ 6）では T_4 で鎖が勝つ（§4 の写像と整合）．

(h) **最小空間の半到達の構造（2026-10-18 追記）**．q_h を T_h の半到達（complete computation）の最小空間，
H_k(h) = H(T_h, q_h + k)（半到達の最短手数），M*(h) = M(T_h, p_h) とする．BFS の厳密値:

| h | q_h | H_0 | H_1 | H_2 | M* | H_0(h−1)+M*(h−1)+2 |
|--:|--:|--:|--:|--:|--:|--:|
| 2 | 3 | 3 | – | – | 5 | – |
| 3 | 4 | 10 | 9 | 8 | 17 | 10 |
| 4 | 5 | 29 | 24 | 23 | 53 | 29 |
| 5 | 6 | 84 | 63 | 54 | 155 | 84 |

（H は本セッションの BFS．T_5 の S = 6, 7 は目標に達するまでに 690,135／2,577,437 状態を訪れた．S = 8 の状態数は記録していない．）
**h = 3, 4, 5 で H_0(h) = H_0(h−1) + M*(h−1) + 2 がちょうど成り立つ．** 片側を最小の persistent 空間で根 1 個まで
pebble して保持し，もう片側を最小空間で半到達する形である．
- 予想（頂上の構造）: 跳びの無い高さ（q_h = q_{h−1} + 1）で H_0(h) ≥ H_0(h−1) + M*(h−1)．
  ピーク論法（§5(c)）で「相手のピークの時刻に片側がちょうど自分の根 1 個」を示せれば出る．深い 1 頂点の場合の排除が要る．
- これと M*(h) ≥ (1+δ)H_0(h) があれば H_0 の比は 2+δ を超え，無条件に指数 1 超えが出る（数値では M*/H_0 = 1.70，1.83，1.85）．
- しかし無条件に示せるのは M*(h) ≥ H_1(h) + H_2(h) − 1（根を最後に置く時刻で前後に分け，前は空間 p_h の半到達，
  後は根を保持した空間 p_h − 1 の両子への到達）までで，その比 (H_1+H_2)/H_0 は 1.70，1.62，1.39 と h とともに下がる．
  余裕つきの半到達 H_k を H_0 で押さえる手段が無く，ここでも余裕の制御で止まる．
  （M* ≥ 2H_1 は偽: h = 3 で 2·9 = 18 > 17．）

(f) **F = M を経由**: 一般の木では偽（§4）．二分木では p5/fm の照合範囲で一致しているが証明は無い（担当外）．

(g) **的の頑健さ（今後への注記）**．補題 B は S = β·log₂ n（β ≥ 1 定数）でも効き，
F_c(n, β log₂ n) ≥ n^{1+V_β−o(1)}．数値は V_1 = 0.3317，V_{1.5} = 0.2477，V_2 = 0.2145，V_4 = 0.1657，V_8 = 0.1367．
したがって **長さ Θ(n) の鎖への「粗い」模倣**（木の 1 手を鎖の定数 k 手で，鎖のペブル数を木の β 倍＋定数で）が
無条件に作れれば，それだけで M*(h) ≥ n^{1+V_β−o(1)}/k，指数 1 超えが無条件に出る．鎖の長さも n^{1−δ}
（(1−δ)(1+V_β) > 1）まで落としてよい．ただし入れ子にすると k は高さだけ掛け算されるので，模倣は木全体に対して
直接作る必要がある．§3.5 の障壁により，その模倣は Ghost の無いことを使わなければならない
（spooky の手順を同じ鎖で模倣できてしまうと矛盾する）．これは未着手（構成の候補も無い）．
