# 木の Knill 再帰 F は最短手数 M に等しくない（反例と構造定理）

2026-10-15。依頼 `REQUEST.md` の決定点「すべての根付き木 T とすべての S で M(T,S) ≥ F(T,S) か」への答え。
**答え: 偽。** 最小の反例は頂点数 15（S=6 で M=51, F=53）。差はいくらでも大きくなる（§5 命題 7: F−M ≥ 2m の族）。

層: 本文の定理・補題・反例は**紙の証明（層 2）**。反例の数値は計算でも確かめてある（層ではなく照合。範囲は `RESULT.md`）:
本作業の BFS（`bfs_m.c`。`witness.py` の BFS はほぼ同じ構造なので独立とは数えない）と F（`ftree.py`）、原稿の `p5_tree_count.py`、
手順の再生検査器。さらに critic（2026-10-15）が別に書いた BFS（全 S、打ち切りなし）は n ≤ 15 の全 141,083 本で `bfs_m` と出力がバイト一致し、
枝刈りなしの F の別実装 2 本でも M(T,6)=51、F(T,6)=53 を再現した。

## 0. 設定と記号

- 根付き木 T（根 r、頂点数 n）。辺は子から親へ向く。頂点 v を置く／外す手は、v の子がすべてペブル済みのときだけ合法。
- 盤 P ⊆ V(T)。空の盤 ∅ から {r} へ、常に |P| ≤ S で移る最短手数を M(T,S)（不可能なら ∞）。
- F は原稿 P5 の定義 1 そのもの:
  F(T,S)=∞ (S≤0)、F(葉,S)=1 (S≥1)、それ以外は F(T,S)=min_{u≠r}[F(T_u,S)+F(T_u,S−1)+F(T−T_u,S−1)]。
  T−T_u では u の親は u をペブル済みの入力として扱う（u とその下を木から除く）。
- 森 Φ の上で、盤 X から盤 Y へ常に |P| ≤ B で移る最短手数を d_B(X,Y) と書く（規則は同じ）。
  手は可逆（同じ盤の対で逆向きにも合法）なので d_B(X,Y)=d_B(Y,X)。
- **下に閉じた集合**: D ⊆ V で、D の頂点の子はすべて D にあるもの。その補集合 U=V−D は上に閉じている
  （U の頂点の親は U にある）。

## 1. F を展開した形（補題 1）

**補題 1.** n ≥ 2 のとき
F(T,S) = 1 + min Σ_{i=1}^{j} [ F(R_i, S−i+1) + F(R_i, S−i) ]。
最小は、根以外の頂点の列 (u_1,…,u_j)（j ≤ S−1）で、R_i を「T から R_1,…,R_{i−1} を除いた木での u_i の部分木」としたとき
R_1,…,R_j が T−{r} を覆うもの全体にとる。このとき r の子はすべて u_1,…,u_j に現れる。

*証明.* 定義の第 3 項 F(T−T_u,S−1) を、残りの木が {r} 1 頂点になるまで同じ式で繰り返し展開すると、
i 番目の展開で使う予算は S−i+1（置く）と S−i（外す）になり、最後に F({r},S−j)=1 が残る。これは S−j ≥ 1 のときだけ有限なので j ≤ S−1。
残りが {r} になるには r の子 c がどれかの R_i に入る必要があり、R_i の根 u_i は残りの木で c の祖先（c 自身を含む）かつ r でないので u_i=c。∎

**系 1'（F の自明な下界）.** F(T,S) ≥ 4n−2S−1。
*証明.* 部品 R_i（m_i 頂点）を置く手順も外す手順も各頂点を少なくとも 1 回置いて外し根を 1 回置くので ≥ 2m_i−1
（F(R,s) ≥ M(R,s) ≥ 2|R|−1。M ≤ F は F が構成であることから）。Σ m_i = n−1、j ≤ S−1 より
F ≥ 1 + Σ 2(2m_i−1) = 1 + 4(n−1) − 2j ≥ 4n−2S−1。∎

## 2. 削除補題と M の分解

**補題 2（削除）.** D を下に閉じた集合、U=V−D とする。合法な手順 (P_0=∅,…,P_M) のある時刻 t' で P_{t'} ∩ U = ∅ なら、
t' より前の U の頂点への手をすべて消しても、同じ終状態への合法な手順で、各時刻の盤の大きさは増えない。

*証明.* 消した後の手順の各時刻の盤は、D の部分は元と同じ、U の部分は t' より前は ∅、t' 以降は元と同じ
（元の手順も t' で U が空なので、t' 以降の U の手は同じ盤から始まる）。
D の頂点への手の合法性は D の中の子だけで決まる（D は下に閉じている）ので変わらない。
t' 以降の U の頂点への手の合法性は、子の D の部分も U の部分も元と同じなので変わらない。盤の大きさは増えない。∎

**系 2a.** 最短手順では、根 r はちょうど 1 回置かれ、外されない。
*証明.* D=V−{r} に補題 2 を使う。r を最後に置く直前の時刻 t' では r は盤に無い。それ以前に r への手があれば消せて短くなる。∎

**補題 3（M の分解）.** n ≥ 2 のとき
M(T,S) = 1 + min_C [ d_S(∅,C) + d_{S−1}(∅,C) ]。
d は森 T−r の上の距離で、C は ch(r) ⊆ C ⊆ V−{r}、|C| ≤ S−1 を動く。

*証明.* (≤) 森の上で ∅→C を予算 S で、r を置き、C→∅ を r を持ったまま予算 S−1 で（∅→C の手順の逆再生）。
(≥) 最短手順で r を置く唯一の時刻 t_r の直前の盤を C とする。r を置くので ch(r) ⊆ C、置いた後 |C|+1 ≤ S。
t_r より前の手はすべて森 T−r の上の手で、∅→C を予算 S で移る。t_r より後の手も森の上の手で（r は外されない）、
r が盤を 1 つ占めるので C→∅ を予算 S−1 で移る。d_{S−1}(C,∅)=d_{S−1}(∅,C)。∎

**補題 4（独立な部分木の順序）.** 森 Φ が木 T_1,…,T_k（根 c_1,…,c_k）の直和で、C={c_1,…,c_k} のとき
d_B(∅,C) = min_σ Σ_{i=1}^{k} M(T_{σ(i)}, B−i+1)
（σ は 1..k の並べ替え、σ(1) が最初。M(·,s)=∞ for s ≤ 0）。

*証明.* (≤) T_{σ(1)} を予算 B で根だけ残るまでペブリングし、c_{σ(1)} を持ったまま T_{σ(2)} を予算 B−1 で、…と順に行う。
(≥) 最短の手順 π をとる。各 T_i は森の連結成分なので、T_i の手の合法性は T_i の中だけで決まり、他の成分の手の合法性にも影響しない。
ある T_i が手を受けた後のある時刻 y で空なら、y より前の T_i の手を消しても合法で（補題 2 と同じ理由）短くなるので、
**π では各 T_i は最初の手を受けてから終わりまで空にならない。** 成分を最初の手の時刻の順に σ(1),σ(2),… と並べる。
T_{σ(i)} の最初の手から終わりまで、先に始まった i−1 個の成分はそれぞれ少なくとも 1 個のペブルを持つので、
T_{σ(i)} の中のペブルは常に B−i+1 個以下。π を T_{σ(i)} に制限すると、∅ から {c_{σ(i)}} への合法な手順
（終状態 C ∩ T_{σ(i)} = {c_{σ(i)}}）なので、その手数は M(T_{σ(i)},B−i+1) 以上。成分ごとの手は互いに素なので和をとる。∎

## 3. 主定理（根の子が S−1 個のとき）

**定理 5.** 根 r の子 c_1,…,c_{S−1} がちょうど S−1 個なら
M(T,S) = 1 + min_σ Σ_{i} M(T_{c_{σ(i)}}, S−i+1) + min_τ Σ_{i} M(T_{c_{τ(i)}}, S−i)、
F(T,S) = 1 + min_σ Σ_{i} [ F(T_{c_{σ(i)}}, S−i+1) + F(T_{c_{σ(i)}}, S−i) ]。

*証明.* M: 補題 3 で ch(r) ⊆ C、|C| ≤ S−1 = |ch(r)| なので C=ch(r)。森 T−r は T_{c_i} の直和なので補題 4 を B=S と B=S−1 に使う。
F: 補題 1 で j ≤ S−1 かつ {u_1,…,u_j} ⊇ ch(r) なので j=S−1 で u_i はすべて r の子。子の部分木は互いに素なので R_i=T_{u_i}。∎

**読み方.** σ は置く順（σ(1) が最初に置く子の部分木で予算 S）。τ は外す側を時間の逆向きにたどった順で、
τ(1) が最後に外す子の部分木（予算 S−1）、τ(S−1) が最初に外す子の部分木（予算 1）。M ではこの 2 つが
**独立な 2 つの割り当て問題**になる。F は同じ σ を両方に使う（後に置いたものを先に外す LIFO）。両者の差がそのまま反例になる。

**系 6（F が正しくなる条件）.** 定理 5 の仮定の下で、根の子の部分木すべてで M=F が成り立つとする。
f_c(s)=M(T_c,s) と書くと、F(T,S)=1+min_σ[A(σ)+B(σ)]、M(T,S)=1+min_σ A(σ)+min_τ B(τ)
（A(σ)=Σ_i f_{σ(i)}(S−i+1)、B(τ)=Σ_i f_{τ(i)}(S−i)）なので、
**M(T,S)=F(T,S) ⟺ A と B に共通の最小化順序がある。** とくに、子を全順序 ≺ で並べて、c ≺ c' なら
s ≥ 2 で f_{c'}(s−1) < ∞ となるすべての s について f_c(s−1)−f_c(s) ≥ f_{c'}(s−1)−f_{c'}(s)（左辺が ∞ でもよい）、かつ
f_{c'}(s−1) = ∞ なら f_c(s−1) = ∞ となるなら、≺ の順に大きい予算を割り当てる順序が A と B の両方で最小なので M=F。

*証明.* 前半は式を並べただけ。後半は交換論法: c ≺ c' と予算 b > b' について
f_c(b)+f_{c'}(b') ≤ f_c(b')+f_{c'}(b) は、両辺の差が Σ_{t=b'+1}^{b}[(f_c(t−1)−f_c(t)) − (f_{c'}(t−1)−f_{c'}(t))] ≥ 0 であることから従う
（f_{c'}(b') = ∞ なら仮定より f_c(b') = ∞ で両辺 ∞。使うのは t ≥ b'+1 ≥ 2 だけ）。順序を乱す対を入れ替えても A, B は増えないので、
≺ の順が A, B の共通の最小。∎

- （系 6 の仮定の下で）葉は予算 ≥ 1 なら 1 手で一定なので、葉以外の子が 1 個なら M=F（その子に最大の予算）。
  仮定（子の部分木で M=F）は外せない: 根の子を §4 の反例 T15 と葉 5 枚にした木（n=21, S=7）では M=107 < F=109（critic の BFS と独立な F）。
- （同じ仮定の下で）葉以外の子が 2 個 P, Q なら、M<F ⟺ 2 つの割り当て問題の最適な順が食い違う。§4 の反例はこの最小の例。
- **系 6'（くも）. 根の子がちょうど S−1 個で、各子の部分木が鎖（脚）なら M(T,S)=F(T,S)。**
  *証明.* 鎖では M=F（Knill Thm 2.1）。≺ を脚の頂点数の降順にとる。脚の長さ l ≥ l' について
  f_l(s−1)−f_l(s) − (f_{l'}(s−1)−f_{l'}(s)) = Σ_{n=l'+1}^{l} 2[δ(n,s−1) − δ(n,s)] ≥ 0 を言えばよく
  （δ(n,s)=(F_c(n,s)−F_c(n−1,s))/2。f_l(s−1)=∞ なら左辺は ∞）、これは鎖の**点ごとの支配 δ(n,s) ≤ δ(n,s−1)** そのもの。
  点ごとの支配は RevExact（arXiv:2609.15062）の Lean にある: `RevPebbling/CountRecursion.lean` の
  `gen_pointwise_dom : ∀ s i (hi : i < (rowIter s).length), (rowIter (s+1))[i] ≤ (rowIter s)[i]` と、`RowExact.lean` の
  `gameF_eq_row : ∀ s m, 1 ≤ m → m ≤ 2^(s+1) → gameF m (s+2) = Fpre (rowIter s) m`
  （`Fpre l m = 1 + 2·(l の先頭 m−1 項の和)`、`rowIter_length : (rowIter s).length = 2^(s+1) − 1`、`gameF` は鎖のゲームの盤操作
  `ReachIn` の最短手数）。よって δ(n,s+2) = (rowIter s)[n−2]（2 ≤ n ≤ 2^(s+1)）で、`gen_pointwise_dom` は
  s ≥ 3、2 ≤ n ≤ 2^(s−2) の範囲で δ(n,s) ≤ δ(n,s−1) を与える。これは F_c(n,s−1) が有限な範囲とちょうど一致し、
  範囲外（F_c(n,s−1)=∞）は上の ∞ の場合分けで扱える。
  公理: 原本 `~/dev/github.com/yokoyama-lab/reversible-pebbling-lean`（commit 0d3feab。zenodo 配布物 PROVENANCE の source_commit と同じ）の
  ビルド済み .olean を読み込んで `#print axioms` を実行し、両定理とも `[propext, Classical.choice, Quot.sound]` だけ
  （critic が先に実行し、本作業でも再実行して同じ出力。このセッションで再ビルドはしていない）。
  規則の常設仮定（RevExact の IEICE 原稿 `~/dev/overleaf/2026_exact_reversible_pebbling/ieice_paper.tex` 234 行、Preliminaries の定義、逐語）:
  "Nodes 1..n form a chain; the source (node 0) is permanently available. A move toggles a pebble on node i and is legal iff
  i = 1 or node i−1 carries a pebble."（arXiv 投稿版 §1 の文言は "A move toggles (places or removes) a pebble on node i and is legal
  if i=1 or node i−1 carries a pebble"。どちらも我々の規則を道に制限したものと同じ。）∎

## 4. 反例（頂点数 15）

T = 根 r の子が 5 個: 葉 ℓ_1, ℓ_2, ℓ_3、星 Y=(y; 葉 4 枚)、X=(x; 葉 a, b と z)、z の子は葉 p, q。
形で書くと `(...(....)(..(..)))`（`.` が葉）。n=1+3+5+6=15、S=6（根の子は 5=S−1 個）。

部分木の値（すべて手で確かめられる）:
- 葉: M=F=1（s ≥ 1）。
- Y: y を置く／外すには葉 4 枚と y で 5 個要る。s ≥ 5 で M(Y,s)=F(Y,s)=9（=2·5−1、下界と構成が一致）、s ≤ 4 で ∞。
- Z=(z; p, q): 同様に s ≥ 3 で 5、s ≤ 2 で ∞。
- X（6 頂点）: s ≥ 6 で M=F=11（=2·6−1）。s=4 は x の子が 3=s−1 個なので定理 5 が使える:
  置く側の予算 4,3,2 のうち Z は 3 以上が要るので位置 1 か 2、外す側の予算 3,2,1 では Z は位置 1 に強制。
  M(X,4) = 1 + (5+1+1) + (5+1+1) = 15、F(X,4) も同じ強制で 1 + (5+5) + (1+1) + (1+1) = 15。
  s=5 では F(X,5) ≥ 4·6−2·5−1 = 13（系 1'）。M(X,5) ≥ 11（自明）。
  s ≤ 3 では ∞（x と子 3 個で 4 個要る）。

**M(T,6)=51.** 定理 5 で、置く側の予算は位置 i に 7−i（6,5,4,3,2）、外す側は 6−i（5,4,3,2,1）。
- 置く側: X を位置 1（予算 6、11 手）、Y を位置 2（予算 5、9 手）、葉 3 枚（3 手）で 23。
  Y を位置 1 にすると X は予算 5 以下で ≥ 11 手なので 9+11+3=23 を下回らない。よって最小 23。
- 外す側: Y は 5 個要るので位置 1 に強制（9 手）、X は 4 個以上要るので位置 2（予算 4、15 手）、葉 3 手。27。
- M(T,6) = 1 + 23 + 27 = 51。

**F(T,6)=53.** 定理 5 の F の式で同じ σ を両方に使う。Y は外す予算 6−i ≥ 5 から位置 1 に強制、X は 6−i ≥ 4 から位置 2 に強制。
F(T,6) = 1 + [F(Y,6)+F(Y,5)] + [F(X,5)+F(X,4)] + 3·2 = 1 + 18 + F(X,5) + 15 + 6 ≥ 1+18+13+15+6 = 53。
F(X,5)=13 は構成で達成される（z の葉 p を先に保持してから z、a、b を置く: 部品 p{5,4}=2、z の残り{4,3}=6、a, b 4、x 1）ので F(T,6)=53。

**つまり** M(T,6) = 51 < 53 = F(T,6)。定理 5 の最適な形に並べた手順は「X を 6 個で置く → X を持って Y を 5 個で置く → 葉と根 →
葉 3 枚を外す → **X を先に**（Y と根を持ったまま 4 個で）外す → Y を（根だけ持って）5 個で外す」。X が {6,4}、Y が {5,5} の予算を使う。
（BFS が返した手順は、X の内部の片付けと Y の設置が交互に入るが、各部分木の手数と予算はこれと同じ。）
F の入れ子では Y が後に置かれれば先に 4 個で外すことになり不可能、Y が先なら X が {5,4} になって 2 手増える。
（手順そのもの: `RESULT.md` の証人。BFS は 51 が最短であることも全数で確かめた。）

## 5. 差はいくらでも大きい（族）

**命題 7（差 ≥ 2m の族。critic の提案を採用）.** m ≥ 1、S ≥ 2m+4。根の子を、j=1..m について
X_j=(x_j; 葉 L_j 枚と Z_j)（Z_j=(z_j; 葉 2 枚)、L_j=S−2j−2 ≥ 2）と Y_j=(y_j; 葉 S−2j 枚)、それに葉 S−1−2m 枚の、計 S−1 個とする。
このとき **F(T,S) − M(T,S) ≥ 2m**。

*証明.* X_j の頂点数は n_j=L_j+4=S−2j+2。x_j を置くには子 L_j+1 個と x_j で L_j+2=S−2j 個要り、Z_j は 3 個（≤ S−2j）で済むので
X_j の最小空間は S−2j。Y_j の最小空間は S−2j+1、予算がそれ以上なら M=F=2|Y_j|−1（星の F は葉を部品として置くだけなので同じ値）。
F 側: 定理 5 の F の式で、外す予算は位置 i で S−i。Y_j は位置 ≤ 2j−1、X_j は位置 ≤ 2j に置く必要がある。位置 1..2j−1 には
Y_1..Y_j と X_1..X_{j−1} の計 2j−1 個が入らねばならないので、j についての帰納法で Y_j は位置 2j−1、X_j は位置 2j に強制される。
よって X_j の置く予算は S−2j+1=n_j−1 で、系 1' より F(X_j,n_j−1) ≥ 4n_j−2(n_j−1)−1 = 2n_j+1。
M 側（上界だけ使う）: 補題 3・4 の (≤) の構成で、置く順だけ X_j を位置 2j−1（予算 n_j。全頂点を置いて 2n_j−1 手）、Y_j を位置 2j
（予算 S−2j+1＝Y_j の最小空間）に入れ替え、外す順は F と同じにする。Y_j の項は予算によらず同じ、葉は 1 手、外す側は M(X_j,s) ≤ F(X_j,s)。
よって F−M ≥ Σ_j [F(X_j,n_j−1) − (2n_j−1)] ≥ 2m。∎

検算（`family2.py`。F は `ftree.py`、M は定理 5 の式に部分木の値を入れたもの。部分木は 14 頂点以下で全数により M=F）:
m=1, S=6, n=15: 差 2（§4 と同形）／m=1, S=8, n=21: 差 2／m=2, S=8, n=30: 差 4／m=2, S=9, n=35: 差 4／m=3, S=10, n=49: 差 6／m=4, S=12, n=72: 差 8。
critic は m=2, n=30 で M=111 を自前の BFS でも確かめ、さらに (m,S)=(1,7),(1,9),(1,10),(1,12),(2,10),(2,11),(3,11) の 7 点でも差がちょうど 2m だった。
（計算したのはこの 13 点。差が一般にちょうど 2m かは示していない。示したのは ≥ 2m。）

## 6. 1 回の交差では足りない（n=23）

F に「2 つの部品の外す順を 1 回だけ入れ替える」構成を足した F2（`cross.py`, `cross_fast.py`）は、n ≤ 16 の全根付き木で M に一致した。
（n=15, 16 の反例はすべて M=F2。§4 の例も根の子は 5 個だが F2=51=M。）しかし定理 5 の割り当ては 2 つの独立な置換なので、
部品が 3 つ以上あると F2 で届かない場合がある。
例: 根の子が 星(葉 5)・星(葉 4)・鎖 8 頂点・葉 3 枚（n=23, S=7）。外す予算は 6,5,4 が 星5・星4・鎖に強制され、

## 7. Knill の論法が木で壊れる箇所

Knill の Thm 2.1 の証明は、まず最適解を「t_b（s_1 に初めて置く時刻）以降はどの時刻にも盤にペブルがある」形に正規化し
（knill.txt 99–102 行）、m(S;t)=「時刻 t の最下位のペブルの行」、m＝その [t_b,t_e] での最大値、t_m＝それをとる最後の時刻として手順を切る。
(i) [t_b,t_e] では行 ≤ m に常にペブルがあるので上の部分は S−1 個、(ii) t_m 以後は行 > m に常にペブルがあるので
下の部分を外す側は S−1 個、とする。

- **(i) が木では成り立たない。** 鎖では最初に置く葉と最後に外す葉が同じ s_1 なので「部分木 T_m が常に空でない」頂点 m が
  根以外にとれる。木では最初に置く葉と最後に外す葉が根の別の子の下にありうる。上の反例の最短手順では最初の手が X の葉、
  最後の手が Y の葉なので、常に空でない部分木を持つ根以外の頂点は無い。
- **これは並べ替えで直せる偶然ではない。** 鎖では保持する頂点がすべて 1 本の道に並び、上の部品は下の部品の頂点を入力に使うので、
  外す順は置く順の逆に**強制される**（Knill の分解が LIFO であることは道の構造から来る）。木では別の枝の部品どうしに依存が無く、
  補題 4 のとおり置く順と外す順は独立に最適化される。F はこれを LIFO に結びつけているので、2 つの割り当て問題の最適な順が
  食い違うと損をする（系 6）。反例では 2 つの部品の Δ(s)=F(·,s−1)−F(·,s) の大小が予算 5 と 6 で入れ替わっている
  （X は Δ(6)=2, Δ(5)=2、Y は Δ(6)=0, Δ(5)=∞）。これは 1 例での観察で、入れ替わりがあれば必ず損をするという主張ではない。
- 鎖の「行の整列」が木で破れる（原稿 6 節）のも同じ根から来ている可能性があるが、確かめていない。

## 8. 何が残るか（二分木）

原稿の表（完全二分木 T_h, h ≤ 12）に効くのは子が 2 個以下の木である。**確かめた範囲（全根付き木 n ≤ 16、子 2 個以下 n ≤ 18）の反例は
すべて、子を 3 個以上持つ頂点を含む**（n=15 の 137 本は「子の数の最大」が 3 が 6 本・4 が 103 本・5 が 28 本）。
二分木では根を置く瞬間に要る子が 2 個だけなので、定理 5 の「保持集合が根の子に強制される」状況は S ≥ 4 では起きない。
ただしこれは二分木で反例が出ないことの説明としては弱い: n=15 の 137 本のうち根の子がちょうど S−1=5 個（定理 5 の形）なのは 28 本だけで、
残り 109 本は根の子が 1〜4 個（critic の分類。本作業の集計でも根の子の数は 1:54, 2:26, 3:9, 4:20, 5:28）。
定理 5 の外でも同じ機構（独立な部品の外す順の入れ替え）が働いている。

- 計算での照合（層ではない）: 子 2 個以下の全木で M=F は n ≤ 18（n=19 は実行中）、F2=F は n ≤ 19。
  T_h では F2=F が h ≤ 9 の p_min、h=7 の p_min+1, +2、h=8 の p_min+1 で成り立った。範囲は `RESULT.md`。
- **予想（未証明）**: 子が 2 個以下の木では M=F。これが成り立てば表の h ≤ 12 は厳密値。反例の機構（独立な部品の外す順の入れ替え）は
  二分木でも深い段で起こりうるので、楽観はできない。
- 一般の木の正しい再帰の候補は、各段で置く順と外す順を独立にした G（`gdec.py`）。G は構成で F を特別な場合として含むので M ≤ G ≤ F
  （G ≤ F2 は示していない。n ≤ 11 の全木では G=F2）。検査した例（n=15 の反例 137 本すべて、n=23）では G=M。一般に M=G かは未決（森の上の多目標 d_B(∅,C) が、C の頂点を 1 つずつ置く順の最小に
  等しいかが鍵。C が独立な部分木の根だけなら補題 4 で示した）。
