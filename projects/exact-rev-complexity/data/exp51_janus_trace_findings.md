# 実装の実行トレースを取って厳密最適と比較した（2026-07-27）

`docs/51_paper_plan_candidate3.md` §4 の**穴 1（最大の弱点）**を埋めるための計測。
実装 `scripts/exp51_janus_trace.py`。

## 1. 方法

PyJanus（`~/dev/github.com/yokoyama-lab/PyJanus`、**読み取り専用でインポート。変更していない**）の
`Runtime` を継承し、**各文の実行後にメモ表の非ゼロ添字集合を記録**する。対応は:

| 実装 | 本モデル |
|---|---|
| `M[i]` が 0 → 非 0 | 節点 $i$ に **put** |
| `M[i]` が 非 0 → 0 | 節点 $i$ から **take** |
| 同時に非ゼロな要素数の最大 | **ピーク $p$** |

対象は `~/dev/overleaf/2017_rev_memoization/program/` の `fib.janus`（対 Fibonacci）と
`fac.janus`（階乗）。**2021 の cut rod 系は未計測**（$\S5$）。

## 2. 結果

| プログラム | メモ表 | 異なる配置 | 正規化後の手数 | **ピーク** | 触れた添字 | **終端配置** |
|---|---|---:|---:|---:|---|---|
| `fib.janus` | `M[10]` | 71 | 70 | **10** | 0–9（全部） | **0–9（全部）** |
| `fac.janus` | `t[10]` | 9 | 8 | **6** | 0–6 | 0,1,2,3,4,6 |

## 3. 最大の発見: **実装は clean ではない**

**両プログラムとも終端でメモ表が空になっていない。**

- `fib.janus`: **ピーク 10 = メモ表全体**。終端でも 0–9 の全要素が非ゼロ。
- `fac.janus`: 終端に 6 要素が残る（`t[5]` だけが途中で消される）。

したがって:

1. **これらは clean 可逆ペブリングを実行していない。**
   我々の検証器（clean 終端を要求）にはそもそも通らない。
   → 「実装は clean 可逆ペブリングを実行している」という仮説は**反証された**。
2. **空間は $\Theta(n)$**（表全体）。`fib.janus` のピークはメモ表のサイズそのものである。
   一方、対応する鎖（対 Fibonacci は $k$ を 2 ずつ減らすので添字 0–9 は 5 対 = 長さ 5 の鎖）の
   clean 最適は $p_{\min}=4$、$M^*=11$。**実装のピーク 10 に対し理論の最適は 4。**
3. これは `data/exp03_results.md` §D.3 で**モデル上の推論として**述べた
   「実装はガベージ蓄積の極（$\Theta(n)$ 空間・熱 0）にいる」を、
   **2017 年の実装についても実測で確認した**ことになる
   （§D.3 は 2021 年の cut rod 実装のコード読解に基づいていた）。

## 4. 比較の限界（正直に）

**手数 70 を $M^*$ と直接比較してはいけない。** 理由:

- `fib.janus` の `main` は **`call fib` を 18 回**行う（同じ $n$ で繰り返し呼び、
  メモのヒット／ミスの挙動を見せるためのテストハーネスになっている）。
  したがってトレースは「1 回の clean な計算」ではなく **18 回の呼び出しの合成**である。
- メモを**消費する**設計（ヒット時に `M[k-1] ^= r1; M[k] ^= r2` で消す）なので、
  呼び出しごとにヒットとミスが交替する。手数はその総和。
- $M^*$ は「空から始めて目標だけを残す 1 回の計算」の最小手数なので、**分母が違う**。

→ **公正な比較には、`main` を「1 回だけ呼ぶ」版に書き換えて計測する必要がある**（§5）。
本節で確定したのは**ピークと clean 性**であり、これは呼び出し回数に依存しない。

## 6. 手続き上の記録

- PyJanus の `parse_program` は方言ごとに別モジュールにあり、
  **`jana_py.cli.parse_for_std(std, filename, text, line_origins)` 経由で呼ぶ**のが正しい
  （`parse_program(src, path, std=...)` は存在しない）。
- メモ表の変数名はプログラムごとに違う（`fib.janus` は `M`、`fac.janus` は `t`）。
  **名前を決め打ちにすると「配置 0 個」という無言の失敗になる**ので、
  最初に宣言を読んで確認すること（実際に一度踏んだ）。
