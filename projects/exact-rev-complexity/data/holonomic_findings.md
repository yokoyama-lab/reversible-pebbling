# holonomic guessing を全数列に適用した結果の読み取り（2026-07-27）

生データ: `data/holonomic_guess.md`（自動生成）／実装 `scripts/holonomic.py`／テスト `tests/test_holonomic.py`

## 1. 結果: **15 本中 0 本**

本プロジェクトで得た厳密数列 15 本すべてで、$order \le 4$・$degree \le 4$ の範囲に
P-recursive な漸化式は**見つからなかった**。

## 2. 実装が働いていることの確認（この否定的結果の前提）

「見つからない」を主張するには、まず実装が**見つけられる**ことを示す必要がある。
`tests/test_holonomic.py`（10 件）に加え、より難しい既知例で確認した:

| 数列 | 期待 | 結果 |
|---|---|---|
| Fibonacci | order 2 / degree 0 | ✅ 発見 |
| Catalan | order 1 / degree 1 | ✅ 発見 |
| 階乗・中央二項係数 | order 1 / degree 1 | ✅ 発見 |
| **Motzkin** | order 2 / degree 1 | ✅ `(3n+3)a(n)+(2n+5)a(n+1)-(n+4)a(n+2)=0` |
| **中央 Delannoy** | order 2 / degree 1 | ✅ `(n+1)a(n)-(6n+9)a(n+1)+(n+2)a(n+2)=0` |

| 素数列 | 存在しない | ✅ 正しく None |

→ 実装は健全。0/15 は実装の失敗ではない。

## 3. なぜ見つからないのか（本節が本当の成果）

**この分野の厳密再帰は線形ではなく min-plus（トロピカル）だから。**

Knill 1995 の $F(n,S)$ の厳密再帰は「分割点にわたる **最小化**」の形をしている:

$$F(n,S) \;=\; \min_{k} \Big( F(k, S) + F(n-k, S-1) + \cdots \Big)$$

holonomic guessing が仮定するのは

$$\sum_i p_i(n)\, a(n+i) = 0 \quad (p_i \text{ は多項式})$$

という**線形**な関係である。$\min$ は線形演算ではないので、
**最小化を含む量が P-recursive になる理由がそもそも無い。**
実際 Knill 自身が「閉じた式は無い」と明言している。

これは我々の観測とも整合する:

- $M^*(p_{\min})$ の数列は $p_{\min}$ の段差で**値が減る**（ピラミッド $105\to99$、
  spinal $61\to57$）。線形漸化式が持つはずのない不連続性である。
- 段差を避けて固定 $p$ で取った数列（鎖 $p=5$ で 16 項、$p=6$ で 32 項）でも見つからない。
  **つまり区分性を除いても holonomic ではない。**

## 4. 方法論上の帰結（今後どうするか）

### 4.1 当てはめの4連続崩壊は「運が悪かった」のではない

`docs/00_overview.md` §2.1 の4件（$3h^2-h+3$、$2\cdot3^h-1$、$\Theta(n^{\log_2 3})$、
OEIS A001845 との4点一致）は、**そもそも存在しないものを探していた**可能性が高い。
多項式・指数・P-recursive はいずれも線形の世界の住人であり、
min-plus 再帰から出る数列がそこに落ちる保証はない。

→ **「閉形式を探す」を既定の目標から降ろす。** 閉形式が無いこと自体が
Knill 以来の既知の事実であり、我々の貢献は別の場所（厳密値・構造・段差の位置）にある。

### 4.2 使うべき機械は holonomic ではなく min-plus（トロピカル）代数

`docs/30_cross_field.md` §2 の見立ては**外れた**。正しい機械は:

- **min-plus 線形代数**: $(\min, +)$ 半環上の行列積・固有値。長時間挙動は
  **トロピカル固有値＝周期的漸近**を与える。「$M^*(n,p)$ は最終的に周期 $\times$ 線形」型の
  法則が出るなら、これで捉えられる。
- 先行プロジェクトの**区間代数**（`count_algebra.py`）は、実質この方向の自作版だった。
  「厳密整数値ベクトル＋Newton 差分＋漸近順序オラクル」は min-plus の直観を近似している。
- **`~/dev/CLAUDE.md` の方針「区間代数エンジン化で $v\le32$・$P_5$ まで一挙に到達」は、
  この分析と整合する。** 手計算でも線形当てはめでもなく、半環構造に沿った機械が効いた。

### 4.3 具体的な次の一手

1. **$M^*(n,p)$ を固定 $p$ で min-plus の遷移行列として書けるか試す。**
   状態＝「現在のペブル配置の同値類」、演算＝$(\min,+)$。書ければ
   トロピカル固有値から $n\to\infty$ の漸近が**厳密に**出る。
2. 出ない場合でも、**差分列の周期性**を調べる（min-plus 系は eventually periodic な
   差分を持つことが多い）。鎖 $p=6$ の 32 項で差分の周期を検定する。
3. holonomic guessing は**捨てない**: 今後どの数列にも自動で走らせ、
   「見つからなかった」を記録に残す。**探索範囲を明記した否定的結果**は、
   当てはめを試みる誘惑への恒久的な歯止めになる。

## 5. 論文に書ける形

「reversible pebbling の厳密値は低階の P-recursive 漸化式を持たない（$order\le4$,
$degree\le4$ で全数検査）」は、**Knill の『閉じた式は無い』を定量化した小さな新事実**である。
単独では弱いが、厳密表の論文に 1 段落として入れる価値がある
（「なぜ表を出すのか＝閉形式が無いから」の根拠になる）。
