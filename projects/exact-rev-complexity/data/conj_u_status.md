## 2. 還元のメタ議論（紙・層2 相当。残る実体は補題 A(≥)・B・C の一般 $p$）

記法: $R_u$ = ちょうど $u$ 回消去済みで到達可能な配置の族。可逆手（put／支持つき
take）は互いに逆なので層内は無向、よって
$R_0 = \mathrm{RevClose}(\{\emptyset\})$、$R_u = \mathrm{RevClose}(\mathrm{erase}(R_{u-1}))$。
$W$ = U の DP 値。

1. **A(≤)**（1 行）: 支持つき $x$ を最後にコミットすると $C(1; p-k) = 0$
   （$k{+}1\le p$ なら自由 $\ge1$）。よって $W(S\cup\{x\}) \le W(S)$。
2. **A(≥)**（SMT で $p\le5$ 確認済み・一般 $p$ 未証明）:
   $W(S) \le W(S\cup\{x\})$（支持つき $x$ の除去で増えない）。
3. **B**（同上）: 支持なし $x$ の除去で $W$ は高々 $+1$。
4. **C（構成、上界側）**: $W(S) \le u \Rightarrow S \in R_{u'}$（$u' = W(S) \le u$）。
   最適順序どおりに確定し、各確定は区間の B1 型構成（Bennett 登り＋消去前進。
   `exp03_reach.construction` が単一区間で機械検証済み）で実現する。
   作業領域は $(\mathrm{pred}, s]$ に収まり確定済みに触れない。消去数は $\sum C$。
5. **帰納**: $S \in R_u$ なら、erase 辺で B、層内の辺で A（両向き）を適用して
   $W(S) \le u$。C と合わせ $R_u = \{W \le u\}$…に見えるが、正確には
   **層の単調性**（$u' < u$ でも $S \in R_u$）に空焚き補題が要る:
   $S$ から `put f+1, put f+2, take f+1, erase f+2` で $u{+}1$ 層の $S$ に戻る。
   側条件 $|S|+2 \le p$ かつ $f+2 \le n$。**側条件が破れる角のケース**
   （$|S| \ge p-1$ や先端が鎖の端）は BFS 実測では常に別経路の空焚きで救われて
   例外ゼロだったが、紙の証明ではここに場合分けが要る（未着手の穴 #3）。

**残る穴**: (#1) A(≥) の一般 $p$、(#2) B の一般 $p$、(#3) 空焚きの角ケース、
(#4) C の合成の書き下し（区間構成が交差しないことの明示）。
→ #1・#2 は §2.5 の共同帰納法で**大半のケースを紙で閉じた**。残る角は 1 型のみ。

### 2.5 補題 A(≥)・B の共同帰納法（2026-08-10 午後。紙・ほぼ完成）

**補助不等式（証明済み・1 行ずつ）**: $q\ge2$ で
(i) $C$ は $g$ について単調非減少、$q$ について単調非増加。
(ii) **$C(g{+}1;\,q{+}1) \le C(g;\,q)$**（分子は $2^{q-1}{-}1$ 減り分母は倍。
閾値側も $g\le2^{q-1} \Rightarrow g{+}1 \le 2^{q}$ ✓）。$q=1$ 側も
$C(g{+}1;2) \le C(g;1)$（$g{=}1$: $0\le0$、$g\ge2$: 有限 $\le \infty$）✓。
(iii) $C(2g;\,q{+}1) = C(g;\,q)$（補題 D の項別形）。

**補題 A(≥) の証明（帰納法、$|T|$ について）**: $T = S\cup\{x\}$、$x{-}1 \in S\cup\{0\}$、
$\sigma^*$ を $T$ の最適順序、$\ell$ を最後のコミットとする。
- **場合 1: $\sigma^*$ で $x{-}1$ が $x$ より先**（$x=1$ の $x{-}1=0$ を含む）:
  $x$ の pred は $x{-}1$ でコスト 0。$x$ を**削除**すると、以後の全要素は自由 $+1$、
  $x$ を pred にしていた要素（依存者）は pred が $x{-}1$ に落ちてギャップ $+1$
  → (ii) で吸収、その他はギャップ不変 → (i) で吸収。帰納法不要で閉じる。∎
- **場合 2a: $x{-}1$ が $x$ より後で $\ell = x$**: 接頭辞が $S$ の順序そのもの。∎
- **場合 2b: $x{-}1$ が後で $\ell \notin \{x, x{-}1\}$**: $T' = T\setminus\{\ell\}$ に
  帰納法（$x{-}1 \in T'$ なので適用可）: $W(T'\setminus x) \le W(T')$。
  $S = (T'\setminus x)\cup\{\ell\}$ は「$T'\setminus x$ を最適に→$\ell$ を最後に」:
  $\ell$ の pred が $x$ だった場合はギャップ $+1$・自由 $+1$ → (ii)、
  そうでなければギャップ同・自由 $+1$ → (i)。∎
- **場合 2c（残る唯一の角）: $\ell = x{-}1$**（支持が最後のコミット）:
  **局所手術では原理的に閉じないことを機械で確定させた**（2026-08-10 午後）:
  - 置換（$x$ のスロットへ $x{-}1$）: 反例 $\sigma^* = [2,6,1]$（$p{=}4$, $x{=}2$）。
    置換後 $[1,6]$ は $C(5;3){=}1 > \mathrm{cost}(\sigma^*){=}0$。勝ち手は依存者 6 の
    **昇格**（$[6,1]$: $C(6;4){=}0$）。掃引では 21,426 順序中 793 で置換が超過。
  - 依存者昇格（$x$ のスロットへ依存者 $d_1$）も普遍でない: 必要な超加法性
    $C(a{+}b;q) \le C(a;q) + C(b;q{-}1)$ は偽（$a{=}8,b{=}4,q{=}4$: $1 > 0$）。
  - つまり角は **min 対 min の大域的性質**。順序 1 本ずつの写像では証明できない。
  - **有効な帰着（A′）**: 「両側とも $x{-}1$ を最後に固定した min 対 min」
    $\min_{S,\,x{-}1\text{ last}} \le \min_{T,\,x{-}1\text{ last}}$ は
    $p{=}4,5$ の 7,621 インスタンスで反例 0。$W(S) \le \min_{S,\text{restr}}$ は
    自明なので **A′ ⟹ 角 2c**。A′ は最終項を両側で共有し（自由は左が $+1$）、
    SMT の順序空間も両側 $(m{-}1)!/(m{-}2)!$ に縮む——p=7 で角 SMT が
    詰まったときの代替定式化。なお最終項を「剥がす」と主張は
    「スラック 0 の B」に堕ちて偽になるので、**最終項の自由差が本質的に
    結合している**（分離不能）ことも判明。

**補題 B の帰納法**も同じ骨格で進み（$\ell = x$: 接頭辞で $+0$、
$\ell$ の pred $\ne x$: (i)/(ii) で吸収）、残るのは
「削除した $x$ の直上の依存者がギャップ合流 $C(g_1{+}g_2)$ を食らう」角 1 型。
**A・B の未証明部分は同一の現象**（依存者の再ギャップに対する大域的並べ替え）
に集約された。

### 2.6 補題 C（構成側）の紙証明（2026-08-10 午後、完成）

**証明**: 最適順序 $\pi$ に沿う帰納法。不変条件「$i$ 手目終了時、盤面 = 確定済み
$i$ 個ちょうど、消去累計 = $\sum_{j\le i} C_j$」。$i{+}1$ 手目、$x$ を pred $w$ から

## 3. 倍化恒等式（新規・証明済み・層2）

> **補題 D**: $|S| \le p-1$ なら $W(2S;\, p{+}1) = W(S;\, p)$
> （$2S = \{2s : s\in S\}$）。

**証明**: 順序 $\pi$ は両側で 1:1。倍化は順序と 0 を保つので、各ステップの
pred も倍化され、ギャップは正確に 2 倍。ステップ $i$ の自由本数は左が
$q+1$、右が $q$（$q = p-(i-1)$）。$|S| \le p-1$ より常に $q \ge 2$。
$q\ge2$ では $C(2g; q{+}1) = C(g; q)$ が成り立つ:
閾値は $2g \le 2^{q} \iff g \le 2^{q-1}$ で一致し、正側は
$\lceil (2g-2^{q})/2^{q-1} \rceil = \lceil (g-2^{q-1})/2^{q-2} \rceil$
（分子分母 2 倍で ceil 不変）。よって順序ごとのコストが項別に一致。∎

### 3.1 $|S| = p$ では偽（仮定が本質的）

$S = \{2,4\}$, $p=2$: 全順序が $C(\cdot;1)=\infty$ を踏み $W = \infty$
（実際 $\{2,4\}$ は $p=2$ で到達不能）。一方 $2S = \{4,8\}$, $p=3$ は
$W = 2$（実測の対表 gap=4, a=4 → $u_{\min}=2$ と一致）。
最終コミットの自由本数が 1 から 2 に上がるため。

**使い途**: (i) 反例ハントの指針——U が破れるなら、その最小反例は
「奇数ギャップを含むか $|S|=p$」の側にある（偶数ギャップ・$|S|<p$ の族は
補題 D で 1 段下の $p$ に写るので、小さい $p$ の全数検証が反例を先に見つけて
いるはず）。(ii) 補題 A/B の一般 $p$ 証明の足がかり——偶数部分は下へ落ち、
奇数の丸めだけが本体（未完）。
