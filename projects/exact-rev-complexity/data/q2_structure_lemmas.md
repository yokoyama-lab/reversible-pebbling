# 時間最適な並列可逆ペブリング（鎖）の構造補題 — 証明への足場

**2026-08-13 夜勤。**$n^*(p) = (p-2)(p-3)+5$ を証明するための下準備。
実測は `q2_parallel_findings.md`（$p=4..9$ で確定・下界は DRAT で層2）。

記号: 鎖 $L_n$ の頂点を $0 \to 1 \to \cdots \to n-1$、sink $= n-1$。
配置列 $P_0 = \emptyset, \dots, P_T$、$P_T = \{n-1\}$（clean）、$\max_t |P_t| \le p$。
可逆性（BHL Def. 1 を合成した形）:
$$v \in P_{t}\triangle P_{t+1} \;\Longrightarrow\; v-1 \in P_t \cap P_{t+1} \quad (v \ge 1)$$

---

## 補題 L3（同時に変化する頂点は隣接しない）— **証明済み**

**主張**: 各 $t$ で、変化集合 $C_t := P_t \triangle P_{t+1}$ は鎖の**独立集合**。
すなわち $v \in C_t \Rightarrow v-1 \notin C_t$。

**証明**: $v \in C_t$ なら可逆性より $v-1 \in P_t \cap P_{t+1}$。
一方 $v-1 \in C_t$ は $v-1 \notin P_t \cap P_{t+1}$ を意味する。矛盾。∎

> **系**: 各ステップで変化する頂点は互いに 2 以上離れている。
> **「1 ステップで隣り合う 2 つを動かす」ことはできない**——並列化の効きにくさの源。

## 補題 L2（最終除去は頂点の降順・時刻の昇順）— **証明済み**

**主張**: $\tau_i :=$ 頂点 $i$ が最後に除去される時刻（$0 \le i \le n-2$）とすると
$$\tau_{n-2} < \tau_{n-3} < \cdots < \tau_1 < \tau_0 .$$

**証明**: $i+1$ を時刻 $\tau_{i+1}$ に除去するには可逆性より $i \in P_{\tau_{i+1}}$。
もし $\tau_i < \tau_{i+1}$ なら $i$ は $\tau_i$ 以降ずっと不在なので矛盾。∎

> **系（時間の下界）**: $\tau_{n-2} \ge n$（頂点 $n-2$ は時刻 $n-1$ に初めて置ける）かつ
> $\tau_i > \tau_{i+1}$ なので $\tau_0 \ge 2n-2$。**したがって $T \ge 2n-2$。**
> clean 到達には sink 以外を全部消す必要があり、実測はすべて $T = 2n-1$。

## 補題 L1（初出時刻は固定）— **ほぼ強制**

**主張**: $T = 2n-1$ のとき、頂点 $i$ が初めて置かれるのはちょうど時刻 $i+1$。

**理由**: 深さより $i$ は時刻 $i+1$ より早くは置けない。
また L2 の系より $\tau_i$ の列は $[n, 2n-1]$ にほぼ隙間なく詰まる必要があり、
sink は時刻 $n$ に置かれねばならない。sink を時刻 $n$ に置くには
$i$ が時刻 $i+1$ に在ることが要る。∎（詳細は要清書）

$$\boxed{T_\parallel(G) = 2\cdot\text{depth}(G) - 1}$$

**実測で見つけた統一則が完全な定理になった。**

```
theorem par_time_exact_dag
    (hs : sink ∈ V) (hds : dep sink = d) (hd : 1 ≤ d)
    (hmax : ∀ v ∈ V, dep v ≤ d) (huniq : ∀ v ∈ V, dep v = d → v = sink)

    Pebbling pa (layered V dep sink d) (2*d+1) ∧

```

**上界の構成 `layered`**: 深さの層ごとに置き（$d{+}1$ 手）、層ごとに崩す（$d$ 手）。

```
layered V dep sink d t =
  if t ≤ d+1 then {v ∈ V : dep v < t}
  else insert sink {v ∈ V : dep v < 2d+1-t}
```

**鍵**: `layered_down`（$t = d{+}1$ で前半・後半の式が一致する）を先に補題にして
場合分けの境界を消したこと。鎖のときと同じ詰まり方をした。

⚠ **ピークに制約は課していない**（`layered` は最大 $|V|$ 個使う）。
空間を絞ったときの $n^*(p)$ は別問題（DRAT の層2）。

#### 下界の詳細（先に証明した部分）

```
theorem time_lower_bound_path
    (hp : Pebbling pa P T) (hw : ∀ j, w j ∈ pa (w (j + 1)))
    (hsink : w (d + 1) ∈ P T) (hgone : ∀ j, j ≤ d → w j ∉ P T) :
    2 * d + 3 ≤ T
```

経路 $w_0 \to \cdots \to w_{d+1}$ の頂点数は $d+2$ なので、これは
$$T \ge 2\cdot(\text{経路の頂点数}) - 1$$
すなわち **$T \ge 2\cdot\text{depth} - 1$**。

**ピラミッド（深さ $h$）に当てると $T \ge 2h-1$。**
実測では十分な空間でこの下界が達成される（統一則。$h=6$ で場外検定的中）ので、
**空間無制約なら $T_\parallel = 2\cdot\text{depth}-1$ が両側とも決着した。**

⚠ **$2d+4$ は証明できない**（変異注入で確認）＝**下界はタイト**。

⚠ 途中で**自分の主張が証明より弱かった**ことに変異注入で気づいた
（$2d+1$ と書いたが実際は $2d+3$ が出ていた）。**変異が「通ってしまった」ときは、
検査の失敗ではなく主張が弱い可能性を先に疑う。**

### ⭐⭐ 鎖版の主定理: **時間の厳密な下界**

```
theorem time_lower_bound (hp : Pebbling P T) (hclean : P T = {n-1}) (hn : 2 ≤ n) :
    2 * n - 1 ≤ T
```

**鎖 $L_n$ の clean な並列可逆ペブリングは、少なくとも $2n-1$ ステップかかる。**
実測ではこの下界がちょうど達成されるので、**空間無制約なら $T_\parallel(L_n) = 2n-1$ が完全に決着**した。

**証明の骨格**（すべて機械検証済み）:

1. `depth_bound` — 頂点 $v$ は時刻 $v$ 以前には置けない（$t$ の帰納法）
2. `exists_placement` / `exists_removal` — 在否が変わるなら、その瞬間が存在する
3. `parent_later` — $v \ne n-1$ が時刻 $t$ に居るなら、親 $v-1$ は**より遅い時刻**に居る
   （$v$ は最後に消えねばならず、消す瞬間に親が要るため）
4. `descend` — 3 を $k$ 回繰り返す（階段）
5. `time_lower_bound` — sink は時刻 $\ge n$ に置かれ、その瞬間に $n-2$ が居る。
   そこから $n-2$ 段下ると頂点 0 が時刻 $\ge 2n-2$ に居る。0 も消えるので $T \ge 2n-1$

## ⭐ 見えてきた仕組み: **接頭辞の作り直しが線形時間かかる**

L2 の系より、降下は **1 ステップにつき最終除去 1 個**でほぼ埋まる
（$\tau_0 > \cdots > \tau_{n-2} \ge n$ と $T = 2n-1$ から $\tau_0 \in \{2n-2, 2n-1\}$）。
つまり降下の各ステップで、**頂点 $i$ を消すために $i-1$ が在ることを要求される**。

$\tau$ は $i$ の降順に増えるので、**低い番号ほど遅い時刻に必要**になる。
空間 $p$ の制約から、上昇中に低い番号は捨てざるを得ない。**捨てたものは後で作り直す。**

**ここで L3 が効く**: 頂点 $j$ を置くには $j-1$ が前後に在らねばならず、
かつ $j$ と $j-1$ は**同じステップで動かせない**。よって
$$\text{接頭辞 } 0,1,\dots,k \text{ を作り直すには } k+1 \text{ ステップ必要}$$
（0 を置き、次に 1 を置き…と**逐次にしか進めない**）。

**総ステップ数は $2n-1$ しかない。**「降下の各ステップは最終除去で埋まっている」
「作り直しは逐次で線形」——この 2 つが $n$ の上限を作っている、というのが現在の見立て。

⚠ **これは見立てであって証明ではない。**ただし
**閉じた式が存在しない可能性**を示唆する（下の実測がそれを支持する）。

## ⚠ まだ埋まっていない穴（ここが本丸）

**空間 $p$ が $n$ の上限を決める仕組み**が未証明。素朴な計数では届かない:

- 変化の総数は $c = (2n-1) + 2r$（$r$ = 一時除去・再配置の対の数）
- 1 ステップの変化数 $k_t$ は、各変化が「親が在って動かない」ことを要求するので
  $k_t \le |P_t| - (\text{その手の除去数}) + 1$
- これを足しても $r$ に**二次の上限が出ない**（線形の緩い上限にしかならない）

**足りない要素**: 「頂点 $i$ は遅い時刻 $\tau_{i+1}$ に**在らねばならない**」という
**要求の時刻分布**を、空間 $p$ の制約と突き合わせる議論。
Král'ovič (2004) Lemma 3.2（時間最適な計算は対称）が使えるはず。
