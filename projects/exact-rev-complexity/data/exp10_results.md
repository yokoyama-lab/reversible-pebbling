## ① 自明性の判定 — 統合担当の疑いは正しい。素朴版は自明かつ既知

**結論: `docs/idea10` §6 の「Hall の結婚定理で達成可能性を証明する」は誤り。Hall は不要。**

素朴な定式化（本稿で **自由ガベージ模型 (F)** と呼ぶ）は

> $f : \{0,1\}^n \to \{0,1\}^m$ に対し、単射 $x \mapsto (f(x), \gamma(x))$ を与える
> $\gamma : \{0,1\}^n \to \{0,1\}^g$ が存在する最小の $g$

であり、これは次の理由で**数え上げだけで決まる**:

- 単射性は「各ファイバー $f^{-1}(y)$ 上で $\gamma$ が単射」と同値。
- **ファイバーは互いに素で、しかも割り当て先の制約もファイバーごとに独立**
  （ファイバー $y$ の元は $\{y\}\times\{0,1\}^g$ にしか行けず、他のファイバーと衝突しない）。
- よって $|f^{-1}(y)| \le 2^g$ が全 $y$ で成り立てば、**ファイバーごとに勝手な単射を選んで
  貼り合わせるだけ**でよい。二部グラフの大域的な結婚条件（Hall）を使う場面が無い。

これを Lean で形式化した（`garbage_iff_card_fiber_le`）。証明に使ったのは
「濃度が小さければ埋め込みが存在する」（`Function.Embedding.nonempty_of_card_le`）だけで、
Mathlib の Hall（`Finset.all_card_le_biUnion_card_iff_exists_injective`）は**一度も使っていない**。

### 置換であることを要求しても自明性は崩れない（(b) の否定）

部分単射を全単射に延長するのは、定義域と値域の補集合が同濃度なら常に可能。
入力を $(x, 0^{a})$ に置く（アンシラ $a = (m+g)-n \ge 0$）ならこの条件は自動的に満たされる。
実験 E で構成的に確認した（`parity_is_free_with_ancilla`）。

### 入力保存型（Bennett 型, (a)）も、そのままでは問いにならない

$(x,0) \mapsto (x, f(x))$ を要求すれば、ガベージは $x$ そのものに固定されるので
$g = n$ が定義から出るだけで、最小化する自由度が無い。
**ただし「入力の一部だけ残す」に緩めると非自明になる**（→ ②）。

### 既知性（一次文献の本文）

| 文献 | 該当箇所 | 内容 |
|---|---|---|
| Maslov–Dueck 2004, TCAD 23(11):1497–1509 | **Theorem 1**（本文 §III） | 「$n\times m$ 関数を可逆化するのに必要なガベージビットの最小数は $\lceil\log_2 q\rceil$（$q$ = 真理値表で最も多く現れる出力パターンの重複度）」。証明は**1 段落**。「最大重複度のものを分離できれば他は容易に分離できる」 |
| Soeken–Wille–Keszőcze–Miller–Drechsler, arXiv:1408.3586, §II | 定義の直後 | 「**It is not hard to see that** $\ell(f) = \lceil\log_2 \mu(f)\rceil$ is both an upper and a lower bound (and thus an optimal bound) for $k$.」 |
| 自分たちの `2022_minimum_garbage/clean-to-NGC.tex` | line 137 の脚注 | 「the number of garbage lines is minimized to $\lceil\log_2 k\rceil$」を **Toff80, MaDu06 を引いて既知として**述べている |

**つまり自分たちの論文が既に「既知」として脚注に書いていた事実である。**
これを Lean で証明しても数学的な新規性は無い（形式化としての価値のみ）。

## ② 選んだ定式化 — 非自明になるのは (c) と、(a) を緩めた「射影ガベージ模型」

自明性が崩れる場所を 4 つ検査し、次の判定を得た。

| 模型 | 非自明か | 理由 |
|---|---|---|
| (F) 自由ガベージ | ❌ 自明 | 上記。ファイバーごとに独立 |
| (b) 置換を要求 | ❌ 自明 | 部分単射の延長は常に可能 |
| (a) 入力全保存 | ❌ 問いにならない | ガベージが $x$ に固定される |
| **(P) 射影ガベージ**（(a) を緩め、入力ビットの**部分集合** $S$ だけ残す） | ✅ **非自明** | 下界が緩む。実際に反例あり |
| **(G) ゲート引数個数の制約** | ✅ **非自明** | パリティ障害。ただし**既知**（→ ⑤） |
| (e) 入力が簡潔表現（回路・BDD）で与えられる | ✅ 非自明 | 計算量が上がる。ただし**既知**（coNP 困難、→ ⑤） |

**採用した主定式化 (P)**:

$$g_{\mathrm{proj}}(f) = \min\{|S| : S \subseteq [n],\ x \mapsto (f(x), x|_S)\ \text{が単射}\}$$

これは Bennett 型埋め込み（$g=n$）の節約版で、**実装が実際に作る形**（入力線を通す）に近い。
$g_{\mathrm{proj}}$ は自由ガベージの特殊形なので $\lceil\log_2\max_y|f^{-1}(y)|\rceil \le g_{\mathrm{proj}}(f)$
（Lean: `proj_lower_bound`）だが、**この下界は緩む**。

同値な言い換え（Lean: `projOK_iff_subcube`、Python 二重実装の根拠）:
> $S$ が使えることは「**$S$ のビットを固定した各部分キューブ上で $f$ が単射**」と同値。

したがって $g_{\mathrm{proj}}(f) = n - \max\{|T| : T$ の外を固定した各部分キューブ上で $f$ が単射$\}$。

**なぜこれを選んだか**: (G) と (e) は非自明だが既知（⑤）。(P) は**下界が緩む唯一の模型**であり、
`docs/idea10` §2 が「一番おいしい問い」と書いた「情報論的下界が緩む最小の反例関数」は
**この模型でのみ意味を持つ**。

## ④ Python 全数計算と Lean 主張の照合

生ログ: `data/exp10_scan.txt`。

### 実験 A — 自由ガベージ模型で下界は常に達成される

- $n=3$ の**全 4140 集合分割**（= 出力ラベルの付け替えを除く全関数。$g_{\mathrm{free}}$ と
  下界はファイバー分割のみで決まるので、これで**全 $m$ を一挙に覆う**）で
  $g_{\mathrm{free}} = \mathrm{lb}$ の**不一致 0 件**。
- 閉じた式と**素朴な後戻り探索**（`g_free_bruteforce`、式を一切使わない）の二重実装照合:
  198 件で不一致 0 件。
- → Lean の `garbage_iff_card_fiber_le` と整合。

### 実験 B — 射影ガベージ模型では下界が緩む（$n=3$ 全数 4140 分割）

| $(\mathrm{lb}, g_{\mathrm{proj}})$ | 個数 |
|---|---|
| (0,0) | 1 |
| (1,1) | 495 |
| (1,2) | 252 |
| **(1,3)** | **16** |
| (2,2) | 2363 |
| (2,3) | 668 |
| (3,3) | 345 |

gap $= g_{\mathrm{proj}} - \mathrm{lb}$ のヒストグラム: **{0: 3204, 1: 920, 2: 16}**。

- **1 出力（2 ブロック）で最小の反例は $\mathrm{MAJ}_3$**（真理値表 `00010111`、$\mathrm{lb}=2$,
  $g_{\mathrm{proj}}=3$）。理由も明快: $x_1=x_2$ のとき多数決は $x_3$ を決めない。
  → Lean `maj3_maxFiber` + `maj3_proj_needs_all_three` と一致。
- **gap は 1 で止まらない**: gap $=2$ の分割が 16 件。代表例 `30201123`
  $=\{000,111\},\{001,101\},\{010,011\},\{100,110\}$（ビットは LSB 先頭表記）。
  全ファイバーが 2 元なので $\mathrm{lb}=1$ だが $g_{\mathrm{proj}}=3$。
  → Lean `gap2_lb_one` + `gap2_proj_needs_all_three` と一致。
- 二重実装照合（実験 B2）: 素朴実装（組の重複を見る）と部分キューブ単射性による独立実装が
  **4140 分割すべてで一致**。Lean の `projOK_iff_subcube` はこの同値性の証明。

### 実験 C — $n=4$, $m=1$ の全 65536 関数

| $(\mathrm{lb}, g_{\mathrm{proj}})$ | 個数 |
|---|---|
| (3,3) | 942 |
| (3,4) | 11928 |
| (4,4) | 52666 |

gap ヒストグラム: {0: 53608, 1: 11928}、**最大 gap 1**。

⚠️ **注意（比較してはいけない）**: $n=3$ で gap 2 が出たのは**4 ブロック（$m=2$）の関数**である。
$n=4$ の走査は **1 出力に限った**ので、この 2 つの「最大 gap」は同じ量の比較ではない。
$n=4$ の多出力全数（$\mathrm{Bell}(16) \approx 1.05\times10^{10}$ 分割）は今回の予算では回せない。

### 実験 D — パリティ障害の全数検査

- arity $\le N-1$ の**すべての**ゲート（対象線の選び方 × 載せる置換のすべて）が偶置換:
  $N=2$: 4 個、$N=3$: 150 個、$N=4$: **967976 個**、すべて偶 ✅
  → Lean `sign_gate_eq_one` の有界検査版。一致。
- 生成群: $N=2$ で $\langle \mathrm{NOT}, \mathrm{CNOT}\rangle = S_4$（位数 24）、
  $N=3$ で $\langle \mathrm{NOT},\mathrm{CNOT},\mathrm{Toffoli}\rangle = S_8$（位数 **40320**）。
  **どちらも奇置換を含む**。これは矛盾ではない: $N\le3$ では Toffoli が「全線に作用するゲート」
  なのでパリティ定理の仮定を満たさない（Toffoli は $110\leftrightarrow111$ の 1 互換＝奇）。
  Shende らの記述（3 線の $8!=40320$ 個すべてが CNT で合成可能）と一致。

### 実験 E — アンシラが 1 本でもあればパリティ障害は消える

$n=3$ を幅 $N=4$ に埋めると非正規領域（アンシラ $\ne 0$）の自由点が 8 個あり、
そこの 2 点の像を入れ替えるだけで符号が反転する（$-1 \to +1$ を構成的に確認、$N=5$ でも同様）。

**含意（今回いちばん実用的な判定）**: **パリティ障害は「アンシラ 0 本」の場合にしか効かない。**
$g \ge 1$ のガベージを許す設定では、埋め込みの選び方に自由度が残るので偶置換を選べる。
つまり (G) は「$f$ が既に全単射で幅を増やしたくない」場合の話であり、
**ガベージ幅の最小化と直交する**。これが「(c) で自明性が崩れる」と期待した部分の実際の限界。

## ⑥ 到達できなかったことと理由

1. **ガベージ×ゲート数のトレードオフ曲線: 未着手。**
   計算量ではなく**既知性**の理由で降格した。幅 $\le 4$ の最適ゲート数は Golubitsky–Maslov が
   全数で持っている（`docs/idea10` §3.2 が想定した Cayley BFS は $n+g\le4$ が限界なので、
   その範囲は丸ごと既知の表に含まれる）。**既知の表を再計算する価値は低い。**
2. **$n=4$ の多出力全数（$g_{\mathrm{proj}}$）: 未到達。**
   $\mathrm{Bell}(16)\approx1.05\times10^{10}$ 分割で 10 分予算に入らない。
   NPN 同値類での商が必要（$g_{\mathrm{proj}}$ は入力ビットの置換・反転と出力ラベル付け替えで
   不変なので商は取れる）。今回は 1 出力に限った。
3. **gap の一般論（上限）が無い。** $n=3$ で gap 2、$n=4$（1 出力）で gap 1 という実測しかなく、
   「gap は $n$ に対してどこまで大きくなるか」は予想すら立てていない
   （`docs/00` §2.1 の教訓に従い、$n=3,4$ の 2 点で当てはめをしない）。
4. **Golubitsky–Maslov の本文未読。** ⑤ の該当行は abstract と二次記述に基づく。
5. **OEIS 照合（C5）未実施。** 実験 B の分布（4140 分割の $(\mathrm{lb},g_{\mathrm{proj}})$ 表、
   n=4 の 942 / 11928 / 52666）を OEIS に当てるところまで行っていない。
