## 読み方

1. **graded∧¬sd は単一シンクでは空**（n≤8 で 0）。紙の理由: 単一シンクなら v≠s は子を持ち、
   graded ならその子は深さ +1。深さ D の v≠s が在れば深さ D+1 の子を持ち矛盾。
   シンクを 2 つ許せば在る（自己検査の W1: 鎖 0→2→4 と離れた辺 1→3。no-slack も peak 下界も破れる）
2. **sd∧¬graded では no-slack・peak 下界の違反が n≤8 で 0 件**（1,698 万個）。
   Lean の `present_at_dep`・`present_at_end_dep`・`peak_lower_*`（`lean/Revgarbage/ParPebbleWindow.lean`）は
   仮定に graded（`hpa1`）を含まず、sink-directed（`huniq`・`hup`）と深さ関数の性質だけを使う（言明を読んで確認。
   2026-10-11 には Lean を再ビルドしていない）
3. **graded が効いているのは交互スケジュール（thm:alt）**: sd∧¬graded の 98.9%（n=8）で非合法、
   graded では 0 件。最小の証人は W2（鎖 0→1→2→3 に近道 0→3）
