# 候補6 — 可逆 LZ ファミリの厳密最悪ケース膨張率

> 一行: **RevLZ77/78/LZW の出力長の厳密最大値と最悪入力の族を、全数探索で決める。**
> 期待値: 新規性 中／成功確率 中〜高／既存資産 大（`RevLZ` リポにパーサ実装済み）

## 1. 厳密量の定義

アルファベットサイズ $\sigma$、入力長 $n$ に対し

- $W_{\mathrm{alg}}(n,\sigma) = \max_{|w|=n} |\mathrm{enc}_{\mathrm{alg}}(w)|$
  （出力長の定義＝ビット長かトークン数かを**最初に固定**し、両方出す）
- 最悪入力の族（$W$ を達成する $w$ の構造）
- 可逆版と非可逆版の**厳密な差** $W_{\mathrm{rev}}(n,\sigma) - W_{\mathrm{std}}(n,\sigma)$
  = 「可逆性の代償」の厳密値
- 最良ケース（最大圧縮）$B(n,\sigma)$ も同時に出る（同じ探索で）

## 2. 既知と空白

- **既知**: LZ 系の圧縮率解析は情報理論的な漸近（エントロピー到達性、$O(n/\log n)$ 型の
  最悪出力長上界）が中心。可逆版は自分たちの構成と正当性証明。
- **空白**: **厳密極値と最悪入力の族が無い。** 「可逆化の代償」を漸近ではなく
  整数で言った例が無い。$n$ を横軸にした厳密最悪曲線は誰も描いていない。
- **一次確認**: LZ78 の最悪ケース出力長には既知の厳密結果がある可能性が高い
  （辞書サイズの組合せ論として古典的）。**まず非可逆版の既知厳密結果を洗う。**
  既知なら「可逆版との差」に主張を絞る（それでも新規）。

## 3. 機械化の設計

1. **全数探索**: $\sigma=2$, $n \le 24$ 程度なら $2^{24}$ = 1600 万で総当たり可能。
   既存 `RevLZ` のエンコーダを呼ぶだけ（Python なら遅いので C/Rust か、辞書構築を
   インクリメンタルにして**探索木上で共有**する = プレフィックス共有で劇的に速くなる）。
2. **分枝限定**: プレフィックスまでの出力長 + 残り長の楽観的下界で枝刈り。
   LZ の辞書は単調なので**プレフィックス共有 DFS が本命**。これで $n\le40$ も狙える。
3. **閉形式推定**: $W(n,2)$ の差分列を Newton 差分で。LZ78 は辞書サイズが
   $\Theta(n/\log n)$ 絡みなので、**$n$ の 2 進構造に依存する階段関数**を予想する。
4. **二重実装照合**: 既存 `RevLZ` の実装と、独立に書いた素朴エンコーダで一致確認。
   **ここでデコード可逆性も全入力について確認できる**（= 実装の全数検証という副産物。
   これ自体が「ツール論文」の材料になる）。

## 4. 初日の実験

```bash
python3 scripts/exp06_revlz_extremes.py --alg rev_lz78 --sigma 2 --nmax 16
```

初日の目標:
1. $W(n,2)$ と $B(n,2)$ の数列を $n\le16$ で出す（素朴総当たりで十分）
2. **OEIS 照合**
3. 最悪入力を1つ表示して構造を目で見る（周期的か、de Bruijn 的か）

副産物として「$n\le16$ の全入力でエンコード/デコードの往復が一致」という
**実装の全数検証**が初日で終わる。これは単独でも報告価値がある。

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: $W, B$ の厳密表 + 最悪入力族の記述 + 実装の全数検証（$n\le20$）。
- **成功（本線）**: $W(n,2)$ の閉形式 or 厳密漸化式の証明 + 可逆化の代償の厳密公式 +
  Lean で「$\forall w, |w|\le N \Rightarrow |\mathrm{enc}(w)| \le f(|w|)$」の有界検証と
  一般上界の無条件証明。
- **撤退条件**: 非可逆版の厳密結果が既知で、可逆版との差が定数（面白くない）場合。
  その場合は「実装の全数検証 + 表」をツール枠の短報にする。

## 6. Lean 計画

- L1: 一般上界（辞書の異なりフレーズ数の組合せ論的上界）を無条件証明。
  これは Lean の `List` 上の帰納で書ける規模。
- L2: $n\le N$ の全入力について厳密最大が表の値に一致することを `native_decide`。
  $N$ は Lean の評価速度次第（$N\approx14$ 程度が現実的）。
