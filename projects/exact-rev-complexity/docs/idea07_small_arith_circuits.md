# 候補7 — 小ビット幅可逆算術回路の「証明付き」最適値

> 一行: **$n\le4$ ビットの可逆加算器等について、ancilla × ゲート数の厳密最適トレードオフを下界証書付きで出す。**
> 期待値: 新規性 中／成功確率 中／Q-Intent への波及あり

## 1. 厳密量の定義

ゲート集合 $\mathcal{G}$（NOT, CNOT, Toffoli / あるいは NCT, GT, MCT）を固定し、
目標関数 $f$（$n$ ビット加算器、比較器、mod $2^n$ 加算、インクリメンタ）について

- $g^*(f, a)$ = ancilla $a$ 本を使えるときの**最小ゲート数**
- 曲線 $a \mapsto g^*(f,a)$（ancilla を1本増やすとゲート数が何個減るか）
- 量子コスト版: **最小 T-count**（Clifford+T 分解での T ゲート数）

## 2. 既知と空白

- **既知**: Golubitsky–Maslov らが **4 ビット可逆回路の最適 NCT 実装を全数探索**で決めている
  （全 $16!$ 置換に対する最適深さの分布まで）。Meuli 等は SAT/QBF による最適合成。
  加算器の構成は多数（Cuccaro, Takahashi–Tani, Draper 等）。
- **空白**:
  1. **下界の証明可搬性**: SAT/全数探索の結果は「計算した」で終わっており、
     **第三者が検証できる証書（certificate）や形式化が無い**。
  2. **ancilla × ゲート数のトレードオフ曲線**が関数ごとに表化されていない
     （最適値の点は知られていても曲線としては整備されていない）。
  3. T-count の厳密最適は小さい例しか知られていない。
- **本候補の立ち位置**: 「全数探索 + Lean で下界証書」＝**C4（二層検証）を武器にする**。
  「最適値はこれ、そしてその下界は機械検証済み」が売り。

## 3. 機械化の設計

1. **探索**: 置換群 $S_{2^{n+a}}$ の Cayley グラフ上の**両側 BFS / IDA\***。
   $n+a \le 4$（$16! \approx 2\times10^{13}$）は文献実績があり、
   ハッシュ + 対称性除去（入力/出力のビット置換とアフィン変換で商を取る）で到達可能。
   $n+a=5$（$32!$）は不可能なので**線は $n+a\le4$**。
2. **下界証書**: 「距離 $\ge d$」の証書は「半径 $d-1$ の球に目標が入っていない」こと。
   球の要素数が巨大なので、**証書は "球の生成規則 + 到達集合のハッシュ" ではなく
   帰納的不変量**にする必要がある。実用的な妥協案:
   - 不変量ベース下界（パリティ、線形性の度合い、代数次数の変化量）を Lean で証明し、
     「1ゲートで不変量は最大 $c$ しか変わらない」+「目標の不変量値」から下界を導く。
   - **これが本候補の本当の研究内容**（探索は既知手法の再実行にすぎない）。
3. **二重実装照合**: 既知の Golubitsky–Maslov の値と一致するかを最初に確認（= 実装の妥当性検証）。

## 4. 初日の実験

```bash
python3 scripts/exp07_circuits.py --bits 3 --gates NCT   # 3ビット全置換の最適ゲート数分布
```

初日の目標: **3 ビット（$8! = 40320$）で全置換の最適 NCT ゲート数分布を出し、
文献値と一致させる。** 一致したら 4 ビットへ進む判断ができる。
一致しなければゲート集合の定義が文献と違う（そこを詰めるのが先）。

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: 3・4 ビットの加算器/比較器の $a \mapsto g^*$ 曲線 +
  不変量ベース下界の Lean 証明1本。
- **成功（本線）**: 「不変量 $I$ は1ゲートで $\le c$ 変化する」系の補題群を Lean で整備し、
  **形式検証された下界ライブラリ**として公開。これは可逆回路合成の分野で
  誰もやっていない切り口（探索結果を再利用可能な形にする）。
- **撤退条件**: 3 ビットで文献値を再現できない（定義の齟齬が解けない）、
  または不変量下界が自明な値しか出さない場合。後者なら候補10へ資産を回す。

## 6. Lean 計画

- L1（本命）: 不変量の単調性補題。「Toffoli 1 個で代数次数は最大 1 上がる」等。
- L2: 具体関数の最適値 $g^*(f,a) = k$ を有界検査（$k$ が小さい場合のみ現実的）。
