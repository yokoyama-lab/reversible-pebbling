# 00 — 全体像: 何を狙い、どの候補から始めるか

## 1. 勝ちパターン（成功例から抽出した必要条件）

`2026_exact_reversible_pebbling` が機能した理由を条件に分解すると次の6つになる。
**新しいトピックを評価するときは、この6項目に○×を付けてから始める。**

| # | 条件 | なぜ効くか |
|---|---|---|
| C1 | 対象量が**厳密整数値**として一意に定義できる | 「厳密値の表」という反論不可能な一次データが作れる |
| C2 | 文献が**漸近だけ**で止まっている（$\Omega(\cdot)$〜$O(\cdot)$ のギャップが残る） | 厳密小データが「どちらの側が真か」を示唆でき、予想を立てる資格が生まれる |
| C3 | 小さいサイズを**全数探索/BFS/DP/区間代数**で確定できる | 手計算の誤りが混入しない。計算機が査読者より正確 |
| C4 | **Lean で二層検証**できる（一般証明 + 有界全数検査 `native_decide`） | ツール枠・形式化枠の両方に出せる。「表が正しい」ことの証書になる |
| C5 | **OEIS 未登録**を確認できる | 新規性の即時証拠。登録そのものが小さな成果 |
| C6 | 可逆計算の**一次文献を自分で読める** | 「既知の系だった」を早期に判定して撤退できる（実際 reach(p) はこれで降格した） |

**失敗の主要因は C6 の不足**（既知結果の再発明）と **C2 の誤認**（実はギャップが埋まっている）。
どの候補も**初週は文献の一次確認に半分の時間を使う**こと。

## 2. 共通の失敗モード（すべて実際に踏んだ。件数は 2026-07-27 時点）

### 2.1 少数点の当てはめは崩壊する（**実例4件・最頻の失敗**）

| # | 対象 | 当てはめ | 根拠点数 | 崩壊 |
|---|---|---|---|---|
| 1 | 鎖の完全計算変種 | $\Theta(n^{\log_2 3})$ | 漸近の一致 | $p=10$ まで厳密計算で崩壊 |
| 2 | ピラミッド $M^*$ | $3h^2-h+3$ | 4点（完全一致） | $h=5$ で崩壊（予測 73／実測 105） |
| 3 | 完全二分木 $M^*$ | $2\cdot3^h-1$ | 3点 | $h=5$ で崩壊（予測 161／実測 155） |
| 4 | grid$(k,k)$ の $M^*$ | OEIS **A001845 に一致** | 4点 | $k=5$（117）で一致が消滅 |

**#4 が最も危険な形**: OEIS が既知列を返してきても、点数が少なければ偶然である。
→ **予想も OEIS 一致も、計算可能域の上限まで回してから採用する。**
4〜5 点の一致は「何も言っていない」に等しいと考えること。

### 2.2 既知性の判定を外す（実例3件）

1. **既知の降格**: `reach(p)=2^{p-1}` は Královič Thm 3.1 の系だった。
   → 予想を立てる前に、対応する定理が既存論文の**系**になっていないか本文で確認する。
2. **新定義だと思ったら既知**: 候補3 の $e$-Landauer ゲームは Li–Tromp–Vitányi 1998 の
   **m-erasure pebble game** と規則レベルで同一だった（候補3 の md 参照）。
   → 「新しいゲームを提案する」と書く前に、規則が一致する既存ゲームを検索する。
3. **既知の所在が査読文献の外**: 可逆 BB 値は **bbchallenge wiki** にあった（候補5 は撤退）。
   → **一次確認は査読文献だけでは足りない。** 全数計算・レコード系のトピックでは
   コミュニティの wiki・リーダーボード・Discord が「既知」の実質的な所在である。

### 2.3 その他

- **後発文献の見落ち**: Pesu–Phillips 2015 は Knill 1995 を引用していなかった。
  → 引用グラフの**両方向**（前方引用も）辿る。Semantic Scholar の citations API を使う。
- **計算量の見積り違い**（過小評価の側）: 「状態空間は $2^{|V|}$ だから $|V|\le24$ が限界」は誤り。
  ピーク上限 $p$ で切れば $\sum_{k\le p}\binom{n}{k}$ で、$p$ が $\log$ オーダーなら劇的に小さい。
  **DP を設計する前に、素朴実装の実際の限界を測る。**
- **標準ペブリングの直観の持ち込み**: 「断面が細いからフロンティア DP が効く」は
  可逆ペブリングでは**成り立たない**（取り除きにも先行点条件があるため手順が切断に沿って
  単調に進まない）。候補1・候補4 が独立に同じ結論に達した。詳細は `docs/idea01_trees_dags.md` §3.2。
- **効いた手**（逆に汎用的に有効だった）: ①状態を int ビットマスクに ②双方向 BFS
  （toggle は対合＝状態グラフが無向なので合法・厳密） ③自己同型群による商グラフ探索
  （始状態と目標がともに不変なら最短距離は厳密に保たれる）。

## 4. 推奨する進め方

- **本命: 1 + 4 の抱き合わせ**。`scripts/revpebble.py` が既に DAG 一般なので、
  入力グラフを変えるだけで木族とメモ化 DAG の厳密表が出る。1本の論文に
  「木族の厳密表」＋「実装が最適からどれだけ離れているか」を同梱できる。
- **大穴: 3**。定義から自分のものになるので新規性が最大。ただし査読で
  「そのモデルは自然か」を必ず問われるので、Landauer/Bennett の物理側の動機を先に固める。
- **話題性: 5**。通常 BB は $k\le5$ が 2024 に確定した話題であり、可逆制約下は空白。
- **学生に振るなら 1・4・6**（計算が軽く、成果が表として見えるため指導しやすい）。

## 5. 全候補で共通する最初の3手

1. `docs/20_prior_art.md` を読む（先行プロジェクトの確定事実）。
2. 対象候補の md の「初日の実験」を実行して、**数を1個出す**。
3. 出た数列を OEIS と Semantic Scholar で照合し、C2・C5・C6 に○×を付けて md に追記する。

この3手で「続ける／撤退する」を判断できる。撤退は失敗ではなく、
判定コストを1日に抑えたこと自体が成果である。
