# 候補2 — 標準 vs 可逆ペブル数の「分離 onset」（小 DAG 全数探索）

> 一行: **$R(G) > P(G)$ が初めて起きる最小の DAG を全数探索で確定する。**
> 期待値: 新規性 中〜高／成功確率 高／既存資産 大

## 1. 厳密量の定義

- $P(G)$ = 標準（不可逆）ペブル数: ペブルは「先行点が揃えば置ける／いつでも取れる」。
- $R(G)$ = 可逆ペブル数: 取るときも先行点が揃っている必要がある（toggle 規則）。
- 目標: 頂点数 $n \le 8{\sim}9$ の**全 DAG**（同型類）に対し $(P(G), R(G))$ を全数計算し
  - 差 $R-P$ の分布
  - $R-P = 1, 2, \dots$ が初めて現れる最小頂点数・最小辺数と、その最小反例グラフ
  - 手数側の分離: 同じ空間での最小手数比 $M^*_{\text{rev}}/M^*_{\text{std}}$ の最大

## 2. 既知と空白

- **既知**: Chan–Lauria–Nordström–Vinyals (FOCS 2015) — 可逆ペブル空間の決定は PSPACE 完全、
  任意加法定数以内の近似も PSPACE 困難、標準との分離は**乗法 $\log$ 倍**（グラフ積構成）。
  Chan 2013 — Dymond–Tompa / Raz–McKenzie ゲームとの同値。
- **空白**: これらは漸近的・複雑性クラス的な言明であり、
  **「最小の分離例」という有限の事実は誰も報告していない**。
  「近似すら PSPACE 困難」だからこそ、小域の厳密全数データは代替として価値がある。
- **副産物**: CCC 2019 の対応で $R(G)$ は NS 反駁の次数。よって
  「resolution 幅 vs NS 次数の最小分離例」という証明複雑性の辞書にも載る。

## 3. 機械化の設計

1. **DAG 列挙**: 頂点数 $n$ の非同型 DAG を列挙。
   - $n\le7$ は素朴列挙 + 正規形ハッシュで十分（$n=7$ の非同型 DAG は約 $10^6$ オーダー）。
   - $n=8,9$ は **nauty/`directg`** または `networkx` + 正規形で。
     枝刈り: 単一シンク・弱連結・全頂点がシンクへ到達可能なものだけ（それ以外は分解できる）。
2. **$P(G)$, $R(G)$ の計算**: どちらも同じ BFS 骨格。`scripts/revpebble.py` の
   `bfs` に「取る操作に先行点条件を課すか」のフラグを足すだけ（**まずテストを書く**）。
   - 標準側の clean 条件は「終端のみにペブル」で統一する（比較の公平性のため）。
3. **候補絞り**: まず $R>P$ の候補を軽い上界/下界フィルタで絞り、残りだけ厳密に。
4. **二重実装照合**: 既知の小さな例（ピラミッド、鎖）で $P$ が文献値と一致することを確認。

## 4. 初日の実験

```bash
# ① revpebble に標準ペブリングモードを足す（先に tests/ へ期待値: 鎖は P=2, R=p_min）
# ② 小さい n で全数列挙して差の分布を見る
python3 scripts/exp02_separation.py --nmax 6
```

初日の目標は「$n\le6$ で $R-P$ の分布を1枚の表にする」。ここで既に分離が出るはず
（可逆ペブリングは鎖ですら $P=2$ に対し $R=\lceil\log_2 n\rceil+1$ なので、
**鎖が既に無限に分離する**）。したがって本候補の**本当の問いは差の大きさではなく**:

- 「$R-P$ が大きくなるグラフの構造的特徴」（鎖的な深さ vs 分岐）
- 「同じ $n$ で $R$ を最大化するグラフ」= 可逆化が最も高くつく形
- 「$R = P$ となるグラフのクラスの特徴付け」（= 可逆化が無料な DAG の分類）

**最後の問いが最も論文になる**: 「可逆化コスト 0 の DAG の特徴付け」は自然な問いで、
小域の全数データから予想を立てて一般証明を狙える。**初日にここへ照準を移すこと。**

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: $n\le7$ の全数表 + $R=P$ となるグラフの必要十分条件の予想 +
  $n\le6$ での Lean 検証。
- **成功（本線）**: $R=P \iff$（構造条件）の一般証明。おそらく
  「各頂点の出次数と再計算不要性」に関する条件になる。反例駆動で詰める。
- **撤退条件**: $R=P$ のクラスが自明（例: 出次数1の木のみ）で面白い構造が出ない場合。
  その場合は表だけをツール論文の材料として候補1に同梱する。

## 6. Lean 計画

- L2: 具体グラフごとに `R (G7_37) = 4` を `native_decide`（グラフをリテラルで埋め込む）。
- L1: 「$R=P$ の十分条件」を無条件に証明。全数データは反例探索に使う。

## 9. 初回測定の結果（2026-07-27, `data/exp02_results.md` に詳細）

- `scripts/stdpebble.py`（標準ペブリング BFS）・`scripts/exp02_dags.py`（DAG 全数列挙・
  同型除去）・`scripts/exp02_separation.py`（実験ドライバ）を実装。テストは
  `tests/test_exp02_stdpebble.py`, `tests/test_exp02_dags.py`。
- $n\le6$ は非同型類まで厳密に全数計算済み（`1,1,3,16,164,3341` 類、OEIS A350415 と一致）。
- **最小の分離**: $n=3$ の鎖（$P=2,R=3$）— 既知（Bennett/Knill/Královič）。
  **最小の「分岐を持つ」分離**: $n=4$, $\{0{\to}2,1{\to}2,2{\to}3\}$（$P=3,R=4$）。
- **§4 の本命の問い（$R=P$ の特徴付け）**: 「出次数$\le1$（木）」仮説は $n=3$ の鎖自体で
  即反証。「深さ$\le1$」は十分条件（$n\le6$ で崩れず）だが必要条件ではない。
  「$R=\max(P,\text{chainR}(\text{深さ}))$」という単純合成則も反証（3526件中2281件不一致）。
  → **撤退条件（自明な特徴付け）には該当しない**。合流（複数消費者を持つ頂点）が
  深さだけでは説明できない追加コストを生むことが分かった。これが次の一手の焦点。
- $n=7$ は同型除去が単体で10〜15分かかり時間予算を超えるため、時間制限つき
  生スキャン（28.1%処理）のみ実施。**$R-P=3$ の実例を発見**（$n\le6$ の最大2を超える）。
  網羅性は無いため個数・最大値の主張はできない。
- OEIS: 非同型類数・ラベル付き候補数は既知数列に一致（実装の裏取り）。
  $R=P$／$R>P$ の個数の列は未登録だが、特徴付けが無いまま登録するのは時期尚早。
