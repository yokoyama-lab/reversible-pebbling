# SAT ソルバの返す最適解は恣意的——構造を読む前に目的関数で正準化する

2026-08-18、ピラミッド $h=13$ の最適解を cadical から取り出して眺めたが、同じ $p=37$ でも
呼ぶたびに形が違い（run が飛び飛び・往復が多い）、構造が読めなかった。
**時間対称を課し（後で WLOG と証明）、ピーク固定で $\sum_t |P_t|$ を CP-SAT で最小化**したところ、
「上部 8 層は `alt`・下部 3 層だけ部分 run」という一目で読める形になった（最適 767、69 秒）。

- 構造仮説（区間性・対称性・単一区間）は**正準解を見て立て、SAT で全数検定**する順が速い
- 正準化の目的関数は「総在時間」が良かった（往復や無駄な滞在を消す）。
  ただし CP-SAT は $h \ge 15$ で 1500 秒でも最適に届かない（`FEASIBLE`）ので、
  大きい $h$ の正準形は取れていない
