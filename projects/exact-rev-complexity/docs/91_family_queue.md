# 作業キュー: 可逆ペブリングの厳密値を新しいグラフ族へ

**このファイルは手で更新する作業台帳である**（`data/families/atlas.csv` とは別物。あちらは生成物）。
手順は `docs/90_family_loop_protocol.md`。

## 目的

可逆シミュレーションの厳密定数（$p_{\min}$ と $M^*$）を、**まだ表の無いグラフ族**へ広げる。
既に表がある族は 鎖・完全二分木・ピラミッド・spinal・バタフライ・小 DAG 全数。
ここで足すのは **円筒（トーラスの DAG 対応物）・$k$ 分木・ビット反転**の 3 族。

新規性の所在: Královič 2004 は木とバタフライの**空間**しか与えていない（手数の表は無い）。
Lengauer–Tarjan のビット反転グラフは**標準**ペブリングの定番例で、可逆版の厳密値は無い。
円筒はメモリハード関数の文献に構造は出てくるが、可逆ペブリングの厳密値は無い。

## 進め方の原則（このループ固有）

- **失敗が完全に安全**。外部への書き込みが無く、結果は数値表として単調に増える。
- 届かなかったセルは `status: timeout` として**行を残す**（黙って落とさない）。
- **閉形式は計算可能域の上限まで回してから**しか書かない（4 回崩壊している）。

## U3d — 「1 回組の個数が $h$ に依らない」を独立に検査する

**状態: done**（2026-08-05）

結果: **円筒に固有ではなく、台帳の全行に効く形へ一般化できた。**

> 正準な最適スケジュールでどの頂点も高々 2 回しか置かれない行では、例外なく
> $r=\min(p,N)$ かつ $M^*=4N-2\min(p,N)-1$（$r$=1 回組の個数、$N$=ペブル可能な頂点数）。

3 族・194 行のうち該当 **131 行で反例ゼロ**。`tests/test_families_atlas.py`（6 件）が
台帳全体に対して検査し、`tools/loopcheck.sh` に組み込んだ（gate は 8 秒のまま）。

$M^*=4N-2r-1$ は $A=2N-r$ からの恒等式で、内容は $r=\min(p,N)$ のほう。
$\min$ が要るのは $p>N$ のときで、そこでは飽和して $M^*=2N-1$ になる。
公差 $4k$（U3c）はこの系である。

**崩れる位置 = 3 回目の再計算が現れる位置**であることも確認した（$k=2,p=9$ で
置いた回数の最大が $h\le11$ で 2、$h=12..15$ で 4、$h=16$ で 6）。

**既知性は未確認**。$M^*=2A-1$ と絡むので Knill 1995 の構造補題にある可能性がある
→ U7 で本文を当たる。

旧・完了条件: 証書から「ちょうど 1 回だけ置かれた頂点」の個数を数える関数を書き、
$k=2$・$p=11$ の等差領域（$h=12..16$）でそれが **11 で一定**であることを
`tests/` に固定する。$k=3$ でも同じ検査を通し、等差でない領域では
**一定にならない**ことも併せて固定する。

留保（findings §3.5）: $A$ は $M^*$ から一意に決まるが、**置かれた回数の分布は
スケジュールに依存する**。したがってこの検査が固定するのは
「BFS の距離表から復元した正準なスケジュールについての性質」であり、
全ての最適スケジュールについての主張ではない。**そう書くこと。**

## U7 — 既知性の一次確認

**状態: done**（2026-08-05・一部未決）

**降格 1 件**: U3d の閉形式 $M^*=4N-2\min(p,N)-1$ は、**鎖については Knill に含意される**。
本文で確認した根拠は (1) Observation 2.2(i) が $F(n,S)=2n-1$ for $S\ge n$（我々の $p\ge N$ の場合そのもの）、

（「公差 4」の領域は Knill の枠組みに入っている）。**鎖については新規と書かない。**

**取り分として残るもの**: (a) 鎖以外の 3 族で $N$ を祖先数として同じ式が成り立つこと、
(b) 領域の終わりが「3 回目の再計算が現れる位置」と一致するという判定条件。
**$x_{2,S}$ は Knill でも上下界しか無い**（Lemma 2.9）ので、(b) はそこに構造的意味を
与える方向であり、主張として立てるならここ。

**確認 1 件**: Královič 2004 は木・バタフライの**空間**（Thm 4.9・4.12）のみで、
時間は鎖（Thm 3.4・Cor 3.5、しかも complete computation 変種）だけ。KF-06 を本文で再確認。

**未決**: Lengauer–Tarjan 1982 の PDF が未入手で、**ビット反転の可逆版の既知性は決着していない**。
$BR_k$ の数値は新規と書けない。Crossref は KF-19 の罠で空振り、S2 は 429。
**検索の空振りは新規性の証拠にならない。** → U7b を立てる。

旧・完了条件: Královič 2004・Knill 1995・Lengauer–Tarjan 1982 の**本文**で、
円筒・$k$ 分木・ビット反転の可逆ペブリング**手数**が与えられていないことを確認し、

（Knill 1995 は $F(n,S)$ の厳密再帰と最適分割点の構造補題を持っているので、
そこに入っている可能性がある。入っていたら findings に既知と明記して降格する）。
`docs/22_known_facts_ledger.md` に ID を振って追記する。
アブストラクトだけで判断しない（`docs/00_overview.md` §2.2）。前方引用も辿る。

## U7b — Lengauer–Tarjan 1982 を入手してビット反転の既知性を決着させる

**状態: done**（2026-08-05・当初の目的は未達、代わりに**もっと重要な訂正**が出た）

Lengauer–Tarjan 1982 の PDF は**入手できていない**（ビット反転の既知性は依然未決）。
代わりに **arXiv 全文検索 1 回**で直撃の後続文献が 2 本出て、**U7 の判定を 2 つ訂正した**。

**KF-25（訂正）**: Komarath–Sarma–Sawlani, arXiv:1604.05510（COCOON 2015）が
「根つき有向木の可逆ペブル数 = 台の無向木の edge rank coloring number + 1」を示している。
一般 DAG では PSPACE 困難なのに**木では多項式時間で決まる**。
→ **§3.6 の $k$ 分木 $p_{\min}$ 表は既知の多項式時間量の実例で、値は新規ではない。**

**KF-26（訂正）**: 同論文は**歩数**も扱う（完全二分木 $n^{O(\log\log n)}$ 歩など）。
→ 「木の手数は文献に無い」は誤り。正しくは
**「漸近的な上界・トレードオフはあるが厳密値の表は無い」**。取り分は厳密値の側だけ。

**KF-27（注意）**: Blocki–Holman–Lee, arXiv:2110.04191 が **parallel** reversible pebbling
（1 段で複数手＝別ゲーム）で Argon2i-A/B・DRSample を解析。円筒の近傍にある。

**方法の教訓**: 一次資料 2 本を精読しても**前方引用を辿らなければ空白判定は外れる**。
決め手は Crossref でも S2 でもなく arXiv 全文検索だった。**検索先を 1 つで諦めない。**

旧・完了条件: Lengauer–Tarjan, *Asymptotically tight bounds on time-space trade-offs in a
pebble game*, JACM 29(4):1087–1130, 1982 の本文を入手し、
(a) ビット反転グラフの定義が我々の `bitrev` と一致するか、
(b) **可逆**ペブリングの手数について何か言っているか（言っていないはず。標準ペブリングの
論文なので）を確認して `docs/22_known_facts_ledger.md` に追記する。

併せて可逆側の後続（Chan 2013、Chan–Lauria–Nordström–Vinyals FOCS 2015、
de Rezende ら CCC 2019）の**前方引用**を辿り、ビット反転の可逆ペブリング値が
どこかで計算されていないかを見る。**アブストラクトだけで決めない**（`docs/00_overview.md` §2.2）。
