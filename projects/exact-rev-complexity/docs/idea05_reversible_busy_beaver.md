## 1. 厳密量の定義

- 機械: 2 記号（`0`,`1`）、$k$ 状態、**両側無限テープ**（採用）、halt 状態1つ。
- **可逆性（確定した定義。当初の記述は誤りだったので修正）**:
  「遷移関係が三つ組として単射」では**不十分**。移動してしまうと直前のマスに書いた記号を
  頭が見ていないため、配置レベルの逆向き決定性には次が必要十分:
  - **五つ組** $(q,a)\to(q',b,d)$: 状態 $q'$ に入る全ての規則が
    **(i) 同じ移動方向**（直前の頭位置が定まる）かつ **(ii) 互いに異なる記号を書く**
    （どの規則が発火したか読み取れる）。
    反例: 通常 BB(2) チャンピオン `1RB1LB_1LA1RZ` は三つ組としては単射だが
    状態 B に R と L の両方向から入るので**可逆ではない**。
  - **四つ組（Morita 流）** 書き込み型 $[q,a,b,q']$ と移動型 $[q,/,d,q']$: 状態 $q'$ に
    **移動型が1本でも入るならそれが唯一の入り規則**、すべて書き込み型なら書く記号が互いに異なる。
    移動型の逆規則 $[q',/,-d,q]$ には読み guard が無いので他のどの逆規則とも衝突する。
    **「移動型2本を方向で区別できる」は誤り**（記号を書かないので逆向きに材料が無い）。
  - 実装 `scripts/revbb.py` の `quintuple_reversible` / `quadruple_reversible`。
    どちらも局所条件なので枚挙時に増分判定できる。
  - 四つ組の1ステップは五つ組より小さい仕事なので、**両形式のステップ数は直接比較しない**。
- 量:
  - $\mathrm{BB}_{\mathrm{rev}}(k)$ = 空テープから停止する可逆 $k$ 状態機械の最大ステップ数
  - $\Sigma_{\mathrm{rev}}(k)$ = 停止時のテープ上の `1` の最大個数
  - **可逆化の代償** $\mathrm{BB}(k) / \mathrm{BB}_{\mathrm{rev}}(k)$ の厳密比（$k\le4$）

## 3. 機械化の設計

**可逆性は枚挙を軽くする**（単射条件で候補が激減する）ので、通常 BB より $k$ を稼げる可能性がある。

1. **枚挙**: 遷移表を単射条件を満たすように生成（バックトラック枚挙）。
   状態の名前替え対称性で正規形に落とす（最初に訪れる順に番号付け）。
2. **実行**: 各機械を上限ステップまで走らせる。停止した最大値を取る。
3. **停止判定（本候補の山）**: 実装済み。**3種の証書付き判定だけで
   五つ組 $k\le5$・四つ組 $k\le6$ が未判定 0 台になった**（bouncer/counter 判定器は不要だった）。
   - **停止規則なし**: Z へ行く規則を1本も持たない機械は原理的に停止しない（自明・最も安い）。
   - **巡回**: 頭位置を原点に揃えた配置の指紋の再訪。オフセット 0 なら同一配置。
     可逆側ではこれが**必ず初期配置への回帰**になることを確認した（単射性の補題）。
     非可逆側では反例多数（$k=3$ で 2,735 台中 2,506 台）→ 補題は可逆性に本質的に依存する。
   - **並進型 (translated cycler)**: 「記録更新時刻」（頭が過去最右／最左を越えた時刻）同士で、
     同じ状態かつ区間内の頭位置最小値 $m$ 以降のテープが $\Delta$ ずれて一致すれば非停止。
     **最も台数を稼ぐ**（五つ組 $k=5$ で全体の 48%）。
   - 判定器を足した経過（$k=3$ 五つ組の未判定台数）: 巡回のみ 189 → 並進型追加 10 →
     停止規則なし追加 **0**。
4. **二重実装**: 未実施。既知値4件（$\mathrm{BB}(2),(3),(4)$ と wiki の可逆チャンピオン4台）の
   再現をもって代替した。

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: $k\le3$ の $\mathrm{BB}_{\mathrm{rev}}$・$\Sigma_{\mathrm{rev}}$ を
  両形式で確定し、全ての非停止機械に判定証書を付ける。
- **成功（本線）**: $k=4$ まで到達 + 「可逆機械の非停止判定は単射性から易しくなる」定理 +
  Lean で全数検査を形式化（BB(5) の Coq 証明に呼応する形式化枠の論文になる）。
- **撤退条件**: ①既知だった ②$k=3$ で未判定機械が数千台残り手が付かない。
  ②の場合も「可逆 BB の下界（構成）と未判定台数」を報告する短報にはなる。
- **判定結果（2026-07-27）: ① に該当して撤退。**②は起きなかった（停止判定は
  予想よりはるかに易しく、$k=5$ まで全数判定できた）。
  皮肉だが「§3.3 の売り＝可逆機械の非停止判定は易しい」は正しく、
  **易しすぎて技術的な障壁が売りにならない**面もある。

## 6. Lean 計画

- L2: 「$k=3$ の全可逆機械について、この表の値が上限」を `native_decide`（機械数が現実的なら）。
  **機械数の実測: $k=3$ で 418 台、$k=4$ で 11,871 台、$k=5$ で 451,479 台。$k\le4$ は
  `native_decide` で十分現実的。** 必要な非停止証書は3種のみ（§3.3）で、
  bouncer/counter 判定器の形式化は不要だと実測で分かった。
- L1: 単射性からの周期性補題（可逆機械が配置を繰り返すなら初期配置に戻る）を無条件証明。
  これが本命の形式化成果。**撤退後に残る最有望の線**（値が既知でも
  「wiki と Discord にしか無い値に機械検証済みの証書を与える」は形式化枠の主張になる）。
