# 候補5 — 可逆 Busy Beaver

> 一行: **可逆 Turing 機械に限定した Busy Beaver 値 $\mathrm{BB}_{\mathrm{rev}}(k)$ を全枚挙で確定する。**
> 期待値: 新規性 高／成功確率 中／話題性 **最大**

## 1. 厳密量の定義

- 機械: 2 記号（`0`,`1`）、$k$ 状態、片側無限または両側無限テープ、halt 状態1つ。
- **可逆性**: 遷移関係が単射。すなわち「(次状態, 書いた記号, 移動方向)」から
  「(前状態, 読んだ記号)」が一意に復元できる。局所条件なので枚挙時に判定できる。
  → **正確な定義（三つ組 vs 四つ組、Bennett/Morita のどの流儀か）を最初に固定する。**
  Morita の可逆 TM は四つ組形式（読み書きと移動を分離）を使うことが多く、
  三つ組形式の可逆性条件とは異なる。**両形式で値を出すのが安全。**
- 量:
  - $\mathrm{BB}_{\mathrm{rev}}(k)$ = 空テープから停止する可逆 $k$ 状態機械の最大ステップ数
  - $\Sigma_{\mathrm{rev}}(k)$ = 停止時のテープ上の `1` の最大個数
  - **可逆化の代償** $\mathrm{BB}(k) / \mathrm{BB}_{\mathrm{rev}}(k)$ の厳密比（$k\le4$）

## 2. 既知と空白

- **既知**: 通常の BB は $\mathrm{BB}(4)=107$、**$\mathrm{BB}(5)=47{,}176{,}870$**（2024 年に
  Coq による協働証明で確定＝形式化コミュニティの話題作）。$\mathrm{BB}(6)$ は絶望的に大きい。
- **既知（可逆側）**: Bennett 1973 の可逆 TM シミュレーション、Morita の可逆 TM 理論
  （可逆 TM の計算万能性、少状態の万能可逆機械）、Lange–McKenzie–Tapp 2000。
- **空白**: **可逆制約下の BB 値は（要一次確認だが）計算されていない。**
  「可逆性という局所条件が Busy Beaver をどれだけ弱めるか」は自然な問いで、
  BB(5) の Coq 証明という直近の話題と接続できる。
- **必須の一次確認**: "reversible busy beaver" / "injective Turing machine busy beaver" で
  検索し、Aaronson の BB サーベイと bbchallenge.org を確認する。**ここで既知なら即撤退。**

## 3. 機械化の設計

**可逆性は枚挙を軽くする**（単射条件で候補が激減する）ので、通常 BB より $k$ を稼げる可能性がある。

1. **枚挙**: 遷移表を単射条件を満たすように生成（バックトラック枚挙）。
   状態の名前替え対称性で正規形に落とす（最初に訪れる順に番号付け）。
2. **実行**: 各機械を上限ステップまで走らせる。停止した最大値を取る。
3. **停止判定（本候補の山）**: 停止しない機械を排除する必要がある。
   - **可逆性が武器になる**: 可逆機械は状態遷移が単射なので**構成空間上で同じ配置に戻れない**
     （サイクルに入るなら初期配置に戻るしかない）。これが強力な非停止/周期性の判定法になる。
     → **「可逆機械の非停止判定は通常より易しい」ことが本候補の技術的な売り。**
   - 残る難物: 定期的にテープを伸ばす並進機械。並進不変量（translated cycler）で検出。
   - どうしても残るものは Lean で個別に非停止を証明する。
4. **二重実装**: 独立に書いたシミュレータで最大値機械を再走行して照合。

## 4. 初日の実験

```bash
python3 scripts/exp05_rev_bb.py --states 2 --formalism triple   # k=2 を完全に決める
python3 scripts/exp05_rev_bb.py --states 3 --formalism triple
```

初日の目標: **$k=2$ を完全確定**（機械数が小さいので手で検証もできる）し、
$k=3$ の候補機械リストと未判定機械の個数を出す。未判定が数十台なら $k=3$ も決まる。

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: $k\le3$ の $\mathrm{BB}_{\mathrm{rev}}$・$\Sigma_{\mathrm{rev}}$ を
  両形式で確定し、全ての非停止機械に判定証書を付ける。
- **成功（本線）**: $k=4$ まで到達 + 「可逆機械の非停止判定は単射性から易しくなる」定理 +
  Lean で全数検査を形式化（BB(5) の Coq 証明に呼応する形式化枠の論文になる）。
- **撤退条件**: ①既知だった ②$k=3$ で未判定機械が数千台残り手が付かない。
  ②の場合も「可逆 BB の下界（構成）と未判定台数」を報告する短報にはなる。

## 6. Lean 計画

- L2: 「$k=3$ の全可逆機械について、この表の値が上限」を `native_decide`（機械数が現実的なら）。
- L1: 単射性からの周期性補題（可逆機械が配置を繰り返すなら初期配置に戻る）を無条件証明。
  これが本命の形式化成果。
