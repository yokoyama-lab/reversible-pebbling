# 候補1 — 可逆ペブリングの木・DAG 族への厳密拡張

> 一行: **Královič が「空間 $h+\Theta(\lg^* h)$」までしか決めなかった木族の、手数の厳密表を作る。**
> 期待値: 新規性 中／成功確率 **高**／既存資産の再利用 **最大**（本命）

## 1. 厳密量の定義

対象は DAG 族 $\{G_h\}$（完全二分木 $T_h$、spinal tree、バタフライ、ピラミッド）。
`docs/20_prior_art.md` §1 のモデルで

- $p_{\min}(G_h)$ = clean に根（終端）へ到達できる最小ピーク
- $M^*(G_h, p)$ = ピーク $p$ の下での最小手数、および $M^*(G_h) := M^*(G_h, p_{\min})$
- トレードオフ曲線 $p \mapsto M^*(G_h,p)$（$p = p_{\min} .. p_{\min}+3$）

**Královič 2004 本文（`~/dev/overleaf/2026_exact_reversible_pebbling/refs/kralovic-2004-rairo.pdf`）
を精読した。以下は該当箇所つきの確定事実。検証は `tests/test_exp01d_kralovic.py`。**

### 2.1 彼が使う3つの量（混同厳禁）

| 量 | 定義 | 本文 |
|---|---|---|
| $S_{\min}(G)$, $T(G,s)$ | **complete computation**（空→空・各頂点を一度カバー）の最小空間・最小時間 | §2, p.139 |
| $S'_{\min}(h)$ | **semicomplete computation**（空→**根だけがペブルされた配置**）の最小空間 | **Def 4.1, p.147** |

**Def 4.1 は我々の clean-reach と字義通り同一。** よって

$$\text{我々の } p_{\min} \;=\; \text{彼の } S'_{\min},\qquad
\text{我々の } M^* \;=\; \text{semicomplete computation の時間}$$

彼の $Bt(h)$ は $2^h-1$ 頂点（$Bt(1)$=1頂点）で**葉も空間に数える**。
我々の「$T_h$ free-leaves」= `QuotientTree(h-1)` に対応（**レベルのずれ 1**）。

### 2.2 既知

- **Thm 4.9**: $S_{\min}(h) = h+\Theta(\lg^* h)$（**空間のみ**）。
- **Thm 4.12 / Lem 4.10, 4.11**: バタフライも $d+\Theta(\lg^* d)$、$S(Bf(d))=S(Bt(d))$。
- **Lem 4.2**: $S_{\min}(h)\le S'_{\min}(h)\le S_{\min}(h)+1$。
  **Lem 4.3**: $S'_{\min}(h+1)=S_{\min}(h)+2$。
- 鎖: **Thm 3.1** $S^{-1}(p)=2^p-1$、**Thm 3.4**（時間の漸化不等式）、
  **Cor 3.5** $T(n,S_{\min}(n))=O(n^{\lg3})$ かつ $\ne o(n\lg n)$、**Thm 3.6/Cor 3.7**。

### 2.3 空白（＝我々の取り分）

- **手数の厳密値がどこにも表化されていない。** §4 冒頭に
  "In this section we shall discuss the **space** complexity" と明記されており、
  **木・バタフライについて時間の定理も表も無い**。鎖でも漸近と不等式のみ。
  → **撤退条件①は発火しない。**
- **$\lg^*$ の段差の onset は未報告**。しかも彼の証明が与える界は
  $\underbrace{2^{2^{\cdots}}}_{p-2}\le S'^{-1}_{\min}(p)\le\underbrace{8^{8^{\cdots}}}_{p}$
  というタワー関数の挟みで、**我々の域では実質何も言わない**
  （$p=2$ の上界 $8^8=16777216$ に対し実測の真値は 6）。
  → **2026-07-27 に $h\le7$ の段差位置を厳密に確定した**（§4.3）。残る空白は $h\ge8$。
- **彼自身の量 $T(Bt(h),S_{\min})$ の厳密表も無い** → 我々が最初に出した（§4.1）。
- **副産物**: de Rezende–Meir–Nordström–Robere (CCC 2019) の対応により、
  厳密 $(t,s)$ は **Nullstellensatz 反駁のサイズ $t+1$・次数 $s$ の厳密値**に直訳される。
  「木族の NS 反駁の厳密最小サイズ表」という証明複雑性側の主張が無料で付く。**ここを必ず書く。**

### 3.1 状態数の見積りが誤っていた（訂正）

> ~~状態空間は $2^{|V|}$ なので素朴 BFS は $|V|\le24$ 程度が限界~~

**これは過小評価だった。** ピーク上限 $p$ で切れば状態数は $\sum_{k\le p}\binom{n}{k}$ に収まり、
$p$ は $\log$ オーダーなので劇的に小さい（`pyr(5)*` は $|V|=21$ だが $p=8$ では 2.3 万状態）。
**この見直しだけで DP を書く前に $h$ が 2 つ伸びた。** 実際に到達した範囲:

| 手段 | 実装 | 到達範囲 |
|---|---|---|
| 素朴 BFS（frozenset） | `revpebble.bfs` | pyr $h\le6$（$p=10$ で 443 秒） |
| ビットマスク＋双方向 BFS | `exp01b_engine.py` | pyr $h\le6$（12.5 秒）、$T_h$ $h\le5$ |
| Aut 商グラフ BFS | `treedp.py` | $T_h$ $h\le6$（+ $p_{\min}$ は $h=7$） |
| ZDD 記号的 BFS | `exp01b_zdd.py`（要 `.venv`） | $T_h$ $h\le6$。$h=7$ は**未到達**（§3.2b） |

### 3.2 「フロンティア DP」「木 DP」は設計が誤っている（訂正）

> ~~木分解による分割統治: 部分木のインターフェース状態だけを持つ DP~~
> ~~ピラミッドは対角線断面が細いのでフロンティア DP が効く~~

**どちらも成り立たない。** 詳細は `data/exp01_results.md` §6-3,4。要点:

- 可逆ペブリングの手順は DAG の切断に沿って**単調に進まない**（置き／取りが任意に交錯し、
  切断の両側を何度も往復する）。「断面が細い」は**標準ペブリングの直観の誤った持ち込み**。
- 部分木 $A,B$ を結合しているのは**占有数の時間プロファイル**であり、
  $A$ を途中の低占有状態で待たせて $B$ を進める手順が実際に最適になる
  （Královič の $\lg^*$ 構成がまさにこれ）。有限インターフェースに潰すと最適解を落とす。
- 素朴に逐次化する DP は**上界しか与えない**。その上界は
  $p_{\min}(T_h)\le p_{\min}(T_{h-1})+2$ に対応し、実測の増分 $2,2,1,1,1,2$ に対して
  $h=4,5,6$ で真に最適でない。

### 3.2b ZDD による記号的 BFS（2026-07-27 第3ラウンド。**現時点で最もメモリ効率が良い**）

`scripts/exp01b_zdd.py`（**`.venv` を要求**: graphillion 2.1）。
状態は頂点部分集合で、BFS の各レベルは**部分集合の族**なので、
ZDD（集合族の圧縮表現）で 1 レベルを 1 つの ZDD として持ち、
1 手の像を ZDD 演算で一括計算する（記号的 BFS）。

このモデルは ZDD と相性が特に良い:

- **toggle 規則で put/take の条件が同一**なので、像は
  「guard を満たす集合に絞る（`supersets`）→ `flip(v)`」の 2 演算で済む。
  **put と take が 1 演算で同時に処理される**（分岐が要らない）。
- **ピーク上限は「濃度 $\le p$」**（`smaller(p+1)`）＝ ZDD が得意な制約。

**圧縮率**: $h=6$ でフロンティア 1.2 億状態が **0.68MB**、
$h=7$ のレベル 30 で 4.1 兆状態が **1.78MB**。

**ただし $M^*(T_7)$ には届かなかった。** フロンティアの ZDD は小さいままなのに、
**1 レベルあたりのコストが深さとともに 2 桁増える**（$h=7$: レベル 10 で 0.03s →
レベル 60 で 10.26s）。60 レベルで peak RSS 11.9GB。
必要レベル数が 603〜1403 なので数時間〜十数時間規模になり打ち切った。
律速はフロンティアではなく**中間結果の同時生存数とライブラリ内部のノード表**である
（詳細と成長曲線は `data/exp01_results.md` §17）。

**効いた工夫**（詳細は `data/exp01_results.md` §16.2）:

1. 無向性より $L_{d+1}=\mathrm{image}(L_d)\setminus(L_d\cup L_{d-1})$。訪問済みを累積しない。
2. 濃度制約は union の**後に 1 回**（127 回 → 1 回。濃度制限は union と可換）。
3. union は**平衡二分木**で畳む。
4. graphillion のノード表は GC されないので、**N レベルごとに保存してプロセスを再起動**
   （`scripts/exp01b_zdd_segment.py`）。無向 BFS は直前 2 レベルで再開できるので厳密性は保たれる。

**教訓**: 2・3 を入れる前は 1 が 3 倍**遅く**、入れた後は 4.5 倍**速く**なった。
ZDD では演算の順序と粒度が支配的で、素朴に測ると最適化の是非を逆に判断する。
1 回目の試行が遅かった主因は診断用 `dumps()` の毎レベル呼び出し（計測が計算を律速）だった。

**Aut 商との組み合わせは採らなかった**: 商の要素は軌道であって頂点部分集合ではないので
頂点を変数とする ZDD では表現できない。代わりに**変数順序を DFS 後順**にして
同型部分木が ZDD のノード共有で自然に畳まれるようにした（上の圧縮率がその効果）。

### 3.3 効いた手（採用）

1. **ビットマスク＋双方向 BFS**（`exp01b_engine.py`）。トグル規則が対合＝状態グラフが**無向**

### 4.2 予想 $M^*(T_h)=2\cdot3^h-1$ は**反証された**

$h=5$ で予想 161 に対し厳密値 **155**、$h=6$ で予想 485 に対し **429**。
反証には厳密値 5 点を使い、うち 2 点が新規（1 点の偶然ではない）。
成長比は $3.40,3.12,2.92,2.77$ と単調減少で $3^h$ 型ではない。
**代わりの閉じた式は提案しない**（6 点では早すぎる。$h=7$ に $p_{\min}$ の段差があるので
外挿が外れる可能性が高い）。

### 4.3 $\lg^*$ 段差の onset と「当てはめ崩壊」の原因

- **$S'_{\min}(h)-h = p_{\min}-h = 0,1,2,2,2,2,3$（$h=1..7$、全点厳密）。段差は $h=3$ と $h=7$。**
  同値な形で $S_{\min}(h)-h = 0,1,1,1,1,2$（$h=1..6$）、段差は $h=2$ と $h=6$
  （両者は彼の Lem 4.3 で結ばれており独立な情報ではない）。
- **彼の定義に揃えた** $\lg^*h-1 = 0,1,2,2,3,3,3$ とは $h=5,6$ でずれる。
  $\Theta$ の主張なので不整合ではないが、**段差が $\lg^*$ の値が変わる位置で起きるわけではない**。
- **彼の定理・証明からは段差位置は一切導けない**（界がタワー関数の挟みで、
  $p=2$ の上界 $8^8$ に対し実測の真値は 6）。**我々の段差位置は新情報である。**
- $h\ge8$ の次の段差は現行の探索では届かない。**位置の予測はしない**（根拠がない）。
- ピラミッドの当てはめ崩壊（$h=5$）の原因は **$p_{\min}$ の超過分の段差**である。
  $h=5$ は「超過分 3 で済む最後の $h$」で $p_{\min}=8$ が限界ギリギリ。
  余裕がないので最適解は再計算で手数を買う（再計算多重度 1.60 → **2.52**、最大 put 3 → 5 回）。
  $h=6$ で超過分が 4 に上がって余裕が復活し、頂点数が増えたのに $M^*$ は $105\to99$ と**減る**。
  → 初回測定の「原因は $p_{\min}$ ではなく構造変化」は**半分だけ正しい**。
  構造変化を引き起こしているのは $p_{\min}$ の段差である。
- **$M^*(G,p_{\min})$ は族の大きさについて単調でさえない**（$P_5\to P_6$、$S_7^*\to S_8^*$、
  $S_{15}^*\to S_{16}^*$ で減る）。**$M^*(p_{\min})$ の数列に式を当てはめるのは筋が悪い。**
  一次データはトレードオフ曲線 $p\mapsto M^*(G,p)$ の 2 次元表にすべき。
- **飽和指標 $\sigma := M^*(p_{\min})/M^*(p_{\min}{+}1)$ が段差検出器として使える**（根拠 5 例、
  うち spinal $k=16$ は事前予測して的中）。$\sigma$ は段差直後に下落し次の段差へ向けて上昇する。
  $\sigma(P_5)=1.567$ は全掃き出し中の最大値で、当てはめが崩壊した場所と一致した。

### 4.4 族が既存族に潰れる（追加した2族の教訓）

- **free-leaves 流儀の spinal tree は鎖と厳密に同一**（$k\le8$・全 $p$）。
- **単一出力のバタフライは完全二分木と厳密に同一**（$k\le3$・全 $p$。出力の錐が木になる）。
- → **族を追加する前に既存族への潰れを確認する。**
  潰れない設定（spinal は all-pebbled、バタフライは全出力終端）にすれば新しい数列が出る。

### 4.5 正規化

`cbt(h) all-pebbled` = `cbt(h+1) free-leaves` が $p_{\min}$・$M^*$・トレードオフ曲線の全 $p$ で
厳密に一致（ピラミッドも同様）。文献と突き合わせるときはレベルのずれ 1 だけ注意すればよい。

  （§3.2。部分木は占有数の時間プロファイルで結合していて有限インターフェースに潰せない）。
  形式化できるのは**上界**側の逐次合成補題
  $p_{\min}(T_h)\le p_{\min}(T_{h-1})+2$、$M^*(T_h,q+2)\le4M^*(T_{h-1},q)+1$ で、
  これは `scripts/treedp.py::compose_schedule` が生成する手順そのものなので
  Lean へ写しやすい（下界はポテンシャル不変量で別途）。
