# 30 — 他分野との結合で画期的な成果を狙う（2026-07-27）

## 0. 判定基準（これを満たさない組み合わせは比喩で終わる）

「異分野融合」は、分野が遠いこと自体には価値がない。次の**どちらか**が成立するときだけ着手する。

- **(M) 機械の移送**: 相手分野に、我々の対象を**計算・判定・証明する道具**があり、
  我々にはそれが無い。→ 我々の行き詰まりが相手の既製品で解ける。
- **(Q) 問いの移送**: 相手分野に、**我々の厳密データが直接答える未解決問題**がある。
  → 我々の副産物が相手の主結果になる。

さらに実務的な篩:

1. **写像が形式的に書けるか**（1ページで定義の対応表が書けるか。書けなければ比喩）
2. **1週間で片方向を検証できるか**（相手の既知値を我々の実装で再現する、等）
3. **相手分野に読者と査読者がいるか**（誰も待っていない結果は画期的にならない）

以下は (M)/(Q) を満たすと判断したもの。**期待値順**。

## 1. 機械学習の再計算（rematerialization / activation checkpointing）— (Q) 最有力

### 写像

深層学習の学習時、活性値をメモリに保持できないので**捨てて後で再計算**する。
これは**標準ペブリングそのもの**である（取り除きは自由）。逆に量子計算のアンシラ管理は
**可逆ペブリング**（clean に戻す必要がある）。

**したがって候補3 の $e$（許される不可逆消去回数）は、この2つの応用領域を繋ぐ軸である。**

| $e$ | モデル | 応用 |
|---|---|---|
| $e=0$ | 可逆ペブリング | 量子回路のアンシラ管理 |
| $0<e<\infty$ | m-erasure ゲーム | **測定を許す量子計算（spooky pebbling 近傍）／未研究領域** |
| $e=\infty$ | 標準ペブリング | ML の再計算・チェックポイント |

**これは候補3 の格下げ（定義が既知）を埋め合わせる第二の生命線になる。**
「1つの厳密枠組みが2つの応用領域を両端に持ち、その間が未研究」という構図は論文の骨格として強い。

### 相手分野が持っているもの／欲しがっているもの

- **Griewank–Walther の `revolve`**（ACM TOMS 2000）: 自動微分の adjoint 計算に対する
  **最適チェックポイント配置**。鎖に対する二項係数構造で、Knill 1995 と同型の構造を持つ。
  → **鎖については既に最適が知られている。我々の貢献は一般 DAG 側。**
- **Chen ら 2016** の $\sqrt{n}$ メモリ、**Checkmate**（MLSys 2020）等の ILP による
  一般計算グラフの再計算スケジューリング。**ILP は最適解を出すが下界の証明を出さない。**
- 実務側は定数倍の改善に金を払う（メモリが GPU の制約）。

### 我々が出せるもの

1. **一般 DAG の厳密最適値**（候補2 の全数データ）= ILP/ヒューリスティクスの **ground truth**。
   「既存ヒューリスティクスは $n\le8$ の全 DAG で最適から何%離れているか」は誰も測っていない。
2. **証明可能な下界**（ILP が出せないもの）。
3. **$e$ による補間**: 「メモリを $p$ に抑えつつ、再計算を $e$ 回に制限する」は
   ML 側で自然な設定（再計算は電力・時間のコスト）なのに定式化されていない。

### 最初の一週間

- `revolve` の最適値を我々の鎖モデルで再現する（写像の検証。ここが合わなければ写像が誤り）。
- 候補2 の $n\le8$ 全 DAG データに対し、ML 側の代表的ヒューリスティクス
  （Chen の $\sqrt{n}$、貪欲、Checkmate の ILP）を実装して最適との差を測る。
- **注意**: 「reversible pebbling ↔ rematerialization」の対応が既に精密化されていないか
  必ず一次確認する（`docs/10_method_toolkit.md` (0') に従い、arXiv/MLSys/NeurIPS と
  Griewank の前方引用を辿る）。

## 2. 記号的組合せ論の holonomic guessing — (M) **我々の最大の弱点を直接治す**

### 動機（我々の実測された失敗）

`docs/00_overview.md` §2.1 のとおり、**少数点の当てはめは4回連続で崩壊した**。
我々がやっているのは素朴な多項式・指数当てはめで、**手法として弱い**。

### 相手分野の機械

- **Zeilberger の creative telescoping** と **holonomic guessing**（Kauers, Mezzarobba,
  Koutschan の `ore_algebra` / `Guess`）: 数列から **P-recursive な漸化式を推測し、
  さらにそれを証明する**。当てはめではなく**証明つきの推測**が出る。
- 推測に必要な項数の理論的下限があるので、「何点あれば信用できるか」が定量的に分かる
  → **我々の「4点は信用しない」を経験則から定量的基準に格上げできる。**

### やること

我々が持っている数列（$1,5,17,53,155,429$、ピラミッド、$e^*$、fib 型、$\Sigma_{\mathrm{rev}}$）を
holonomic guessing に投げ、P-recursive な漸化式が出るか、出るなら何点必要かを見る。
**出た漸化式は creative telescoping で証明できる可能性がある**（＝候補1・4 の本線がいきなり通る）。

**制約**: `ore_algebra` は Sage/Python パッケージで外部依存になる。導入はユーザー確認が必要。
依存を避けるなら、整数上の線形代数で「多項式係数の線形漸化式」を自力で解く実装（Hermite–Padé）
でも同じことができる。**先に自力実装を試すのが本プロジェクトの流儀に合う。**

## 3. SAT コミュニティの proof logging（VeriPB / DRAT）— (M) 下界の証書問題を解く

### 我々の問題

候補7・10 で「全数探索の下界を第三者が検証できる形にしたい」が壁になっている。
Lean に全数検査を載せると `native_decide` の信頼境界が広がるし、規模も限られる。

### 相手分野の機械

- **pseudo-Boolean proof logging（VeriPB）**: SAT/PB ソルバの探索そのものに
  **機械検証可能な証明ログ**を吐かせる。開発者は **Nordström のグループ**
  — つまり可逆ペブリングの複雑性を研究している当人たちで、話が通じる。
- グラフ問題・組合せ探索への適用例が既にある。

### やること

ペブリング最適値の下界（「$p$ 本では $M$ 手未満で不可能」）を PB 制約として符号化し、
ソルバに解かせて **VeriPB 証書を得る**。得られれば「探索したから正しい」ではなく
「証明を添えた」に格上げでき、(a) 認証型の論文になる。

## 4. 非平衡統計力学（stochastic thermodynamics of computation）— (M)+(Q) ハイリスク・ハイリターン

### 状況

候補3 に対する **Grochow–Wolpert (SIGACT News 2018) の批判**
「熱力学的コストは消去ビット数では尽きない」は、裏返せば**相手分野の機械を使えという指示**である。

- Wolpert らの枠組みには **mismatch cost**、**entropy production の下界**、
  Crooks/Jarzynski 等式など、**計算過程の熱力学的コストを厳密に評価する道具**がある。
- 彼らの興味は「計算のどの構造が散逸を決めるか」で、**具体的な最適スケジュールの厳密例が無い**。

### やること

ペブリングスケジュールに対し、消去回数ではなく **entropy production の厳密最小値**を計算する。
$M^*(G,p,e)$ の $e$ を「消去回数」から「mismatch cost の総和」に置き換えた最適化。
成功すれば「**ペブルゲームの最適スケジュールを熱力学的コストで測る**」という新しい量になり、
Grochow–Wolpert の批判に正面から答える形になる（批判を武器に変える）。

**リスク**: 相手分野の定式化を誤解すると全部無駄になる。**共同研究者を探すのが正しい**
（物理側の人を1人巻き込めるかが成否を決める）。単独で踏み込むと時間を溶かす。

## 5. 超最適化（superoptimization）— (M) 候補8 の実装を既製品にする

候補8（極小可逆言語の最小プログラムサイズ）は、実は **superoptimization** そのもの。
相手分野の機械: STOKE、Souper、Rosette/SyGuS ソルバ、bounded synthesis。
**枚挙を自作せずソルバに投げれば、規模が一気に伸びる可能性がある。**
逆に (Q) 側: 可逆言語は探索空間が置換群なので、superoptimization のベンチマークとして新しい。

## 6. 見送るもの（基準を満たさない）

- **DNA/化学反応ネットワーク**: 「ガベージ＝廃棄種」という対応は魅力的だが、
  写像が形式的に書けるところまで詰まっていない。Soloveichik（spooky pebbling の共著者）が
  両分野にいるので**将来の窓口**として記憶しておく程度。
- **圏論・ホモトピー型理論との一般論**: 可逆計算との接続は既に多数あるが、
  **我々の厳密値を計算する道具にはならない**（(M) 不成立）。
- 「量子機械学習」「LLM で予想を生成」等: (Q) が具体化していない。
  ただし LLM は「OEIS コメントの未証明主張の大量スクリーニング」には使える（道具として (M)）。
