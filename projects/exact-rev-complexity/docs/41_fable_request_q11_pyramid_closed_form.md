## なぜやるか
IEICE Trans. A に出す `2026_exact_reversible_pebbling` と、その後続で「時間最適な
並列可逆ペブリングの空間」を扱う。完全二分木では $3\cdot 2^{h-2}+1$ が両側で層1に
なった（`tree_pmin_exact`）。**ピラミッドだけが数列（h≤18）のまま**で、定理になっていない。
このリポの教訓は「価値は数値の点数でなく定理の本数」（`docs/35` 末尾）。
h=19 の値を 1 つ足しても論文は 1 行も進まない。**式か、式が立たない構造的理由が要る。**

## 目標（決定点は 1 つ）
**$p_{\min}(P_h)$（時間最適 $T=2h-1$）を $h$ の式にできるか、できないなら
「なぜ式にならないか」を構造の言葉で確定する。**具体的には次のどれかを成果物にする:
- (a) 閉形式または準多項式（周期つき線形など）の候補 1 本と、それを支える**上界の構成**
  （一般 $h$ の手順族）＋**下界の論法**（`docs/35` が示す run 数を陽に持つ抽象か、別の不変量）。
  片側でも一般 $h$ で Lean に載れば層1に上げる価値がある
- (b) 「$h=13$ で階差の周期が崩れる」ことの構造的説明（最適解のプロファイルが平らになる
  領域の幅など）と、その説明から導かれる**次に測るべき 1 点**（それが h=19 ならそのとき初めて回す）
- (c) 「個数抽象・区間抽象に続いて run 数抽象も届かない」ことの確認（改善 0 件を変異注入で
  空振りでないと示す）。これなら Q12 を「閉じてよい」と提案できる
どれに落ちるかを**最初の 1〜2 時間でスコープし、その判断を先に `docs/` に書いてから**進める。
迷ったら私に質問を書き置いてよいが、答えを待たずに最も見込みのある枝を進める。
