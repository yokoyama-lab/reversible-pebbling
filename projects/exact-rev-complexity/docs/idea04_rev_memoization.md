# 候補4 — 可逆メモ化・可逆部分評価の厳密時空トレードオフ

> 一行: **自分の過去論文（rev_memoization, rev_PE）の漸近的主張を、厳密最適値で裏打ちする。**
> 期待値: 新規性 中／成功確率 **高**／既存資産 大（候補1と抱き合わせ推奨）

## 1. 厳密量の定義

メモ化の依存関係を DAG として取り出し、その上の厳密可逆ペブリング値を求める。

対象 DAG 族:
- **Fibonacci 型**: $F(n)$ の呼び出し DAG（頂点 $0..n$、$v$ の先行点 $\{v-1, v-2\}$）
- **二項係数型**: パスカルの三角形の DAG（$C(n,k)$ 依存）
- **編集距離型**: $m\times n$ グリッド DAG（各セルの先行点は左・上・左上）
- **区間 DP 型**: 行列連鎖乗算・最適 BST の $O(n^3)$ DP の依存 DAG

各々について $p_{\min}$、$M^*(G,p)$、トレードオフ曲線、最適スケジュールの構造。

**キラー比較**: 既存実装（`2017_rev_memoization` / `2021_rev_memoization2` / `rev_PE`）が
実際に使っているスケジュールを同じモデルで手数評価し、**厳密最適との差**を出す。
「我々の実装は $n\le N$ で最適、$n=K$ から $c$ 手だけ損をしている」と言えれば強い。

## 2. 既知と空白

- **既知（自分の仕事）**: 可逆メモ化の設計と漸近評価、可逆部分評価の枠組み。
- **空白**: **最適性が未証明**。実装が最適スケジュールからどれだけ離れているかを
  誰も測っていない。DP の依存 DAG に対する厳密可逆ペブリング値の表も無い。
- **関連**: グリッド DAG の**標準**ペブリングは古典的に研究されているが（Cook のピラミッド下界等）、
  **可逆**版の厳密値は未整備。Královič の「標準ペブル × 鎖」合成上界と比較して
  「合成上界がどれだけ緩いか」を厳密に測れる ← これも新規の言明になる。
- **量子側の接続**: 量子アルゴリズムで古典 DP を可逆に走らせるときのアンシラ管理と直結
  （Meuli 等の SAT ベース手法と比較できる）。応用の動機として書ける。

## 3. 機械化の設計

`scripts/revpebble.py` に DAG 生成関数を足すだけ（**先に tests/ へ期待値**）。

```python
def fib_dag(n): ...      # 先行点 {v-1, v-2}、頂点 0,1 は free
def grid_dag(m, n): ...  # 先行点 左・上・左上、境界は free
def pascal_dag(n): ...
```

- 状態空間の壁: グリッド $4\times4$ = 16 頂点なら素朴 BFS で足りる。$6\times6$ 以上は
  **フロンティア DP**（対角線ごとの断面状態）に切り替える。グリッドは断面幅が小さいので
  この手が効く（候補1の木 DP と同じ発想）。
- Fibonacci 型は幅2の帯なので $n$ を大きく取れる → **数列が長く取れて閉形式推定に向く**。
  ここが最初の成果になりやすい。
- 既存実装のスケジュール抽出: インタプリタに trace を吐かせ、
  (put/take, 頂点) 列に正規化して手数を数える。差分は
  先行プロジェクトの `schedule_extract.py` の分類（部分消去の交錯・不均等セグメント・早期再配置）を流用。

## 4. 初日の実験

```bash
python3 scripts/exp04_memo_dags.py --family fib --nmax 24
```

初日の目標: **Fibonacci 型 DAG の $p_{\min}(n)$ と $M^*(n)$ の数列を $n\le24$ で出し、OEIS 照合。**
帯幅2なので $n$ を大きく取れ、初日で「数列 + 差分構造 + OEIS 未登録」まで到達できる。

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: Fibonacci 型・グリッド型の厳密表と OEIS 未登録の確認、
  既存実装との差の定量化1件。
- **成功（本線）**: $M^*$ の漸化式（帯状 DAG の一般公式）+ 既存実装の最適性/非最適性の証明 +
  Královič 合成上界の緩さの厳密評価。
- **撤退条件**: グリッドで状態爆発してフロンティア DP も組めない場合は
  Fibonacci 型（帯幅2, 3）に絞って短報にする。撤退しても必ず何か出る安全な候補。
