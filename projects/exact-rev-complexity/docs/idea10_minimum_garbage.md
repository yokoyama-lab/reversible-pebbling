## 1. 厳密量の定義

$n$ 入力 $m$ 出力のブール関数 $f$ に対し

- **最小ガベージ幅** $g^*(f) = \min\{g : f$ が $(n{+}g_{\text{in}}) \to (m{+}g)$ の
  可逆関数（置換）に埋め込める$\}$
  - 埋め込みの流儀（入力を保存するか＝Bennett 型か、出力だけ要求するか）を**最初に固定**。
    両方の表を出す。
- **トレードオフ**: ガベージ幅 $g$（$\ge g^*$）を許したときの最小ゲート数 $\gamma(f,g)$。
  「ガベージを1本増やすとゲートが何個減るか」の厳密曲線。
- 分布: 全 $n$ 入力ブール関数（$n\le3$ は全数、$n=4$ は同値類代表）の $g^*$ のヒストグラム。

## 2. 既知と空白

> ⚠️ 以下の §2 は当初の見込み。**実際の判定は `data/exp10_results.md` ①⑤**。
> 「空白」と書いた 1.・2. はいずれも埋まっていた（1. は自明かつ既知、2. は既知）。

- **既知**: 可逆埋め込みに必要なガベージ幅の基本的下界
  $g \ge \lceil \log_2 (\max_y |f^{-1}(y)|) \rceil$（最大逆像サイズの情報論的下界）。
  Bennett の $(x,y) \mapsto (x, y \oplus f(x))$ 構成。自分たちの
  `2022_minimum_garbage`（clean-to-NGC）での議論。
- **空白**:
  1. **上の情報論的下界が達成可能かの厳密判定**が関数ごとに表化されていない。
     **どの関数で下界が緩むか**（$g^* >$ 下界となる最小の $f$）が本命の問い。
  2. **ガベージ × ゲート数の厳密トレードオフ曲線**が未整備。
- **本候補の一番おいしい問い**: **情報論的下界が緩む最小の反例関数を見つける。**
  下界が常にタイトなら定理になり、緩むなら反例が新規結果になる。**どちらでも成果。**

## 3. 機械化の設計

1. **埋め込みの枚挙**: $f$ とガベージ幅 $g$ を固定し、
   「$f$ と整合する $(n+g_{\text{in}})$ ビット置換が存在するか」を判定。
   これは**二部マッチング/フロー問題**として解ける（各入力を、出力プレフィックスが
   一致する符号語へ単射に割り当てる）→ **全数探索でなく多項式時間で判定できる。**
   ここに気付けば $g^*$ の計算は $n=4,5$ でも軽い。**初日に確認すること。**
2. **ゲート数**: 埋め込みを固定した上での最小ゲート数は候補7の Cayley BFS。
   $n+g \le 4$ が限界。よって曲線は小さい関数に限られる。
3. **同値類**: 入力/出力のビット置換・反転（NPN 同値）で商を取り、$n=4$ の代表類だけ扱う。
4. **二重実装照合**: 情報論的下界と全数判定の結果が矛盾しないこと。

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: $n\le4$ の $g^*$ 分布表 + 下界のタイトさの判定結果 +
  `2022_minimum_garbage` の主張との突き合わせ1件。
- **成功（本線）**: 「情報論的下界は常にタイト」の一般証明（Lean 化可）**または**
  緩む最小反例の提示。加えて $n+g\le4$ でのガベージ×ゲート数曲線。
- **撤退条件**: 下界が常にタイトで証明も簡単（既知の系）だった場合、
  ゲート数トレードオフだけが残るが計算量の壁が厳しい → 候補7へ資産を統合して撤退。

## 6. Lean 計画
