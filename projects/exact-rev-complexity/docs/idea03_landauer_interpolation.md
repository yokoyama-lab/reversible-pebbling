# 候補3 — Landauer コストで可逆↔標準を補間するペブリングゲーム

> 一行: **「消してよいビット数 $e$」を第三のパラメータにして、可逆と標準の間の厳密曲面を作る。**
> 期待値: 新規性 **最大**／成功確率 中／既存資産 大（大穴・本命の対抗）

## 1. 厳密量の定義

$e$-**Landauer ペブリングゲーム**（本プロジェクトによる新定義）:

- 基本は clean reversible pebbling game（`docs/20_prior_art.md` §1）。
- ただし**不可逆な取り除き**（先行点が揃っていない状態でペブルを消す）を
  **合計 $e$ 回まで**許す。1 回の不可逆消去は Landauer の意味で $kT\ln 2$ の熱を出す。
- $M^*(G, p, e)$ = ピーク $p$、不可逆消去 $\le e$ の下での最小手数。

境界条件が既知の2極に一致する:
- $e = 0$ → 通常の可逆ペブリング（$M^*(G,p,0) = M^*(G,p)$）
- $e = \infty$ → 標準ペブリング（不可逆消去が自由）

**主な問い**:
1. **飽和点** $e^*(G,p)$: $e$ をこれ以上増やしても $M^*$ が減らなくなる最小の $e$。
   「この DAG を実質的に標準ペブリング並みに速く計算するのに必要な最小の熱」。
2. 曲面 $(p,e) \mapsto M^*$ の形（$e$ について凸か？ $p$ と $e$ の交換レート）。
3. $e=1$ の効果: **たった1ビット消すだけで手数がどれだけ落ちるか**。
   ここが劇的なら「準可逆計算」の設計指針になる。
4. 鎖について $e^*(n,p)$ の閉形式。$e$ と $p$ のトレードオフ（$\log n$ 本のペブル vs $\log n$ 回の消去？）。

## 2. なぜ空白なのか

- 文献は**可逆（$e=0$）と標準（$e=\infty$）の二極**しか扱っていない。
- Landauer 原理・Bennett の熱力学的議論は「消去回数がコスト」と言っているのに、
  **ペブリングゲームの側でそれをパラメータ化した定式化が無い**（要一次確認）。
- Buhrman–Tromp–Vitányi 2001 は可逆と決定性の**空間**の中間領域を接続しているが、
  「消去回数」という資源での補間ではない。→ **ここが本候補の主張の核。**
- 関連しうる先行: Li–Vitányi のエネルギー/可逆性のトレードオフ、
  「partially reversible」「erasure cost」で検索して**必ず一次確認する**（初週の最重要タスク）。

## 3. 機械化の設計

`scripts/revpebble.py` の状態に消去カウンタを1つ足すだけ。

- 状態 = (ペブル集合, 使用済み消去回数)。状態空間は $e_{\max}+1$ 倍になるだけで済む。
- 手: 通常の toggle に加え「先行点条件を満たさない `take`」を、カウンタ $< e$ のときのみ許す。
- BFS で $M^*(G,p,e)$ を全 $(p,e)$ について一括計算し、曲面を CSV へ。
- 飽和点は $M^*(G,p,e)$ が $e$ について単調非増加なので、値が変わらなくなる最初の $e$。
- **二重実装**: $e$ が十分大きいとき標準ペブリングの BFS と一致することを検証（候補2 の実装を流用）。

## 4. 初日の実験

```bash
# 先に tests/ へ: e=0 で従来の M* に一致、e 大で標準ペブル値に一致（両端の整合性）
python3 scripts/exp03_landauer.py --nmax 20 --emax 6   # 鎖の M*(n,p,e) 曲面
```

初日に見るべきもの:
1. **両端の整合**（$e=0$ と $e$ 大）が取れているか。取れていなければ実装バグ。
2. $n=16$ で $e=1$ が手数を何手縮めるか。$M^*(16)=71$ からの落差が最初の見せ場。
3. $e^*(n, p_{\min})$ の数列を $n\le20$ で出し、**OEIS 照合**。

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: 鎖の $M^*(n,p,e)$ 曲面の厳密表 + $e^*(n,p)$ の数列 + $e=1$ の効果の定量化。
  新定義なので**表そのものが一次データ**として全て新規。
- **成功（本線）**: $e^*(n,p_{\min})$ の閉形式 or 漸化式（$\log n$ 絡みを予想）と、
  「$e$ 回の消去は $\Theta(f(e))$ 本のペブルと等価」という交換レート定理。
- **撤退条件**: ①同等の定式化が既存だった（初週の一次確認で判定） ②曲面が退屈
  （$e=1$ で標準ペブリングに落ちてしまう等）。②なら「$e=1$ で崩壊する」自体が
  短報になるので、書き切って次へ。

## 6. Lean 計画

- L2: 曲面の一部（$n\le12$, $e\le3$）を `native_decide`。
- L1: 両端定理（$e=0$ で可逆、$e\ge n$ で標準に一致）を無条件証明。これは
  **定義の妥当性の証明**になるので査読対策として最も重要。

## 8. リスク・注意

- **モデルの自然さを必ず擁護する**こと。「なぜ消去回数を数えるのが正しいか」を
  Landauer 原理から1段落で説明できないと査読で落ちる。
- 「$e$ 回の消去」ではなく「$e$ **ビット**の消去」（一度に複数ビット消す操作を1回と数えるか）
  の区別を最初に決め、両方の表を出すのが安全。
