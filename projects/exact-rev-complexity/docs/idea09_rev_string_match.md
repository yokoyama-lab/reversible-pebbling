# 候補9 — 可逆パターンマッチングの厳密操作数下界

> 一行: **可逆に文字列照合するときの最小操作数・最小ガベージを小域で全数確定し、
> 既存アルゴリズム（Rabin–Karp+）の最適性を判定する。**
> 期待値: 新規性 中／成功確率 中／既存論文の続報

## 1. 厳密量の定義

**操作モデルの固定が本候補の生命線**（ここが甘いと査読で必ず落ちる）。

- 計算モデル: 可逆 RAM ないし可逆ストレートライン program。
  許す基本操作を明示的に列挙する（例: レジスタ間の $\pm$ 代入、スワップ、
  条件付き反転、比較結果の XOR 蓄積、配列読み出しは可逆コピーとして扱う等）。
- 対象問題: 長さ $n$ のテキスト $T$、長さ $m$ のパターン $P$、アルファベット $\sigma$。
  出力は「全出現位置の集合」（clean = 入力と出力以外にガベージを残さない）。
- 量:
  - $\mathrm{OP}^*(n,m,\sigma)$ = clean に照合を完了する最小操作数（最悪ケース）
  - $G^*(n,m,\sigma)$ = 最小ガベージ語数、およびトレードオフ $g \mapsto \mathrm{OP}^*$
  - 既存実装（`2025_Rabin_Karp_Plus`, `2022_EPTCS_rabin_karp_string_match`）の操作数と厳密最適の差

## 2. 既知と空白

- **既知（自分の仕事）**: 可逆 Rabin–Karp と可逆文字列照合のアルゴリズムおよび漸近評価
  （EPTCS 2022、および `2025_Rabin_Karp_Plus`）。
- **空白**: **最適性が未証明。** 「提案手法は $n\le N$ で最適」または
  「$n=K$ から $c$ 操作だけ損」という厳密な言明が無い。
  可逆計算における**問題固有の操作数下界**という研究自体が薄い
  （多くは汎用の可逆化オーバーヘッドの議論に留まる）。
- **一次確認**: 非可逆側の文字列照合の**厳密比較回数**下界には豊富な既知結果がある
  （Knuth–Morris–Pratt の比較回数最適性、Galil–Seiferas 等）。
  **これらの可逆版がどこまで移るかを最初に確認する。** 移らないなら、そこが本論。

## 3. 機械化の設計

1. **操作モデルを状態機械に落とす**: レジスタ数 $r$、各レジスタの値域を有限に切る
   （mod $q$ の小さいハッシュ等）。状態 = 全レジスタの値の組。
   可逆操作は状態空間上の置換 → **Cayley グラフ BFS**（候補7・8 と同じ骨格）。
2. **問題インスタンスを固定して下界を出す**: 「この $(T,P)$ を clean に処理する最小操作数」を
   BFS で厳密に。最悪ケースは全 $(T,P)$ について最大を取る（$\sigma=2$, $n\le8$, $m\le3$）。
3. **既存アルゴリズムの操作数**: 実装を同じ操作集合に翻訳して数える。
   **翻訳の忠実性が争点になる**ので、翻訳規則を明文化して付録に載せる。
4. **二重実装照合**: 素朴 BFS と、既知アルゴリズムの操作数（上界）で挟む。

3. 既存アルゴリズムの同ケースの操作数と比較して差を見る

## 5. 成功判定と撤退条件

- **成功（最小ライン）**: 操作モデルの明文化 + 小域の厳密表 + 既存手法との差1件。
- **成功（本線）**: 「$\Omega(n + m\log\sigma)$ 型の可逆固有下界」+ 既存手法の最適性判定 +
  ガベージ・操作数トレードオフの厳密曲線。
- **撤退条件**: 操作モデルの選び方で結論が変わってしまい（モデル依存性が強すぎ）、
  主張が「我々のモデルでは」に留まる場合。**このリスクが本候補で最も高い。**
  その場合は「同じモデルで既存2手法を比較する」相対評価に主張を落とす（それでも有用）。

- L2: 小域インスタンスの $\mathrm{OP}^*$ を有界検査。
