# 可逆ペブルゲームの亜種: 着想の棚（2026-08-10）

**なぜこの文書があるか**: 2026-08-10 に「消去予算の効き方が分岐の有無で質的に変わる」
（鎖は $e$ に比例して伸び続け、木は有限の $e$ で $p-1$ に飽和する）が出た。
これは **量を固定して族を変える**だけで出た。**同じやり方で亜種を作れば、まだ問える。**
この研究群は計算律速ではなく**着想律速**なので、問いの在庫を切らさないための棚。

土台（既にあるもの）:
- `PebbleDP.Reach`（Lean・忠実な遷移系）と `reach_eq`（層1・機械証明）
- `scripts/exp03_reach_dag.py` の `reachable_dag`（一般 DAG・消去予算つき）
- `scripts/landauer.py`（ビット単位の消去コスト）、`scripts/sat_pebble.py`（SAT+DRAT）
- BFS / CP-SAT / MIP(stage) / SAT の 4 系統と、DRAT 検証の配管

---

## 軸 A: 予算にする資源を変える

現在の予算は「消去イベントの回数」。**何を数えるかを変えると別のゲームになる。**

### A1. ⭐ ランダウアー予算（消したビット数を数える）

**いまの消去は 1 回 1 コストだが、物理的には消した情報量に比例する。**
他のペブルから決まっている値を消してもエントロピーは増えない（コスト 0）。

- **問い**: $\mathrm{reach}_{\mathrm{bit}}(p, B)$ — 総消去ビット数 $B$ での到達。
  **$e$ を数えるゲームと違う答えになるか。** 木の飽和は起きるか
- **なぜ良いか**: **物理的に正しいモデル**で、しかも `landauer.py` が既にある。
  「1 回の消去」を粗い近似だったと位置づけ直せる
- **検証**: 既存 `reachable_dag` と重なる域（各消去のコストを 1 に固定）で一致するか
- **初夜**: 鎖で $\mathrm{reach}_{\mathrm{bit}}(p,B)$ の表。$B=e$ のとき現行と一致するかの校正

### A2. 消去の「同時性」を予算にする

BTV の "limited erasing needs to be performed at **precise instants**" は
**いつ消すか**が効くことを言っている。ならば「**同時に高々 $k$ 個消せる**」制約が自然。

- **問い**: 1 手で $k$ 個まとめて消せるとき、$k$ を増やすと何が変わるか。$k=1$ と $k=\infty$ の差は
- **検証**: $k=1$ で現行と一致

### A3. 3 パラメータ面 $\mathrm{reach}(p, e, T)$（時間も縛る）

現行は手数を無制限にしている。**時間も縛ると、消去と時間が代替関係にあるかが見える。**

- **問い**: 「消去 1 回は手数何回分の価値があるか」の交換レート
- **なぜ良いか**: $M^*$（最小手数）の戦線と `reach` の戦線が**1 つの面に統合される**
- **検証**: $T=\infty$ で現行、$e=0$ で $M^*$ に一致（**両端が既知値で校正できる**）

### A4. スロット再利用回数の予算

ペブルを「置き場」と見て、**同じ置き場を高々 $r$ 回しか使えない**とする。
量子回路の ancilla の疲弊（デコヒーレンス）に対応。

## 軸 B: 二分法の境界を決める ⭐ 最も即着手できる

**今夜の発見の直接の続き。** 鎖（飽和しない）と木（飽和する）の**間**はどうなっているか。

### B1. ⭐ 飽和閾値 $e_0(F,p)$ を新しいグラフ不変量として定義する

$e_0(F,p) := \min\{e : \mathrm{reach}_F(p,e) = \mathrm{reach}_F(p,\infty)\}$
（$\infty$ が有限で達成される最小の $e$。鎖では $e_0 = \infty$）

- **実測済みの手がかり**: cbt は $e_0 = 1$（$p=4,5,6$ で確認）。
  **pyramid は $p\le6$ で $e_0=1$、$p=7,8$ で $e_0=3$ に増える**。$p$ とともに増える
- **問い**: $e_0$ の閉形式。$e_0 < \infty$ となる族の特徴づけ
- **見立て**: 律速が**フロンティアの幅**（兄弟に同時にペブルが要る）なら、
  $e_0$ は **Strahler 数 / vertex ranking** 系の量と関係するはず
- **検証**: 既存の `reachable_dag` でそのまま計算できる。**今夜から回せる**

### B2. 境界にある族を掃く

**分岐はあるが鎖に近い**族を並べ、$e_0$ が有限になる瞬間を見る:
caterpillar（背骨＋葉）／分岐が 1 か所だけの DAG ／不均衡二分木（左が深い）／
series-parallel ／$k$ 分木（$k=2,3,4$）／ダイヤモンド格子

- **問い**: **飽和は「分岐がある」ことで起きるのか、「分岐が繰り返される」ことで起きるのか。**
  caterpillar（分岐はあるが深さ方向に一直線）が答えを分ける
- **検証**: `families.py` に族を足すだけ。**最も安く、最も情報量が多い**

### B3. 逆問題

与えた飽和プロファイル $e \mapsto \mathrm{reach}(p,e)$ を実現する DAG は存在するか。
**任意のプロファイルが実現できるなら「二分法」は存在せず連続体である。**

## 軸 C: spooky pebble game との合流 ⭐ 未踏で、しかも自然

spooky pebble game（Gidney 2021、2110.08973 / 2401.10579 / 2510.08432）は
**測定でペブルを外し、後で「借金」を返す**モデル。消去は**返さない**。

### C1. ⭐ spooky ＋ 消去予算の 2 パラメータ版

**誰もやっていない。** 「返す借金（spooky）」と「返さない破壊（消去）」を同時に持つ。

- **問い**: $\mathrm{reach}(p, s, e)$ — spooky $s$ 個・消去 $e$ 回。
  **$s$ と $e$ は代替するか、相補的か。** 木の飽和は $s$ を入れても起きるか
- **なぜ良いか**: 物理的に意味がある（測定＝安い／消去＝高いがエントロピーを外へ捨てる）。
  **2 つの緩和の相互作用**は、どちらか一方の研究からは見えない
- **注意**: spooky は既存研究があるので、**単独の spooky を再発明しないこと**。
  `docs/24` §2 に既存の対応表がある

### C2. 木の spooky ペブリング

Gidney 系は鎖・一般グラフが中心。**木で spooky が何を買うか**は見当たらない。
**今夜の二分法と同型の問い**（木では spooky も飽和するか）が立つ。

### C3. 測定回数 vs T-count

量子では測定より **T ゲート**が高い。予算を T-count にすると別の最適化になる。

## 軸 D: 高水準可逆言語からのコンパイル ⭐ 応用として最も強い

**研究室の資産（Janus / R-WHILE / RFun / ROOPL++ / rcore / PyJanus）が全部ここに繋がる。**

### D1. ⭐ 可逆機械へのコンパイルにおけるスケジューリング＝ペブルゲーム

可逆言語は**言語として**ゴミを出さないが、**コンパイル時**には
「どの中間値を保持し、どれを再計算するか」を決める必要がある。
**これはレジスタ割付の可逆版で、ペブルゲームそのもの。**

- **問い**: 実プログラムの DAG に対する厳密な最小ペブル数・最小手数
- **なぜ良いか**: **上界は実装（コンパイラを走らせる）、下界は SAT+DRAT**。
  非対称性が理想的に効く。しかも**成果がコンパイラの改善として実体化する**
- **既にあるもの**: `real_program_dags.py`、`exp51_janus_trace.py`、`atlas/` の 111 本計測
- **初夜**: 小プログラム 10 本の DAG を抽出し、既存 `reachable_dag` で厳密値

### D2. 「ゴミ最小性」との接続

研究室の既発表のゴミ理論に対し、**ペブル数がゴミ量の下界を与えるか**。
理論と実測の橋。`Garbage.lean`（層1）に接続できる。

### D3. 再計算コストが一様でない場合

実プログラムでは再計算のコストが命令ごとに違う。**重み付きペブルゲーム**。
`KoAT2`（コスト解析器・未使用）が使える可能性。

## 軸 E: 「階層が潰れる」現象そのものを対象にする

今夜見つけたのは「**木では消去の階層が有限予算で潰れる**」。
**これは資源限定計算の一般的な問いの、きれいな具体例。**

### E1. どの資源階層が潰れ、どれが潰れないか

- 消去予算（今夜: 木で潰れる、鎖で潰れない）
- 時間予算、spooky 予算、ビット予算（A1）
- **「潰れる/潰れない」を分ける構造は何か**

### E2. 潰れる速さ

pyramid は $p$ とともに $e_0$ が増える（1→3）。
**$e_0(p)$ の増大度**（定数・対数・多項式）が族の分類になるかもしれない。
