## 2. 構造的な結論（ここが本題）

**勝った 5 件と負けた 5 件を分けている線は、道具の性能ではない。**

> **今日入れた道具は、ほぼ全部が「有界な事例を判定する」道具である。**
> だから **有界な問い**（$n\le N$ で成り立つか、この構成は規則を守るか、この UNSAT は正しいか）には
> 強く、**全称の問い**（$\forall n, \forall p, \forall e$）には**原理的に届かない。**

- 定理 A・B1 が片付いたのは、**人間が証明を書き、機械が構成と境界を検証した**から。
- **B2 が片付かないのは、B2 が全称命題だから。** IC3 を $p=7$ まで伸ばしても
  $\forall p$ には一歩も近づかない。$p=100$ で反例が出ない保証はどこからも来ない。
- 全称命題に効く道具は **Lean（定理証明系）だけ**で、そこのボトルネックは
  道具の能力ではなく**人間の証明労力**である。

### したがって見込みは「条件つきで高い」

| 問いの型 | 成熟ツールの見込み | 根拠（今日の実測） |
|---|---|---|
| **有界な厳密値を出す** | **高い** | CP-SAT で 8 倍。ZDD・nauty は未使用で伸び代あり |
| **既知結果との比較を決着させる** | **高い** | LTV 比較を 30 点で決着 |
| **下界に証明書を付ける** | **高い**（ただし代価あり） | SAT+DRAT で $n\le20$、証明 33.6 MB |
| **失敗の原因を診断する** | **高い** | holonomic の 0/15 が min-plus 構造を示した |
| **証明の芯を発見する** | **中** | $e=0$ では成功、$e\ge1$ では緩すぎた |
| **全称命題を証明する** | **低い**（Lean 以外に手段なし） | B2 が未解決のまま |

## 3. 見込みが具体的に高い着手先（未使用の道具と直結するもの）

**「道具を入れたから使う」ではなく「この問いに、この道具が噛む」という順序で挙げる。**

1. **候補2 の $n=8,9$ ← nauty**（導入済み・未使用）
   非同型 DAG 列挙が律速で、nauty はそのための 40 年物の標準。
   $R-P$ の分布の完全表という**有界な問い**なので、確実に前進する。**最も確実。**
2. **$M^*(T_7)$ ← ZDD**（導入済み・未使用）
   状態が**頂点部分集合の族**で、ZDD はまさにそれを圧縮する構造。
   候補1 で唯一残った未確定値。有界な問いで、道具と構造が原理的に一致している。
3. **候補4 のメモ DAG ← CP-SAT interval**（実績あり）
   すでに $n\le160$ を出した道具がそのまま適用できる。実プログラムの DAG は
   $e$ が大きい領域なので、勝ちパターンにはまる。
4. **候補10 の下界 ← Lean（Hall の結婚定理）**
   「情報論的下界が達成可能か」は Mathlib の Hall 定理で書ける規模。
   **全称命題に届く唯一の道具を、届く大きさの問題に当てる**という配置。
5. **可逆性を書き換え系の性質として自動判定 ← ACP/AProVE/CeTA**（導入済み・未使用）
   TRS 一式を入れた唯一の使い道。**道具を作らずに済む**のが利点だが、
   まず「可逆性を TRS の性質として書けるか」を紙で確かめる必要がある。**未検証の賭け。**

## 4. 今日の投資の反省（今後の規律）

- **TRS 一式は「対象となる問いを決めずに」入れた。** 6 個入れて 0 個使用。
  導入自体は安価（半日）だが、**問いより先に道具を選ぶと使われない**という実例になった。
- 次からは **「この問いに詰まった。だからこの道具を入れる」** の順序を守る。
  今日で言えば CP-SAT（$n$ を伸ばしたい）と drat-trim（証明書が欲しい）は
  この順序だったから使われ、TRS 一式は逆だったから使われなかった。
- ただし**導入手順の記録（`docs/33`）は資産として残る**ので、
  問いが来たときの立ち上げは速い。完全な無駄ではない。

## 5. 結論（一行で）

> **成熟ツールは「厳密値を伸ばす・比較を決着させる・証明書を付ける・失敗を診断する」には
> 明確に効く（今日 3 件が実証）。しかし全称命題を証明する力は Lean 以外に無く、
> そこは人間の証明労力が律速である。**

したがって見込みの立て方は:
**論文に必要な有界の主張は道具で確実に固められる。定理は人間が書く。**
今日の候補3 はまさにその形（定理 2 本は人間、境界と構成の検証は機械、下界に証明書）で、
**このパターンは他の候補にも移せる。**
