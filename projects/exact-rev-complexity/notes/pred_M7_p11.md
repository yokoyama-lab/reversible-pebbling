## 今夜あらたに計算した数（`tools/night50_offdiag_gap.py`）

3 相分解の手数を

$$\mathrm{3phase}(h,p) \;:=\; M^*(T_{h-1},p) \;+\; P2(h,p-1) \;+\; M^*(T_{h-1},p-1)$$

と定める（第49夜 §11 の対角線の漸化式を、対角線の外でも評価したもの）。これは
**実現可能な手順の手数**なので $M^*$ の上界であり、実測 20 点すべてで
$\Delta(h,p) := \mathrm{3phase}(h,p) - M^*(T_h,p) \ge 0$ である。

$$\mathrm{3phase}(7,11) \;=\; M^*(T_6,11) + P2(7,10) + M^*(T_6,10) \;=\; 261 + 315 + 295 \;=\; \mathbf{871}$$

式の校正: 同じ関数が $\mathrm{3phase}(7,10) = 295 + P2(7,9) + 339 = 295 + \mathbf{367} + 339 = \mathbf{1001}$
を返し、**既知の厳密値 $M^*(T_7,10)=1001$ と一致する**（$P2(7,9)=367$ は第49夜 §11 と独立に再計算した値）。
つまり $(7,11)$ に使っている式は、隣の点で当たることが確かめてある。

⚠ **871 はまだ「手順として replay していない」。** 上界として登録するには
$T_6$ の $p{=}11$ 手順・$P2(7,10)$ の手順・$T_6$ の $p{=}10$ 手順を実際に連結して

## 予測（$(7,11)$ は off=1）

2 つの独立な推定量を使う。

**(a) 比の推定量**: $r(h) = M^*(T_h,p_{\min}+1)/M^*(T_h,p_{\min})$ は
$h=3,4,5,6$ で $15/17=0.882$、$45/53=0.849$、$115/155=0.742$、$339/429=0.790$。
平均 0.816、範囲 $[0.742, 0.882]$。$\Rightarrow 1001 \times [0.742,0.882] = [743, 883]$、中心 **817**。

**(b) 3 相のずれの推定量**: 相対ずれ $\Delta/\mathrm{3phase}$ は off=1 で
$2/17=11.8\%$、$2/47=4.3\%$、$22/137=16.1\%$、$4/343=1.2\%$。平均 8.4%、範囲 $[1.2\%, 16.1\%]$。
$\Rightarrow 871 \times [0.839, 0.988] = [731, 861]$、中心 **798**。

⚠ **基礎は弱い。** 点は 4 つしかなく、$h=5$ だけ桁違いに外れている（$\Delta=22$）。
$T_7$ は $p_{\min}$ が $8 \to 10$ と **2 段**上がった直後なので、off=1 の意味が
他の $h$ と揃っている保証も無い。**外れることを見込んで、幅の違う 4 つに分けて登録する。**

- **P1（広い区間）**: $731 \le M^*(T_7,11) \le 871$
- **P2（狭い区間）**: $790 \le M^*(T_7,11) \le 850$（中心 **815**）
- **P3（構造）**: $\Delta(7,11) > 0$、すなわち $M^*(T_7,11) < 871$
  ——対角線の 3 相漸化式は $h=7$ でも**対角線の外では厳密に非最適**である。
  $M^*(T_7,11) = 871$ なら P3 は失敗（$>871$ は起こりえない。3 相は実現可能なので）
- **P4（パリティ）**: $M^*(T_7,11)$ は奇数
