## 想定している具体化

- I は Fin 10、M は Fin 12。ID は**イベント列の添字**（頂点番号ではない。同じ頂点の配置と除去は別 ID）。
- 重みは配置 +1・除去 −1。初期高さは I・M とも 4。容量ガードは「各イベント後の高さが 0 以上 5 以下」。
- 費用は各イベント**後**の盤面の大きさの和（初期の大きさも遷移数も含めない）。
- 基礎順序 Q は**全ての合法局所語**の先行関係の共通部分（I の 6・M の 14 の下界証人だけから作らない。言語は 200/584 語）。

## 残っている橋渡しの義務 1〜6

1. **合法述語と置換の一致**: ID と ±1 の印はソースに明示。ソースの合法述語（長さ・Nodup・範囲）が
   Fin の全列挙の `List.Perm` と同値であることは Lean の橋渡しとして残る。
   → 手掛かり: CAPACITY-EDGE-I/M の依存 `EnumerationCorrectness.isPermutation_iff_perm_range`
   （`isPermutation n t ↔ t.Perm (List.range n)`）は手元の再ビルドで依存として緑。ただし ID を `List Nat` の
   `range n` で表す形であり、一般定理の側（型 E・`LayerSpec`）への写し替えは誰も示していない（取り込み時の判断: 義務 1 は半分まで）。
2. **1 手の高さ ±1**: 配置は不在の頂点を挿入、除去は所属を要して消す。元の step について盤面長が ±1 になる定理。
   → 11-15 の後続単位 PHYSICAL-STEP-HEIGHT-A2（`successful_step_length_increment`）で**緑**（手元で再検査済み）。
3. **再生が不変条件を保ち高さと費用を積む／容量の成功が符号語ガードに一致**:
   → PHYSICAL-REPLAY-A2（高さの望遠鏡和・Nodup 保存）、PHYSICAL-REPLAY-COST-A2（累積費用＝`cost`）、
   PHYSICAL-CAPACITY-A1・PHYSICAL-PREFIX-GUARD-A1（容量つき再生の成功 ⇔ 容量なし再生の成功 ∧ 接頭辞の上限、
   全体の上限には初期 ≤ 5 が別に要る）で**緑**。ただし Q 言語・一般定理への接続は未。
4. **先行・生存期間・実消去・最終盤面の条件は ID と盤面に依存**するので符号だけのガードには移せない。
   Q の拡張言語全体で捉えられていなければならない。
   → Q-CONVERSE（Python の有限検査のみ）: Q 拡張 ⊊ 容量なし合法語（I 472 vs 1200、M 2916 vs 15840）で**逆は偽**、
   ただし「Q 拡張 ∩ 容量ガード ＝ 容量つき合法語」は I・M とも成立（手元で同じコードを再実行して一致。独立実装ではない）。
   NONCAPACITY-COUNTEREXAMPLE（Lean 緑）は物理的な反例だけで、Q の定義への違反は未証明。
   紙の証明 `pebbling-noncapacity-classification-20261115T2000.md`（小さい DAG R_X で N_X=LE(R_X)、I 1200・M 15840）は未形式化・未レビュー。
5. **v15 の「資源ガードを残す表現との対照」の数（Q 拡張 472/2916・ガード後 200/584）は原稿に記録された有限の証拠であって、
   取り込んだ Lean 定理ではない。** 具体的な Q の辺のデータと、容量以外の条件の同値の完全な証明を回収または証明するまで、
   形式検証済みの物理的適用とは言えない。
6. **大域の k**: 改名した互いに素な ID と、因子・末尾の固定順の合成。物理的な分解の一意性と費用のシフトには別の橋渡しが要る。
   局所の証拠も一般定理も、単独では大域の式を証明しない。
